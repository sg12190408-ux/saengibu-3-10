2학년 수학Ⅱ 패턴 ① 동기·과정·결과·확장 + ⑥ 머리·가슴·발 통합

신소재 열전도율 모델링 — 푸리에 법칙·미분방정식·유한차분

"신소재의 열전도율 모델링에서 푸리에의 법칙과 온도에 따른 열전도율 변화를 수학적으로 탐구함. 미분방정식·적분·지수함수를 활용해 열 전도 현상을 분석하고, 유한 차분법·유한 요소법으로 실험 데이터를 수치 해석. 편미분방정식으로 3차원 온도 분포를 예측하는 과정을 이끌어냄."

재료공학 지원자 중 '신소재의 물성을 수학으로 푸는 능력'을 이렇게 명확히 보여준 사례는 흔치 않아. 학종 평가자가 가장 좋아하는 '진로 직결 정량 모델링' 정점.
2학년 기하 패턴 ② 키워드 연계형 + ③ 호기심·탐구형

그래핀 격자 — 벡터·브릴루앙 존 시뮬레이션

"이차곡선의 정의와 판별식을 수학적으로 해석하고, 그래핀 구조의 물리적 특성을 기하적으로 접근하며 벡터·격자 구조·브릴루앙 존 등 고등수학을 넘어선 개념을 활용해 물질의 성질을 설명함. 시뮬레이션으로 그래핀 내 원자 위치와 밴드 구조의 관계를 도출."

고등학교 기하 단원에서 그래핀 브릴루앙 존까지 끌고 간 건 명확한 재료공학 의지 표현. '탄소나노튜브(1학년) → 그래핀(2학년)'으로 탄소계 신소재에 대한 깊이가 한 단계씩 자라고 있어.
2학년 진로활동 패턴 ① + ② 키워드 연계형

회로 설계자 vs 재료공학 연구원 — 직무 비교 + AI 반도체 산업 분석

"반도체 회로 설계자와 재료공학 연구원을 주요 직업군으로 선정해 직무별 역할과 요구 역량을 비교 분석함. 회로 설계는 EDA 시뮬레이션, 재료공학은 신소재 개발과 물성 개선이 핵심임을 파악. 'AI 반도체 개발 경쟁 심화'를 주제로 NPU 설계 필요성, 데이터센터 전력·냉각 비용, 엣지 AI 저전력 반도체 수요까지 산업·정치·환경 관점으로 분석."

진로 전환의 결정적 한 줄. '왜 회로 설계가 아니라 재료공학을 골랐는가'에 대한 본인의 정답이 여기 있어. 면접·자소서에서 그대로 인용 가능한 1순위 자료.

1. 신소재 열전도율 측정 — 수학Ⅱ 푸리에 모델의 실험 검증

난이도 ★★☆ 3~4주 키워드 연결: 신소재·물성 측정·재료공학
🌱 왜 태현이에게 좋을까? 2학년 수학Ⅱ에서 푸리에 법칙·유한차분으로 '계산'은 했지만, 실제 측정 데이터로 '검증'한 적은 없어. 재료공학의 핵심 훈련은 모델 → 실험 → 모델 보정 사이클이야. 이 활동이 끝나면 태현이는 "신소재의 열전도율을 직접 측정하고 푸리에 식으로 보정해본 사람"이 돼. 면접에서 "왜 회로가 아니라 재료냐"에 답할 수 있는 한 장이 손에 남아.

📚 알아두면 좋은 핵심 이론

  • 푸리에 열전도 법칙 — q = -k(dT/dx). 단위면적당 열류는 온도 기울기에 비례, k가 재료 고유 물성.
  • 1차원 정상상태 열전도 — 막대 양 끝 온도 차가 일정할 때 거리별 온도가 직선이 되는 조건.
  • 유한차분법(FDM) — 미분방정식을 이산 격자에서 차분으로 근사해 컴퓨터로 푸는 수치 해석 기법.
  • 접촉저항·열손실 — 측정값이 문헌값보다 작게 나오는 두 주범. 단열 처리·열화상으로 검증.
  • 금속·세라믹·고분자 k 비교 — 자유전자가 있는 금속이 압도적으로 높고 고분자는 낮음. 신소재(그래핀)는 예외적으로 1500 W/mK 이상.

A. 실험형 / 실천형

  • 구리·알루미늄·스테인리스 봉 3종 한쪽 끝 가열 후 거리별 온도 시계열 측정 (디지털 온도센서·아두이노)
  • 1차원 푸리에 식으로 k 추정 → 문헌값과 비교 → 오차 원인(열손실·접촉저항) 분석
  • 유한차분 시뮬레이션 그래프와 실험 그래프 한 장에 겹쳐 산출
  • 1쪽 인포그래픽 + 보고서

B. 문헌형

2. 그래핀·탄소나노튜브 — 격자 기하에서 밴드갭까지

난이도 ★★★ 3주 키워드 연결: 신소재·격자·소자 응용
🌱 왜 태현이에게 좋을까? 1학년 탄소나노튜브 → 2학년 그래핀 격자·브릴루앙 존 흐름에 한 번 더 깊이를 더할 수 있어. 단일층 그래핀이 왜 반금속(밴드갭 0)인가 vs CNT는 왜 직경·카이랄리티에 따라 반도체/금속이 갈리는가를 격자 기하로 직접 설명할 수 있게 되면, 재료공학 면접에서 가장 강력한 카드가 손에 남아. "태현이가 직접 격자 벡터를 그려보고 밴드를 시각화한 사람"이라는 정체성.

📚 알아두면 좋은 핵심 이론

  • 육각 격자와 단위 셀 — 그래핀의 격자 벡터 a₁·a₂(약 2.46Å), 단위 셀 안에 탄소 2개(A·B 부격자).
  • 역격자와 브릴루앙 존 — 실공간 격자 벡터에서 역격자 벡터를 구하면 K·K′ 디랙 점이 정육각형 꼭짓점에 위치.
  • 밴드갭과 반금속 — 그래핀은 K점에서 가전자대-전도대가 한 점에서 만나 밴드갭이 0(반금속). 보통 반도체와 다른 이유.
  • CNT 카이랄 벡터 (n,m) — n-m이 3의 배수면 금속, 그 외엔 반도체. 직경 d ≈ a√(n²+nm+m²)/π.
  • X선 회절 결정구조 분석 — 브래그 식 nλ=2d sinθ로 격자상수 측정. 그래핀·CNT 식별의 표준 도구.

A. 실천형

  • 그래핀 단위 셀 격자 벡터 직접 작도 → 역격자·디랙 점(K, K') 위치 도출

  • '격자 기하 한 장 → 전기 물성 한 장' 매칭 인포그래픽

  • KCI·DBpia '그래핀 밴드 구조 입문', 'carbon nanotube chirality'

3. 반도체 PN접합 — 도핑이 만드는 다이오드의 I-V 특성

난이도 ★★☆ 2~3주 키워드 연결: 반도체 도핑·PN접합·소자 응용
🌱 왜 태현이에게 좋을까? 1학년 N/P형 반도체 회로 실습 → 2학년 신소재(재료공학)로 시선이 깊어진 흐름에서, 둘을 잇는 카드가 바로 '도핑이 만드는 PN접합 I-V 특성'이야. 회로 레벨(다이오드)과 재료 레벨(도핑·캐리어)을 한 실험에서 동시에 다뤄볼 수 있어. 이 활동이 끝나면 태현이는 "실리콘에 도핑이 어떻게 PN접합 다이오드를 만들고 어떤 I-V 곡선을 만드는지 직접 측정·시뮬레이션해본 사람"이 돼.

📚 알아두면 좋은 핵심 이론

  • 반도체 도핑 — N형(인·As)은 자유전자, P형(붕소·Ga)은 정공을 만드는 불순물 첨가. 캐리어 농도 ~10¹⁵~10¹⁸/cm³.
  • PN접합과 공핍층 — N과 P가 만나는 경계에서 캐리어가 재결합해 생기는 전기 중성 영역. 내부 전위차(built-in potential) 약 0.7V(Si).
  • 다이오드 방정식 — I = I₀(exp(qV/nkT)−1). 순방향에서 지수적 증가, 역방향에서 미세 누설. n: 이상계수 1~2.
  • 밴드 다이어그램 — 페르미 준위가 N에서 전도대 근처, P에서 가전자대 근처. 접합 시 평형 페르미 준위가 일치하며 밴드가 휘어짐.
  • Shockley-Read-Hall 재결합 — 결함 매개 재결합. 도핑이 너무 높거나 결함이 많으면 누설 전류 증가, 소자 성능 저하.

A. 실천형

  • 실제 1N4148 다이오드의 I-V 곡선을 멀티미터·아두이노로 직접 측정
  • LTspice로 동일 다이오드 SPICE 모델 시뮬레이션 → 측정값과 비교, n·I₀ 추정
  • 온도 변화(상온·40℃·60℃)에 따른 I-V 시프트 관찰 → kT 의존성 검증

B. 문헌형

  • KCI·DBpia '반도체 도핑 PN접합', 'Si diode I-V characteristics'
  • 한국반도체디스플레이기술학회지 도핑·소자 논문 리뷰
  • 단행본: 'Solid State Electronic Devices(Streetman)' 5장
  • 오픈코스: MIT OCW 6.012 'Microelectronic Devices' 강의노트

🚀 어떻게 시작하면 될까 — 4단계

  1. 다이오드 1개 + 측정 회로 구상⏱ 30분
    1N4148 다이오드와 1kΩ 저항을 과학실에서 확보(또는 학교 메이커실). 검색 키워드 반도체 도핑 PN접합 · 다이오드 I-V 측정 회로로 회로도 1장 확보. 가변저항으로 인가 전압을 0~1V 변화시키고 V·I를 측정하는 단순 회로 그리기.✓ 완성품: 회로도 손그림 1장 + 부품 사진. 다음 단계의 청사진.
  2. LTspice에서 SPICE 시뮬레이션 먼저⏱ 1~2h
    LTspice(analog.com/ltspice) 무료 다운로드 → 1N4148 다이오드 회로 그리기 → DC sweep 0~1V 분석. 출력 그래프에서 순방향 0.6V 부근부터 지수 상승 확인. 명령:
    .dc V1 0 1 0.01
    .model D1N4148 D(Is=2.52n N=1.752)
    그래프를 .png로 저장. n·Is 값을 메모.✓ 완성품: LTspice 회로 .asc + I-V 시뮬레이션 그래프 .png 1장.
  3. 실측 I-V + 다이오드 방정식 피팅⏱ 2~3h
    가변저항 돌려가며 V를 0~0.8V로 0.05V 간격 측정, 각 V에서 I 기록(15~17점). Google Colab에서 Colab(colab.research.google.com)에 데이터 입력 후 다이오드 방정식 피팅:
    from scipy.optimize import curve_fit
    def diode(V, I0, n): return I0*(np.exp(V/(n*0.0259))-1)
    popt, _ = curve_fit(diode, V, I, p0=[1e-9, 1.5])
    실측 n·I₀를 시뮬레이션값과 비교. 온도 3종(상온·40℃·60℃)에서 반복 측정하면 깊이 ↑.✓ 완성품: 실측-시뮬 비교 그래프 .png 1장 + n·I₀ 추정 표 + 코드 .ipynb.
  4. '도핑 → PN접합 → I-V' 한눈에 보기 인포그래픽⏱ 2~3h
    Canva(canva.com) A4 1매: 실리콘 결정구조 → N형/P형 도핑 → 공핍층·내부전위 → 다이오드 I-V 곡선. 한국반도체디스플레이기술학회지·KCI(kci.go.kr)에서 검색 키워드 반도체 도핑 리뷰논문 1편 인용. 물리 교과샘께 5분 검토 — 회로(소자) vs 재료(도핑) 두 시각이 한 장에 있는지 점검.✓ 완성품: A4 인포그래픽 1매 + 보고서 6쪽. 학종 자기소개서 '회로→재료 전환 서사' 핵심 자료.
