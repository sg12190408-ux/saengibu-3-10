너만의 키워드 3개

학종 평가의 한 가지 분명한 원칙: "한 키워드로 1→2→3학년이 이어지면 학종에서 최고점".

키워드 수직 연계 — 학년별 깊이

역학·열·운동현대 물리·양자시뮬레이션·AI 계산
✨ 잘하고 있는 점: 1학년 진로희망은 '이공계'(물리·화학·생명·지구·공학·수학)였는데, 2학년에 '물리학·공학'으로 똑 부러지게 좁혔어. 1학년에는 베르누이 비행기·원심분리기·마찰계수가 폭넓게 펼쳐져 있었고, 2학년 진로활동은 마찰계수 빗면 실험·LED 플랑크 상수 측정·과제연구특강·진로독서('문명과 수학')로 모두 물리학·수학·공학 한 축으로 정렬됐어. 이건 일관성 부족이 아니라 전환 이후 일관성 확보야. 거기에 인공지능 기초 99점·자율주행 AEB·디지털 트윈으로 '시뮬레이션·AI 계산'이 새 키워드로 또렷이 솟아오른 게 너의 차별점. 🌱 다음 한 걸음: 3학년 활동 1개에 '시뮬레이션으로 풀어본 물리 현상'을 한 번 더 등장시키면 1·2학년 키워드가 3학년까지 수직으로 한 줄을 만들어.

SECTION 05

너의 베스트 모먼트 3

생기부에서 가장 잘 쓰인 문장 3개. 왜 좋은지를 우수 세특 패턴 분류로 풀어줄게.

🟢 진로활동 · 2학년 패턴 ① 동기·과정·결과·확장

LED 플랑크 상수 측정 — 고전→현대 물리 잇기

"플랑크 상수 측정 과정을 LED의 문턱 전압과 방출 파장이라는 현대적 방법으로 진행하며, 양자점의 특성과 에너지 준위의 원리를 분석함. 고전 물리와 현대 물리의 연결점에서 이론과 실험의 상호작용을 체계적으로 탐구하며 과학 연구가 실생활 및 첨단 기술과 어떻게 이어지는지 논리적으로 설명함."

✨ 같은 물리학·공학 지원자 중에서도 '플랑크 상수를 LED로 직접 측정'까지 간 학생은 흔치 않아. '고전→현대'라는 시간 축 위에 자기 학습을 배치한 게 학종 평가자가 가장 좋아하는 그림이야.
🟢 수학Ⅱ · 2학년 패턴 ② 키워드 연계형 + ⑥ 머리·가슴·발 통합

자율주행 AEB 제동거리 — 정적분으로 푼 알고리즘

"속도-시간 그래프에서 면적이 이동 거리를 의미함을 수학적으로 분석하고 이를 바탕으로 AI가 실제 제동 거리를 계산하여 충돌 가능성을 판단하는 과정을 깊이 있게 설명함. 등가속도 운동의 수식과 정적분 개념의 일치를 확인함으로써 교과서 내 이론과 실생활의 연결고리를 명확하게 인식함."

✨ 수학·물리·인공지능 알고리즘이 한 활동 안에서 깔끔하게 합쳐졌어. '교과 안 정적분 → 자율주행 의사결정'으로 연결이 자연스러워서 진로 일관성을 가장 잘 보여주는 사례.
🟢 진로활동 · 2학년 패턴 ① + ③ 호기심·탐구형

빗면 마찰계수 측정 — 오차를 물리법칙으로 다시 읽기

"경사면의 기울기를 조절하며 나무토막의 마찰계수를 구하고, 다양한 경사각을 측정해 나온 정지거리와 이론적 수치의 차이를 분석... 미세한 오차와 표면 거칠기, 회전 운동 등 실험 상황별로 다양한 요인을 고려하여 탐구하고, 실험 결과를 물리 법칙의 한계로 확장해 해석함."

✨ 단순 실험 보고가 아니라, '오차 = 모델 가정의 한계'로 해석해낸 한 줄이 핵심. 물리학과·기계공학과·항공우주공학과 면접에서 그대로 답이 되는 사고 흐름이야.

너의 키워드를 한 단계 더 깊게 가져갈 탐구 3종.

⚛️ 1. LED 문턱전압 ↔ 플랑크 상수 — 색깔별 정밀 측정과 오차 모델링

난이도 ★★☆ 3주 키워드 연결: 현대 물리·양자·실험
🌱 왜 이 활동이 너에게 좋을까? 2학년 진로활동에서 LED 문턱전압으로 플랑크 상수를 한 번 측정해봤는데, 그건 시작점이야. 같은 실험을 빨강·초록·파랑·자외 LED 4종으로 확장하고 오차 요인을 모델링하면 '고전→현대 물리' 줄기가 3학년에 한 칸 더 깊어져. 같은 물리학·공학 지원자 중에서도 흔치 않은 활동이고, "오차를 모델로 푸는 학생"이라는 색을 만들어내는 결정적 한 장이 돼.

📚 알아두면 좋은 핵심 이론

  • 광전효과(Photoelectric Effect): 빛(광자)이 전자를 튕겨내는 현상. E = hf 관계로 양자역학의 출발점이 된 실험.
  • 플랑크 상수 h: 6.626×10⁻³⁴ J·s. "에너지가 띄엄띄엄 양자화된다"는 사실의 단위. LED 빛에서도 직접 측정 가능.
  • 문턱전압 V_th: LED가 빛을 내기 시작하는 최소 전압. 전자가 밴드갭을 넘는 데 필요한 에너지에 대응. e·V_th ≈ E_gap = hc/λ.
  • 밴드갭(Band gap): 반도체에서 전자가 점프하기 위해 필요한 에너지 간격. LED 색깔(파장 λ)이 이 값으로 정해짐 — 빨강이 작고 파랑이 큼.
  • 측정 오차의 분해: 시스템적 오차(접합부 전압강하·온도) vs 통계적 오차(반복 측정 표준편차). "오차의 출처를 안다"는 게 정밀 실험의 핵심.

A. 실험형 / 실천형

  • LED 4색 + 가변저항 + 디지털 멀티미터로 I-V 곡선 측정
  • 문턱전압 V_th와 방출 파장 λ로 h = e·V_th·λ/c 계산, 색별 오차 비교
  • 온도·다이오드 종류·측정 회로의 영향을 통제변인으로 추가
  • 색별 측정값 + 오차 막대 그래프 1쪽 포스터로 산출 (학급 발표 가능)

B. 문헌형

  • RISS·KCI '플랑크 상수 LED 학생 실험' / 'Planck constant LED'
  • 한국물리학회 새물리·물리교육 학회지의 학생 실험 사례
  • EBS·KOCW 양자역학 입문 강의(에너지 준위·반도체 밴드갭)
  • 단행본: '파인만의 여섯 가지 물리 이야기' 양자 단원, '대학 물리학(영·프리드먼)' 광전효과 단원

🚀 어떻게 시작하면 될까

  1. LED 4종 + 측정 도구 세팅⏱ 30분~1h
    학교 물리실 또는 아두이노 키트에서 빨강(620nm)·노랑(590nm)·초록(525nm)·파랑(470nm) LED 4종 + 가변저항(10kΩ) + 디지털 멀티미터 2대 준비. 데이터시트에서 정확한 peak wavelength λ를 메모하기. PhET 시뮬레이션 phet.colorado.edu/ko/simulation/diode로 회로 구성 먼저 가상으로 확인.✓ 완성품: LED별 λ 값 표 1장 + 회로도 1장. 다음 단계의 기준선.
  2. 색별 I-V 곡선 측정 → 문턱전압 V_th 추출⏱ 1~2h
    가변저항을 0V부터 0.05V 간격으로 올리며 LED별 전류 I 기록. 빛이 막 보이는 지점이 아니라 I-V 그래프의 외삽 직선과 V축 교점이 V_th. 색별 5회 반복하고 평균±표준편차 산출. 어두운 방·디지털카메라 RAW로 점등 시점 보조 판정.✓ 완성품: I-V 곡선 4장 + V_th 평균±σ 표 1장.
  3. Colab으로 h 계산 + 색별 오차 비교⏱ 1~2h
    Google Colab(colab.research.google.com)에서:
    import numpy as np
    e, c = 1.602e-19, 3e8
    V_th = np.array([1.95, 2.10, 2.35, 2.65]) # R,Y,G,B
    lam = np.array([620, 590, 525, 470]) * 1e-9
    h = e * V_th * lam / c
    참값 6.626e-34와의 상대오차를 색별로 계산. 빨강 LED에서 오차가 가장 큰 이유(밴드갭 손실·열에너지)를 한 줄로.✓ 완성품: h 계산 .ipynb 1개 + 색별 오차 막대그래프 1장.
  4. 오차 모델 보고서 + 학급 발표 포스터⏱ 2~3h
    A4 1쪽 보고서 구조: 광전효과 이론(E=hf) → 실험 설계(통제·조작 변인) → 결과(색별 h·오차) → 오차 모델(접합부 전압강하·온도·암전류). 한국물리학회 새물리 또는 물리교육에서 LED 학생 실험 논문 1편 인용. 물리샘께 5분 점검 후 학급 게시판에 포스터 부착.✓ 완성품: A4 보고서 1쪽 + 발표 포스터 1장. 면접 '실험 정밀화' 사례로 직결.

🚗 2. 자율주행 AEB 제동거리 — 정적분 시뮬레이터 (수학Ⅱ 다음 단계)

난이도 ★★☆ 2주 키워드 연결: 시뮬레이션·AI·역학
🌱 왜 이 활동이 너에게 좋을까? 2학년 수학Ⅱ에서 정적분으로 AEB 제동거리를 풀어봤지만, 거기서 멈췄어. 인공지능 기초 99점·기하 A의 코딩·기하 감각과 정확히 만나는 영역. 변수만 바꾸면 결과가 바뀌는 '시뮬레이터'를 직접 만들면 머리·가슴·발(패턴 ⑥)이 한 활동에서 완성돼. "수학을 시뮬레이터로 옮길 줄 아는 학생"이라는 자격증이 손에 남는 활동.

📚 알아두면 좋은 핵심 이론

  • 등가속도 운동: 속도 v(t) = v₀ + at, 거리 s = v₀t + ½at². 수학Ⅱ 정적분의 가장 직접적인 물리 응용.
  • 반응시간(t_r): 운전자가 위험을 인지하고 브레이크를 밟기까지의 시간. 보통 0.7~1.5초. 이 0.5초 차이가 정지거리에서 m 단위 차이로 증폭.
  • 정적분으로 거리 구하기: s = ∫v(t)dt. v-t 그래프 아래 면적 = 이동거리. 수학Ⅱ 적분 단원의 살아있는 사례.
  • 국토부 정지시거(Stopping Sight Distance): 도로 설계 시 보장해야 하는 최소 정지거리. 도로의 구조·시설 기준에 관한 규칙에 속도별 표가 명시되어 있음.
  • 로지스틱 회귀 분류기: "안전/위험" 같은 이진 분류에 쓰는 가장 단순한 머신러닝 모델. sklearn.linear_model.LogisticRegression으로 한 줄 학습 가능.

A. 실험형 / 실천형

  • Python(matplotlib)으로 v(t) → ∫v dt = s 시뮬레이터 구현
  • 변수: 초기속도(40·60·80·100 km/h) × 감속도(-3·-5·-7 m/s²) × 반응시간(0.5·1·1.5s)
  • 최소 안전거리·충돌 가능성 분류기를 if 조건문으로 추가
  • 국토부 도로 설계 기준의 정지시거와 비교해 적절성 검증

B. 문헌형

  • 한국자동차공학회지·자동차안전학회지 'AEB 제동거리 모델'
  • 국토교통부 '도로의 구조·시설 기준에 관한 규칙' 정지시거 표
  • NHTSA·Euro NCAP의 AEB 평가 프로토콜 영문 자료
  • 단행본: '자율주행 자동차의 모든 것' 1·2장

🚀 어떻게 시작하면 될까

  1. v(t) 모델 결정 + 정적분 손계산⏱ 30분~1h
    먼저 종이에 손계산: 반응시간 t_r 동안 등속 → 감속 시작 후 v(t)=v0+at. 정지거리 s = v0·t_r + ∫₀^(v0/|a|) (v0+at) dt. 수학Ⅱ 정적분이 곧바로 들어가는 부분. v0=80km/h, a=-5m/s², t_r=1s 케이스 직접 풀어보고 답 확인.✓ 완성품: 손풀이 노트 1쪽. 시뮬레이터 검증의 정답지.
  2. Colab/Python 시뮬레이터 골격 작성⏱ 1~2h
    Colab에서:
    import numpy as np, matplotlib.pyplot as plt
    def stopping_dist(v0, a, tr):
      t = np.linspace(0, tr + v0/abs(a), 500)
      v = np.where(t<tr, v0, v0 + a*(t-tr))
      v = np.maximum(v, 0)
      return np.trapz(v, t)
    1번 손풀이 결과와 5% 이내로 일치하면 통과.✓ 완성품: stopping_dist() 함수 + 검증 통과 로그 1장.
  3. 변수 격자 실험 + 안전거리 분류기⏱ 2~3h
    v0(40·60·80·100km/h) × a(-3·-5·-7m/s²) × t_r(0.5·1·1.5s) = 27케이스 자동 반복. pandas.DataFrame에 정리 후 히트맵으로 시각화(seaborn.heatmap). 도전: sklearn.linear_model.LogisticRegression으로 '안전/위험' 이진 분류기 학습. 국토부 도로의 구조·시설 기준에 관한 규칙 정지시거 표와 격자 결과를 같은 그래프에 겹쳐 그리기.✓ 완성품: 27케이스 결과 표 + 히트맵 1장 + 분류기 정확도.
  4. 자율주행 AEB 제언 보고서 + 코드 공개⏱ 2~3h
    A4 2쪽 보고서: 문제(반응시간이 0.5s 늘면 거리 ?m 증가) → 모델·정적분 → 27케이스 분석 → NHTSA AEB 기준과 비교 → 제언(센서 latency 0.3s 이하 필요성 등). NHTSA AEB 평가 프로토콜 영문 1편을 인용 + 한국자동차공학회지 1편. GitHub에 코드 공개(github.com/[본인ID]/aeb-sim) 하면 면접 카드 +1.✓ 완성품: A4 2쪽 보고서 + GitHub 저장소 1개. '수학Ⅱ→공학 시뮬레이션' 결정타.

🏔️ 3. 빗면 마찰계수 정밀 측정 — 회전 운동 보정 모델

난이도 ★☆☆ 2~3주 키워드 연결: 역학·실험·오차 모델링
🌱 왜 이 활동이 너에게 좋을까? 2학년 진로활동에서 빗면 마찰계수를 측정하며 '회전 운동·표면 거칠기'를 오차 요인으로 짚은 게 인상적이었어. 거기서 한 발 더 — 회전 관성을 보정한 모델과 보정하지 않은 모델을 직접 비교하면, 1학년 수학 약점도 '나는 오차를 모델로 푸는 학생'이라는 강점으로 덮을 수 있어. 실험 부담이 적어 3학년에 가장 안전한 카드.

📚 알아두면 좋은 핵심 이론

  • 동마찰계수 μ_k: 운동 중인 물체와 표면 사이의 마찰력 비례 상수. F_k = μ_k·N. 빗면에서는 μ_k = tanθ - a/(g·cosθ)로 직접 측정 가능.
  • 관성모멘트 I: 회전 운동에서 '회전하기 싫어하는 정도'. 구는 I = ⅖mr², 원기둥은 I = ½mr². 굴러 내려가는 물체는 이만큼 가속도가 작아짐.
  • 구르기 마찰(Rolling Friction): 미끄러지기 마찰과는 다른 메커니즘. 실측에서 마찰계수가 과대평가되는 가장 큰 원인 중 하나.
  • 잔차(Residual): 잔차 = 실측값 - 예측값. 어느 모델이 실제와 더 가까운지 비교하는 가장 단순한 도구.
  • RMSE(Root Mean Square Error): √(평균(잔차²)). 모델 정확도를 한 숫자로 요약. 모델 A·B·C를 비교할 때 객관적 지표가 됨.

A. 실험형 / 실천형

  • 나무토막·구슬·원기둥 3종으로 빗면 정지거리 5회 반복 측정
  • 모델 A: 단순 마찰만 / 모델 B: 회전 관성(I·α) 보정 / 모델 C: 공기저항 항 추가
  • 각 모델의 예측값과 실측값 잔차(residual)를 표·그래프로 비교
  • '오차의 50%는 회전 관성에서 온다' 같은 정량적 결론 도출

B. 문헌형

  • RISS '회전 관성 빗면 정지거리' / 'rolling friction inclined plane'
  • 한국물리학회 물리교육의 일반물리 실험 사례 모음
  • EBS·KOCW 일반물리학 강의 회전 운동 단원
  • 단행본: '대학 물리학(영·프리드먼)' 회전 운동 / '자전거의 물리학' 일부

🚀 어떻게 시작하면 될까

  1. 실험 세팅 + 통제변인 명문화⏱ 30분~1h
    나무 빗면(길이 1m) 각도 15°·20°·25° 3종 + 시료 3종(나무토막=미끄럼만 / 구슬=구·I=2/5mr² / 원기둥=I=1/2mr²). 통제변인은 출발지점·실내온도·표면 거칠기·재질. 각도계·줄자·스톱워치(혹은 스마트폰 슬로우모션 240fps)로 정지거리·시간 측정 준비. 표면 거칠기는 사포 #240으로 일관 처리.✓ 완성품: 실험 세팅 사진 + 변인 표 1장.
  2. 3가지 모델 수식 정리 (손계산)⏱ 1~2h
    모델 A(미끄럼만): μ_k = tanθ - a/(g·cosθ). 모델 B(회전 관성 보정): 구의 경우 a = (5/7)·g·sinθ, 원기둥은 a = (2/3)·g·sinθ로 Hooke 식 응용 → 같은 a라도 마찰 비교가 달라짐. 모델 C(공기저항): F_drag = ½ρCdAv² 추가. 세 모델의 가정 차이를 한 표로 정리.✓ 완성품: 모델 A·B·C 수식 비교 표 1쪽.
  3. 각도 3종 × 시료 3종 × 5회 반복 측정⏱ 2~3h
    각 조합 5회 반복 = 45회 측정. Google Sheets에 각도 / 시료 / 회차 / 정지거리 / 정지시간 입력. Colab에서 모델 A·B·C 예측값 산출 후 잔차 = 실측 - 예측 막대그래프. 모델별 RMSE 계산:
    rmse = np.sqrt(np.mean((y_obs - y_pred)**2))
    "오차의 약 ?%가 회전 관성에서 온다"를 정량적 한 줄로.✓ 완성품: 측정표 1장 + 모델별 잔차 그래프 3장 + RMSE 표.
  4. 오차 모델 보고서 + 1학년 수학 약점 덮기⏱ 2~3h
    A4 2쪽: 실험 동기(2학년 빗면 측정의 한계) → 모델 A·B·C 비교 → 실측 vs 예측 잔차 분석 → "나는 오차를 모델로 푸는 학생"이라는 결론 한 단락. 한국물리학회 물리교육에서 회전 관성 학생 실험 1편 + RISS rolling friction inclined plane 영문 1편 인용. 물리샘께 5분 면담으로 회전 운동 식 점검.✓ 완성품: A4 2쪽 보고서. 1학년 수학 약점을 '정밀 모델링' 강점으로 전환하는 결정타.
