💊 1. 약물 반감기 → 다회 투약·환자 변동성 시뮬레이션 (수학Ⅰ 다음 단계)

난이도 ★★☆ 2~3주 키워드 연결: 약동학·임상통계·임상의학
💗 왜 윤찬이에게? 2학년 수학Ⅰ에서 타이레놀 일반형(반감기 4h)·이알형(반감기 8h) 단일 투약 곡선까지는 그렸지만, 다회 투약·신장/간 기능 보정은 가본 적이 없어. 인공지능 기초 A·기하 A의 정량 역량과 정확히 만나는 영역이고, 임상의가 가장 자주 마주치는 '복용 간격·용량 결정'에 직결. 의대 면접의 "약을 어떻게 정밀하게 줄까"에 본인 그래프로 답할 수 있게 돼, 윤찬아.

📚 알아두면 좋은 핵심 이론

  • 반감기(Half-life): 체내 약물 농도가 절반으로 줄어드는 데 걸리는 시간. 약물마다 고유의 값이고, 투약 간격을 정하는 가장 중요한 숫자야.
  • 1차 약동학 모델: C(t)=C₀·e^(-kt). "남은 양에 비례해 사라진다"는 가장 기본 모델 — 수학Ⅰ 지수함수의 임상 버전.
  • 정상상태(Steady State): 다회 투약에서 들어오는 양과 빠져나가는 양이 같아져 농도가 안정화되는 구간. 보통 반감기의 4~5배 시간 후 도달.
  • Cmax / Cmin / 축적계수: 최고/최저 농도와 다회 투약 시 축적 비율. Cmax 너무 높으면 독성, Cmin 너무 낮으면 효과 × — 이 균형이 임상의 핵심.
  • 근거중심의학 EBM·95% CI: 효과 추정에는 점추정뿐 아니라 95% 신뢰구간을 함께 보고하는 것 — 면접에서 "이 차이가 의미 있다고 본 근거"를 말할 때 쓰는 단어.

A. 실험형 / 실천형

  • Python·엑셀로 1차 약동학 C(t)=C₀·e^(-kt) 다회 투약 시뮬레이터 작성
  • 변수: 반감기(4·8·12h) × 복용간격(6·8·12h) × 클리어런스 보정
  • 정상상태 농도·Cmax/Cmin·축적계수 그래프 9장 비교
  • 아세트아미노펜·이부프로펜 등 일반의약품 2종 실제 데이터로 검증, 1쪽 인포그래픽 산출

B. 문헌형

  • 대한의학회지·KCI '임상약물동력학' 키워드
  • 약학정보원·식약처 의약품 허가정보의 반감기·청소율 공시 자료
  • 치료적 약물 모니터링(TDM) 가이드라인(반코마이신·디곡신)
  • 단행본: '쉽게 배우는 약물동력학' 1·2장

🚀 어떻게 시작하면 될까

  1. 약학정보원에서 한 약의 반감기 찾기⏱ 30분
    약학정보원(health.kr) 접속 → 상단 "의약품 검색" → 아세트아미노펜 입력 → 결과의 "약리정보" 또는 "허가사항" 탭에서 반감기(half-life) 항목을 찾아 메모. 보통 2~3시간으로 표기됨. 식약처 의약품안전나라(nedrug.mfds.go.kr)도 같은 정보 제공.✓ 완성품: "아세트아미노펜 반감기 = 2.5h" 한 줄 메모. 이 숫자가 모든 계산의 출발점.
  2. Colab에서 단일 투약 농도 곡선 그리기⏱ 30~60분
    Google Colab(colab.research.google.com)에 새 노트북 → 다음 코드 입력:
    import numpy as np, matplotlib.pyplot as plt
    t = np.linspace(0, 24, 240)
    k = np.log(2) / 2.5 # 반감기 2.5h → 분해상수
    C = 100 * np.exp(-k*t) # 초기농도 100mg
    plt.plot(t, C); plt.xlabel('Time (h)'); plt.ylabel('C (mg/L)')
    2학년 수학Ⅰ에서 그렸던 타이레놀 일반형(4h)·이알형(8h)도 같은 코드로 두 줄 겹쳐 그려보기. 반감기를 4·8·12h로 바꿔 그래프 3장 비교.✓ 완성품: 단일 투약 농도-시간 곡선 .png 3장 + 코드 .ipynb.
  3. 다회 투약 시뮬레이션 — 정상상태 도달 관찰⏱ 1~2h
    for 루프로 일정 간격 반복 투약을 더해보기:
    doses = [0, 6, 12, 18, 24, 30, 36, 42, 48] # 6h 간격
    C_total = np.zeros_like(t)
    for d in doses:
      mask = t >= d
      C_total[mask] += 100 * np.exp(-k*(t[mask]-d))
    그래프에서 정상상태(steady state)가 보이는 순간을 직접 확인. 변수 조합: 반감기 3종 × 복용간격 3종 → 그래프 9장 + Cmax/Cmin 표 1장.✓ 완성품: 다회 투약 그래프 9장 + Cmax/Cmin/축적계수 산출 표 1장.
  4. 임상 투약 매뉴얼 A4 1쪽으로 정리⏱ 1~2h
    표 형식 약물명 / 반감기 / 권장 간격 / Cmax / 위험 신호로 일반의약품 3~5종 정리. 마지막 단락에 "신장 기능 30% 저하 환자라면 간격을 어떻게 늘릴까?"를 본인 답으로 한 단락. 수학 교과샘께 그래프 해석 한 번 점검 받기.✓ 완성품: A4 1쪽 매뉴얼. 의대 면접 핵심 자료로 직결.

🦠 2. 미세플라스틱·생물막·항생제 내성 — 과제연구 후속 메타·실측

난이도 ★★☆ 3~4주 키워드 연결: 항생제 내성·생물막·임상감염
💗 왜 윤찬이에게? 2학년 과학과제 연구의 "미세플라스틱이 주변 세균의 생물막 형성을 도와 항생제 내성을 높인다"는 본인 가설 — 거기서 한 단계 더 깊게 가져가는 카드야. 임상감염내과의 가장 뜨거운 주제(MDRO·MRSA)와 직결되고, 동아리에서 다룬 알파폴드·단백질 구조-기능 시각까지 합치면 같은 의대 지원자 중에서도 매우 단단한 한 줄이 돼, 윤찬아.

📚 알아두면 좋은 핵심 이론

  • 생물막(Biofilm): 세균이 분비하는 세포외기질 안에 군집을 이루는 형태. 이 안에선 항생제 농도가 같아도 효과가 10~1000배 떨어져.
  • 항생제 내성(AMR): 본래 효과 있던 항생제가 듣지 않게 되는 현상. WHO가 21세기 최대 보건위협으로 지정한 임상의학 핵심 키워드.
  • MIC(최소억제농도): 세균 성장을 막는 가장 낮은 항생제 농도. 임상에서 항생제 선택의 기준 — '단순 평균'이 아니라 95% CI까지 함께 보는 게 표준.
  • QS(Quorum Sensing): 세균이 농도 신호를 주고받아 생물막 형성을 켜는 통신 시스템. 신약 개발의 새 표적.
  • EBM·메타분석: 여러 연구의 효과 크기를 종합해 결론을 내는 방식. "내가 본 1편"보다 "5편 종합"이 임상 의사결정의 표준 — 의대 지원자에게 가장 매력적인 단어.

A. 실험형 / 실천형

  • 인공 미세플라스틱(PE 분말) 농도 3종 × 일반 세균 모델(Bacillus subtilis 등 안전종) 한천 배양
  • 크리스탈바이올렛 염색법으로 생물막 두께 정량(이미지 분석 또는 OD 측정)
  • 일반 항균 대조군과 비교해 MIC 변화 관찰
  • '미세플라스틱 → 생물막 → AMR' 1쪽 인포그래픽 산출

B. 문헌형

  • NCBI PubMed (microplastic biofilm antibiotic resistance) 5편 메타표
  • 대한의학회지·KCI '항생제 내성 생물막' 키워드
  • WHO Global Action Plan on AMR 보고서
  • 단행본: '면역에 관하여(율라 비스)' + '인수공통 모든 전염병의 열쇠'

🚀 어떻게 시작하면 될까

  1. NCBI PubMed에서 5편 메타 비교 표 만들기⏱ 2~3h
    PubMed(pubmed.ncbi.nlm.nih.gov) 접속 → 검색창에 microplastic biofilm antibiotic resistance 입력 → 최근 5년 리뷰·실험 논문 5편 선택. Abstract만 읽고 표 작성: 연구(저자·연도) / 미세플라스틱 종류·농도 / 균주 / MIC 변화 / 효과 크기·95% CI. KCI(kci.go.kr)에서 국문 1편 추가.✓ 완성품: A4 1쪽 메타 비교 표. 본인 가설을 메타근거로 받쳐주는 핵심 자료.
  2. 크리스탈바이올렛 생물막 정량 실험 1라운드⏱ 3~4h(2일 분산)
    96-well 플레이트에 안전종(B. subtilis) 배양 → PE 분말 0/0.1/1 mg/mL 3조건 × 3반복 → 24h 후 0.1% 크리스탈바이올렛 5분 염색 → 70% 에탄올로 가용화 → OD590 측정. 학교 과학실 또는 인근 대학 부설 실험실(과학과제 연구 때 협력처) 활용. 안전 가이드: 생물안전 1단계 균주만 사용, 실험복·장갑 필수.✓ 완성품: 농도별 OD 막대그래프 + 평균±95% CI 표 1장.
  3. Colab에서 단백질 구조 시각화로 깊이 더하기⏱ 1~2h
    알파폴드 DB(alphafold.ebi.ac.uk) 또는 PyMOL 무료 학생판으로 생물막 핵심 단백질(예: LuxS 또는 SinR) 구조 다운로드 → α나선·β시트 어노테이션 → "이 부위가 QS 신호 결합" 화살표 추가. 동아리 알파폴드 활동에서 익힌 GLUT4 시각화 그대로 재사용 — 30분 만에 한 장 완성.✓ 완성품: 생물막 핵심 단백질 3D 구조 .png 1장 + 결합 부위 어노테이션.
  4. '미세플라스틱 → AMR' 인포그래픽 + 보건샘 면담⏱ 2~3h
    Canva(canva.com) 또는 미리캔버스(miricanvas.com)에서 A4 1매. 구조: 환경 노출(미세플라스틱) → 생물막 강화(QS 활성) → MIC 상승(AMR) → 임상 영향(MDRO 증가). 보건샘 또는 화학·생명샘께 5~10분 면담으로 검토. 학급·보건실 게시판 공유까지 가면 '발(실천)' 단계 채움.✓ 완성품: A4 인포그래픽 1매 + 교과샘 피드백 메모. 의대 면접 'Why 의학·왜 감염내과'의 직접 답변 자료.

🦷 3. 법랑질 마모 다항함수 모델 → 임상 예방치의학 매뉴얼

난이도 ★☆☆ 2~3주(분산) 키워드 연결: 예방치의학·항상성·근거중심의학
💗 왜 윤찬이에게? 2학년 수학Ⅱ에서 직접 만든 "치아 법랑질 두께 감소 다항함수 모델" + 진로활동의 잇몸주머니 바이오필름 아이디어 — 두 활동을 한 임상 시나리오(예방치의학 매뉴얼)로 합치면 본인 색이 또렷해져. 실험 부담이 적어 3학년 시기에 가장 안전한 카드이고, 의대 면접의 단골 질문 "왜 임상의인가?"에 본인 그래프와 다이어그램으로 답할 수 있게 돼, 윤찬아.

📚 알아두면 좋은 핵심 이론

  • 법랑질 탈회·재광화: pH 5.5 이하에서 칼슘·인산 이온이 빠져나가고(탈회), 침의 중화 작용으로 다시 채워지는(재광화) 동적 평형 — 항상성 피드백의 구강 버전.
  • 다항함수 모델링: 시간에 따른 두께 변화를 t·t²·t³ 항으로 근사하는 방법. 수학Ⅱ에서 본인이 이미 사용한 도구를 임상 데이터에 다시 적용.
  • EBM·95% CI: "한 사례"가 아니라 "여러 연구의 평균±신뢰구간"으로 결론을 말하는 방식. 예방치의학 가이드라인의 표준 언어.
  • 구강 바이오필름·QS: S. mutans가 분비하는 산이 법랑질 탈회의 직접 원인. 칫솔질·스케일링은 물리적 제거, 클로르헥시딘은 화학적 억제.
  • 예방치의학 4단계: 1차(불소·식이) → 2차(스케일링·실란트) → 3차(수복) → 4차(보철). 의대 가이드라인의 의사결정 프레임 그대로.

A. 실험형 / 실천형

  • 본인의 수학Ⅱ 다항함수 모델을 다양한 pH 조건(콜라·오렌지주스·물) 실측 데이터로 보정
  • 달걀껍질을 법랑질 대용으로 24·48·72h 침지 → 무게 변화·이미지 분석
  • 다항함수 계수 비교 표 (음료별 마모 속도)
  • 학급·보건실 공유용 1쪽 구강건강 카드 제작

B. 문헌형

  • NCBI PubMed (enamel erosion polynomial kinetics) 5편 메타표
  • 대한치의학회지·KCI '법랑질 탈회 재광화' 키워드

🚀 어떻게 시작하면 될까

  1. 본인 수학Ⅱ 모델을 Colab에 다시 옮기기⏱ 1h
    2학년 수학Ⅱ 보고서의 다항함수 식을 Google Colab(colab.research.google.com)에 입력. 예: thickness = a0 - a1*t - a2*t**2 형태로 정리하고 본인이 잡았던 계수 a0·a1·a2를 그대로 사용. 시간 0~72h 그래프 1장 그리고, 변곡점·1차 미분(마모 속도) 함수까지 추가. 본인 작년 모델이 임상에 어떻게 연결되는지 한 단락 메모.✓ 완성품: 작년 모델 .ipynb 재현 + 마모 속도 함수 그래프 1장.
  2. 달걀껍질 침지 실험 — 음료 3종 × 시간 3종⏱ 3~4h(3일 분산)
    달걀껍질 9조각 무게 측정(0.001g 저울) → 콜라·오렌지주스·물 3컵에 24·48·72h 침지 → 매일 꺼내 무게·표면 사진 기록. 식초로 가속 실험을 추가하면 효과 더 또렷. pandas.DataFrame으로 데이터 정리 → numpy.polyfit(t, mass, 2)로 2차 다항 fitting → 본인 작년 모델과 계수 비교 표.✓ 완성품: 음료별 무게 감소 그래프 + 다항 계수 비교 표 1장.
  3. NCBI PubMed·KCI 5편 메타 비교 표⏱ 2~3h
    PubMed(pubmed.ncbi.nlm.nih.gov) 검색 키워드 enamel erosion polynomial · tooth demineralization kinetics. KCI(kci.go.kr)에서 '법랑질 탈회' 국문 2편 추가. 5편의 결과를 표로 정리: 연구(저자·연도) / 음료·산 / 노출 시간 / 두께 변화율 / 95% CI. 본인 실험 데이터를 같은 표 한 줄로 추가하면 메타 안에 본인 자리 만드는 효과.✓ 완성품: A4 1쪽 메타 비교 표 (본인 데이터 1행 포함).
  4. 예방치의학 매뉴얼 A4 1쪽 + 보건샘 면담⏱ 2h
    Canva(canva.com) 또는 미리캔버스(miricanvas.com)에서 A4 1매. 구조: 탈회 시작(pH 5.5) → 다항함수 두께 감소 → 재광화 한계 → 예방 전략(불소·식이·스케일링). 보건샘 또는 수학·화학샘께 5~10분 면담으로 검토 받고 학급 공유. 의대 면접에서 "수학을 임상에 어떻게 쓸 거냐"의 직답이 됨.✓ 완성품: A4 예방치의학 매뉴얼 1매 + 교과샘 피드백 메모.
