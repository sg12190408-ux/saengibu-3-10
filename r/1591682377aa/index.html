연료감응형 태양전지 — 변인 분석으로 본 구조-출력 인과

"초기 낮은 광전 효율을 단순 오차로 보지 않고, TiO₂ 층의 소결 상태와 염료 흡착 정도를 중심으로 원인을 분석함. 조건을 달리한 실험을 분담해 데이터를 비교·분석하고, 전해질 누액 방지를 위한 밀봉 공정의 중요성을 도출함. 구조적 정밀성이 출력 효율에 직결됨을 체험하고 전하 재결합 억제까지 탐구."

✨ '재료의 미세 구조 → 기계 출력 성능'이 한 실험 안에서 인과로 묶여. 너의 진로 전환(재료→기계)이 '단절'이 아니라 '심화'였다는 가장 강한 증거.
🟢 동아리·과제연구 · 2학년 패턴 ① + ③ 호기심·탐구형

중화반응 열역학 — 무선센서·열량계 보정으로 정량 검증

"중화 반응 연계 열역학 실험에서 리더조로서 출입하는 열의 총합이 일정함을 정량 검증. 예비 실험을 반복 수행해 변수와 도구 작동에서 발생하는 오차 요인을 파악하고, 무선 센서 기반 온도 데이터 분석으로 실측값 재현성과 신뢰도를 높임. 열 손실·수산화나트륨 조해성을 점검하고 열량계 열용량과 보정식을 적용한 개선 방안을 제안."

✨ '오차를 무시하지 않고 식으로 보정'까지 간 사례. 기계공학에서 가장 중요한 '측정-보정 사이클'을 고2 단계에 한 번 완주한 게 진짜 무기.
🟢 진로활동 · 2학년 패턴 ② 키워드 연계형

"기계공학·항공우주에 대한 진로 의식을 바탕으로 발사체 엔진 개발을 중심으로 공학자의 역할을 구체적으로 탐색. 로켓 엔진·우주 탐사 자동화를 조사하며 항공우주 기술이 물리·화학·수학·정보과학이 융합된 분야임을 인식. 화성 탐사·달 탐사 계획을 분석하며 우주 탐사가 국가 전략·기술 경쟁과 연결됨을 이해."

✨ 진로 전환 이후 흩어질 수 있는 활동들을 '발사체 엔진'이라는 한 키워드로 묶어준 결정적 한 컷. 같은 기계공학과 지원자 중에서도 차별점.

🚀 1. 발사체 노즐 재료의 열적 한계 — 재료-기계 융합 탐구

난이도 ★★☆ 3~4주 키워드 연결: 발사체·재료-기계 융합·동역학
💚 왜 형서에게? 1학년 재료·나노 실험 + 2학년 발사체 엔진 진로탐구 + 물리학Ⅰ 로켓 운동량 인포그래픽까지, 흩어진 활동 셋이 '노즐 재료'라는 한 핵심 부품으로 합쳐져. 진로 전환이 단절이 아니라 심화였다는 걸 한 보고서로 보여줄 수 있어.

📚 알아두면 좋은 핵심 이론

  • De Laval 노즐: 수축-확장 형상으로 연소가스를 초음속으로 가속해 추력을 만드는 핵심 부품. 발사체 엔진의 심장이야.
  • 비추력(Specific Impulse, Isp): 같은 연료로 얼마나 효율적으로 추력을 내는지의 척도(초 단위). 노즐 효율과 직결돼 — 항공우주 면접 단골 키워드.
  • 비강도(Specific Strength): 강도/밀도 비율. 발사체는 가벼울수록 유리 — '강한데 가벼운 재료'가 곧 성능.
  • 열피로(Thermal Fatigue) / SN곡선: 가열-냉각 반복으로 누적되는 손상. 재사용 발사체 시대의 핵심 설계 변수.
  • 재생냉각(Regenerative Cooling): 연료를 노즐 벽 안쪽으로 흘려 냉각 후 연소실로 보내는 기법. 누리호 75톤급 엔진의 핵심.

A. 실험형 / 실천형

  • 액체로켓 노즐의 후보 재료 3종 비교: 인코넬·구리합금·세라믹 매트릭스 복합재(CMC)
  • 각 재료의 융점·열전도율·열팽창계수·비강도를 표로 정리
  • 고전 노즐(De Laval) 식으로 출구 속도·추력 계산 후 재료 한계 온도 대입
  • 1쪽 인포그래픽 '재료 선택이 추력에 미치는 영향'으로 산출

B. 문헌형

  • DBpia·RISS '액체로켓 노즐 재료', 'rocket nozzle material thermal'
  • 한국항공우주연구원(KARI) 누리호·차세대 발사체 기술 보고서
  • 대한기계학회지·한국추진공학회지의 노즐 냉각·재생냉각 사례
  • 단행본: '로켓 추진공학(Sutton)' 노즐 챕터 일부

🚀 어떻게 시작하면 될까

  1. KARI 보고서 1건으로 노즐 재료 후보 확정⏱ 1h
    한국항공우주연구원(kari.re.kr) 또는 KCI(kci.go.kr)에서 누리호 연소기 재료 또는 액체로켓 노즐 인코넬로 검색 → 보고서·논문 1건 PDF 저장. 후보 3종(인코넬718·구리합금GRCop-84·CMC) 골라 재료 / 융점 / 열전도율 / 비강도 / 출처 표로 정리.✓ 완성품: A4 반쪽 재료 비교표 1장. 모든 계산의 기준선.
  2. Excel/LTspice 대신 Excel로 De Laval 출구속도·추력 계산⏱ 1~2h
    Excel 새 시트 → 셀에 직접 수식: 출구속도 v_e = sqrt(2·k/(k-1)·R·T_c·(1-(P_e/P_c)^((k-1)/k))), 추력 F = m_dot·v_e. 변수: 연소실 온도 T_c를 2500·3000·3500K로 바꿔 출구속도 계산. 비추력 Isp = v_e/g도 같이 산출.✓ 완성품: 온도 3종 × 압력비 3종 = 9개 셀 매트릭스 + Isp 그래프 1장.
  3. 재료 한계 온도 대입 → '진짜 가능한 추력' 한 줄⏱ 1h
    2단계 표에 재료별 사용한계 온도 입력(인코넬 ~1200K·구리합금 ~700K·CMC ~1800K). 재생냉각으로 벽면 온도를 낮출 수 있다는 가정도 한 줄 추가. 본인 답: "재료가 추력 상한을 정한다"를 한 줄 결론 + 그래프 1장으로.✓ 완성품: 재료별 도달 가능 추력 비교 그래프 1장 + 결론 한 단락.
  4. '재료 선택이 추력에 미치는 영향' A4 인포그래픽⏱ 2~3h
    Canva(canva.com)·미리캔버스(miricanvas.com) A4 1매. 구조: 발사체 임무 → 노즐 조건(T·P) → 재료 3종 비교 → 한계 온도 대입 → 최적 선택 근거. 물리·기술가정 선생님께 5분 검토 받기.✓ 완성품: A4 인포그래픽 1매 + 보고서 6쪽. 면접 핵심 자료.

· KARI (kari.re.kr) — 누리호 기술자료
· KCI (kci.go.kr) · 한국추진공학회지
· Canva (canva.com)

⚙️ 2. 베르누이에서 양력까지 — 1학년 자율탐구의 기계공학 후속편

난이도 ★☆☆ 2~3주 키워드 연결: 동역학·항공기 날개·메커니즘
💚 왜 형서에게? 1학년 자율활동 '베르누이 원리 실험'을 2학년에 한 번 더 깊게 가져가본 적은 없어. 같은 주제를 1→3학년으로 잇는 흐름이라 '키워드 수직 연계'가 완성돼. 항공우주 진로에 직결.

📚 알아두면 좋은 핵심 이론

  • 베르누이 정리: P + ½ρv² + ρgh = 일정. 속도가 빠를수록 압력이 낮아진다는 유체역학의 출발점.
  • 받음각(Angle of Attack, AoA): 날개 시위선과 공기 흐름이 이루는 각. 이 각이 양력의 크기를 결정해.
  • 실속(Stall): 받음각이 임계값(보통 15°)을 넘으면 양력이 급격히 감소하는 현상. 항공기 사고의 단골 원인.
  • NACA 익형: 미국 NASA 전신이 정한 표준 날개 단면 코드(예: NACA 0012 = 두께 12% 대칭형). 항공우주의 공통 언어.
  • CFD(전산유체역학): 컴퓨터로 유동을 시뮬레이션하는 분야. 풍동 실험과 한 쌍으로 항공우주 설계의 양 축.

A. 실험형 / 실천형

  • 저비용 풍동(드라이어+종이 박스) 자작 + 종이 날개(NACA 0012 등) 3D 프린팅
  • 받음각(0°·5°·10°·15°) 변화에 따른 양력 변화를 디지털 저울로 측정
  • 아두이노 압력 센서로 표면 정압 분포 측정 → 베르누이 식과 비교
  • 실속 발생 각도·표면 거칠기 영향까지 정량 보고서로 산출

B. 문헌형

  • DBpia·RISS '익형 양력 받음각', 'airfoil lift angle of attack'
  • 한국항공우주학회지의 풍동 실험 표준 가이드
  • 한국과학창의재단 '청소년 항공·우주 탐구' 자료
  • 단행본: '비행의 원리(존 D. 앤더슨)' 도입부

🚀 어떻게 시작하면 될까

  1. NACA 0012 익형 도면 → Tinkercad에서 모델링⏱ 1h
    구글에서 NACA 0012 coordinates 검색 → 좌표 .dat 파일 다운로드. Tinkercad(tinkercad.com)에서 좌표 따라 단면 그리고 길이 100mm로 압출 → STL 저장. 시위(chord) 80mm·스팬 100mm 권장.✓ 완성품: NACA 0012 STL 파일 1개. 3D 프린팅 출력 의뢰.
  2. 저비용 풍동 + 디지털 저울 측정 세팅⏱ 1~2h
    박스 + 드라이어(저속·냉풍) → 출구에 0.001g 디지털 저울. 날개를 가는 봉으로 저울 위에 고정 → 받음각 0°·5°·10°·15°·18°로 5케이스 측정. 풍속은 아두이노 풍속 센서(MH-Z19 대신 Wind sensor Rev.P)로 기록.✓ 완성품: 받음각-양력 데이터 표 5행 + 사진 5장.
  3. Excel로 양력계수 Cl 계산 + 실속점 찾기⏱ 1h
    Excel에 Cl = 2L/(ρv²S) 공식 입력. ρ=1.225, v=풍속 측정값, S=시위×스팬. 받음각 vs Cl 그래프를 그려 실속 직전 최대 Cl을 표시. 이론치(얇은 날개 이론 Cl = 2π·α)와 한 그래프에 같이 그려 비교.✓ 완성품: 실험 vs 이론 양력계수 그래프 1장 + 실속각 한 줄 결론.
  4. '1→3학년 베르누이 후속편' 보고서 + 발표⏱ 2h
    구조: 1학년 베르누이 실험 회상 → 한계점 → 3학년 받음각·실속 측정 → 이론 vs 실험 차이 분석 → 다음 도전(CFD 시뮬레이션 OpenFOAM). 학급 5분 발표로 마무리.✓ 완성품: 보고서 5쪽 + 발표 슬라이드 7장. 면접 '연속성' 답변 자료.

· 아두이노 풍속·압력 센서
· 한국항공우주학회지 (ksas.or.kr)
· 단행본: 비행의 원리(존 D. 앤더슨) — 학교 도서관

🛠️ 3. 아두이노+3D 프린팅 메커니즘 — 동작 검증 1쇼케이스

난이도 ★★☆ 3~4주(분산) 키워드 연결: 메커니즘 자동화·재료 선택·정량 검증
💚 왜 형서에게? 2학년 지구과학Ⅰ 교과융합에서 아두이노+3D 프린팅 수질분석 장치 제작·여과 전후 비교까지 했어. 그 흐름을 '간단한 4절 링크 메커니즘' 또는 '소형 구동 장치'로 한 단계 더 가져가면 기계공학과 면접에서 가장 자주 묻는 '직접 만들어본 기계 장치'에 답할 수 있어.

📚 알아두면 좋은 핵심 이론

  • 4절 링크(Four-bar linkage): 4개의 강체 막대로 이루어진 가장 기본 메커니즘. 자동차 와이퍼·재봉틀·로봇팔의 출발점.
  • 그라쇼프 조건(Grashof's law): 가장 짧은 막대 + 가장 긴 막대 길이 합 ≤ 나머지 두 막대 합. 회전 가능 여부를 결정하는 황금 규칙.
  • 운동학 vs 동역학: 운동학은 '어떻게 움직이나'(궤적), 동역학은 '왜 움직이나'(힘·토크). 메커니즘 분석은 운동학부터.
  • 재료 피로도(SN곡선): 반복 하중으로 재료가 파손되는 한계. PLA는 충격에 약하고 PETG는 유연성·내구성이 균형, TPU는 탄성.
  • 서보모터 PWM 제어: 듀티비로 회전각을 지정하는 방식. 아두이노 Servo.h 라이브러리의 핵심.

A. 실천형

  • 4절 링크 또는 슬라이더-크랭크 메커니즘 1건 선정 → Tinkercad/Fusion 360에서 설계
  • 3D 프린팅 시 PLA·PETG·TPU 중 적합 재료를 직접 선택·근거 기록
  • 아두이노+서보모터로 동작 구현 → 의도한 궤적과 실제 궤적을 영상으로 비교
  • '재료 선택 → 메커니즘 → 동작' 1쪽 보고서, 학교 메이커 부스에 시연

B. 문헌형

  • DBpia '4절 링크 운동학', 'four-bar linkage kinematics'
  • 대한기계학회지의 메커니즘 설계 사례
  • 한국공학교육학회지의 '메이커 기반 기계공학 입문' 사례
  • 단행본: '기계요소설계 입문' 링크·캠 장 일부

🚀 어떻게 시작하면 될까

  1. 그라쇼프 조건으로 4절 링크 치수 정하기⏱ 1h
    막대 4개 길이를 30·60·70·80mm로 가정 → 그라쇼프 조건 검증: 30+80 ≤ 60+70 ? → 110 ≤ 130 ✓. Excel로 입력 각도 0~360°에서 출력 링크 각도 계산(코사인 법칙). 궤적이 닫힌 곡선인지 확인.✓ 완성품: 4절 링크 치수 표 1장 + 입력각-출력각 그래프 1장.
  2. Tinkercad → 4개 링크 STL + 핀 조인트 설계⏱ 2h
    Tinkercad(tinkercad.com)에서 막대 4개 모델링 → 양 끝에 3mm 구멍(M3 볼트용). 두께 5mm 권장. 베이스 플레이트(고정 막대용) 별도 출력. 재료는 PETG로(PLA보다 내충격·반복 동작 강함) — 근거 SN곡선 한 줄 메모.✓ 완성품: STL 파일 5개(링크4+베이스1) + 재료 선택 근거 한 단락.
  3. 아두이노+서보모터 동작 코드 작성⏱ 2~3h
    SG90 서보모터를 입력 링크에 연결 → 아두이노 코드:
    #include <Servo.h>
    Servo s; void setup(){s.attach(9);}
    void loop(){for(int a=0;a<180;a++){s.write(a);delay(15);}}
    스마트폰으로 동작 영상 촬영 → 의도한 궤적(1단계 그래프)과 실제 궤적(영상 프레임 좌표 추출)을 한 그래프로 비교.✓ 완성품: 동작 영상 30초 + 의도 vs 실제 궤적 비교 그래프 1장.
  4. 학교 메이커 부스 시연 + 1쪽 보고서⏱ 2h
