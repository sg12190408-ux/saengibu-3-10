🧬 1. USAG-1 단백질 억제 치아재생 — 알파폴드 구조 기반 메커니즘 분석

난이도 ★★★ 3~4주 키워드 연결: 유전공학·재생의학·단백질구조
💚 왜 상훈에게? 1학년 동아리에서 알파폴드로 단백질 접힘을 직접 다뤘고, 2학년 진로활동에서 USAG-1을 만남. 두 활동을 하나로 합치면 같은 유전생명공학 지원자 중 흔치 않은 차별점. 진로 전환 서사의 결정적 마무리 카드.

📚 알아두면 좋은 핵심 이론

  • USAG-1(SOSTDC1): BMP·Wnt 신호경로를 동시에 억제해 치아 발생을 막는 단백질. 이걸 막으면 잠자고 있던 '제3의 치아 싹'이 깨어난다는 게 토레천 항체의 핵심 가설.
  • BMP / Wnt 신호경로: 발생·재생을 지휘하는 두 갈래 신호. BMP는 "분화하라", Wnt는 "증식하라"에 가까워. USAG-1은 둘 모두에 브레이크를 걸어.
  • 알파폴드(AlphaFold) 단백질 구조 예측: 아미노산 서열만으로 3D 접힘을 추정하는 AI. 결합 부위(인터페이스)를 시각화하면 "왜 이 항체가 들어맞는지"가 한눈에 보여.
  • 단클론 항체 의약품: 표적 단백질에만 결합하는 정밀 무기. 토레천 항체(중외제약 일본 임상)는 USAG-1 표면의 BMP 결합 부위를 가린다는 가설이야.
  • 임상시험 단계(Phase 0~3): 안전성→소수 환자→대규모 효능. 한국 도입 가능성을 말하려면 지금 어느 단계인지를 정확히 짚어야 해.

A. 실험형 / 실천형

  • 알파폴드 DB(AlphaFold Protein Structure Database)에서 USAG-1(SOSTDC1) 구조 직접 시각화
  • BMP·Wnt 결합 부위를 단백질 표면 그림으로 표시 → 토레천 항체의 결합 부위 추정
  • 임상시험 Phase·한국 도입 가능성·윤리 쟁점까지 1쪽 인포그래픽
  • 학급·동아리 발표 자료로 산출 (실천 단계)

B. 문헌형

  • Murashima-Suginami et al. 'Anti-USAG-1 antibody'(Science Advances 2021) — PubMed 무료 접근
  • 대한구강생물학회지·대한치과의사협회지 '치아재생' 키워드 리뷰

  3. BMP·Wnt 결합 부위 추정 + 항체 작용 도식 만들기⏱ 2~3h

⚡ 2. 통증의 객관화 — AI 기반 통증 측정 모델 + 가상 데이터 시뮬레이션

난이도 ★★☆ 2~3주 키워드 연결: 통증의학·정밀의학·디지털헬스
💚 왜 상훈에게? 2학년 자율(테마학습 신체 변화 분석)·생명과학Ⅰ(중추감작)·진로활동(AI 기반 통증 관리 조사)·인공지능 기초(증상 입력 진단 모델)가 같은 줄에 있어. 단발 활동 4건이 한 시뮬레이션으로 합쳐지면 정밀의학 연구자 진로의 핵심 사례가 돼.

📚 알아두면 좋은 핵심 이론

  • 중추감작(Central Sensitization): 같은 자극에도 척수·뇌가 과민해져 통증이 증폭되는 현상. 만성통증의 핵심 메커니즘이고, 객관 측정이 어려운 이유 중 하나.
  • 심박변이도(HRV) / 피부전기활동(EDA): 자율신경 활성을 보여주는 두 대표 지표. HRV 감소·EDA 상승은 통증·스트레스의 생체 신호로 자주 쓰여.
  • 특징 공학(Feature Engineering): 원시 신호를 모델이 잘 학습하도록 RMSSD·SDNN 같은 통계량으로 변환하는 작업. 모델 성능보다 이게 더 중요할 때가 많아.
  • 회귀 vs 분류: 통증 강도(0~10) 예측은 회귀, '경미·중등·심함' 분류는 분류 문제. 같은 데이터로 두 방식 다 비교하면 모델 한계가 또렷이 보여.
  • 플라시보·문화차·개인차: 통증은 같은 자극에도 사람마다 다르게 보고됨. AI 객관화의 가장 큰 한계이자 윤리적 쟁점.

  2. Colab에서 가상 통증-HRV 데이터셋 1000명 분량 생성⏱ 1~2h
    Google Colab(colab.research.google.com)에서 새 노트북 → 다음 코드:
    import numpy as np, pandas as pd
    n = 1000
    pain = np.random.randint(0, 11, n) # 0~10 통증 강도
    hrv = 60 - 2*pain + np.random.normal(0, 5, n) # 통증↑ → HRV↓
    eda = 1 + 0.3*pain + np.random.normal(0, 0.4, n)
    df = pd.DataFrame({'pain':pain, 'HRV':hrv, 'EDA':eda})
    산점도(df.plot.scatter)로 통증-HRV·통증-EDA 관계 확인.✓ 완성품: 가상 데이터셋 .csv 1개 + 산점도 .png 2장 + .ipynb 코드.

    from sklearn.linear_model import LinearRegression
    from sklearn.tree import DecisionTreeClassifier
    X = df[['HRV','EDA']]; y = df['pain']
    ① 회귀: LinearRegression().fit(X, y).score(X, y) → R² 출력

🔬 3. 식물 노화에서 인간 세포 노화로 — 시토키닌 후속 메타리뷰

난이도 ★★☆ 3주(분산) 키워드 연결: 노화·재생의학·문헌 종합
💚 왜 상훈에게? 2학년 과학과제 연구에서 시토키닌 식물 노화 방지 실험을 직접 설계·수행했고, 자율활동에서 '노화 지연 물질' 조사로 확장한 단서가 이미 있어. 같은 주제를 식물→인간으로 확장하는 흐름이라 '키워드 수직 연계'가 1→3학년까지 이어져. 실험 부담이 적어 3학년 시기에 안전한 카드.

📚 알아두면 좋은 핵심 이론

  • 시토키닌(Cytokinin): 식물의 세포분열·노화 지연 호르몬. 잎의 황화(노란색화)를 늦추는 효과가 잘 알려져 있어.
  • 세포 노쇠(Cellular Senescence): 더 이상 분열하지 않지만 죽지도 않는 상태. 텔로미어 단축·DNA 손상이 주요 원인이고, 재생의학의 핵심 표적.
  • SASP(Senescence-Associated Secretory Phenotype): 노쇠 세포가 분비하는 염증성 인자 묶음. 주변 세포까지 노화시키는 '나쁜 이웃' 효과를 만들어.
  • 세놀리틱스(Senolytics): 노쇠 세포만 골라 제거하는 약물군(다사티닙·퀘르세틴 등). 동물실험에서 수명 연장이 확인된 정밀의학 신영역.
  • 식물·동물 공통 노화 신호: 활성산소(ROS)·후성유전 변화·텔로미어(동물)·종말체(식물 텔로미어 유사 구조). 두 계통의 보존된 메커니즘이 비교 메타리뷰의 핵심 축.

A. 실험형 / 실천형

  • 2학년 시토키닌 실험 데이터 재정리 → '식물 노화 지표 비교 표' 작성
  • 인간 세포 노화 마커(텔로미어·SASP·p16·p21) 비교 표로 확장
  • '식물·동물 노화 메커니즘 공통점·차이점' 1쪽 인포그래픽
  • 학급·동아리·진로활동에서 공유 (실천 단계)

  • Cell·Nature Reviews Molecular Cell Biology의 senescence 리뷰(요약본)

    2학년 과학과제 연구 보고서·사진·측정값을 한 폴더에 모으기. Google Sheets에 표 작성: 처리 농도 / 잎 황화율 / 엽록소 함량 / 관찰일. 변인 통제(반투막 부피 정량화 경험 활용)가 잘 된 데이터인지 본인 손으로 다시 점검. 한 줄 메모: "이 실험에서 나온 결론 한 문장."✓ 완성품: 식물 노화 지표 비교 표 A4 반쪽 + 결론 한 문장. 인간 세포 노화로 확장하는 다리.
  2. 한국생명공학연구원·KCI에서 인간 세포 노화 마커 5개 조사⏱ 2h
    한국생명공학연구원(kribb.re.kr) 자료실 + KCI(kci.go.kr)에서 세포 노쇠 · 텔로미어 · SASP 검색. 한국생화학분자생물학회 생화학학회지 리뷰 1~2편 다운로드. 마커 5개 카드: 마커명 / 측정 방법 / 의미(노쇠 진행 여부) / 조절 약물. 후보: 텔로미어 길이·p16INK4a·p21·SA-β-gal·SASP 인자.✓ 완성품: 인간 세포 노화 마커 카드 5장(A4 1매에 정리).
  3. 식물 vs 동물 노화 메커니즘 메타 비교 표 + 다이어그램⏱ 3~4h
    KISTI ScienceON(scienceon.kisti.re.kr)에서 plant animal senescence comparison 검색 → 영문 리뷰 1편 + 국내 논문 2편. 표 작성: 요인 / 식물(시토키닌·ROS·종말체) / 동물(텔로미어·SASP·세놀리틱스). 그 위에 공통 신호(ROS·후성유전)를 별표로 강조. 본인이 발견한 의미 있는 차이 한 단락 작성.✓ 완성품: A4 1쪽 메타 비교 표 + 식물·동물 노화 신호 다이어그램 1쪽 + 본인 해석 한 단락.
  4. 인포그래픽 A4 1매 + 동아리·진로활동 공유⏱ 2~3h
    Canva(canva.com) 또는 미리캔버스(miricanvas.com)에서 A4 1매. 구조: 1학년·2학년 실험(시토키닌) → 식물 노화 지표 → 인간 세포 노쇠 마커 → 공통 메커니즘(ROS·후성유전) → 재생의학에 주는 시사점. 동아리·진로활동에서 발표하고 세특에 기록 요청. 생명과학샘께 검토 받기.✓ 완성품: A4 인포그래픽 1매 + 발표 7분 자료. 면접 '식물→인간 확장' 서사의 마무리.
