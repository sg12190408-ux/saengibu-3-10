다음 학기 탐구 퀘스트 3

너의 키워드를 한 단계 더 깊게 가져갈 탐구 3종.

🤖 1. AGV·로봇 경로 최적화 시뮬레이션 (택시기하 + 그래프 알고리즘)

난이도 ★★★ 3주 키워드 연결: 스마트팩토리·전자공학·시뮬레이션
🌱 왜 민찬이에게? 2학년 기하 세특에 'AGV의 경로 설계를 벡터로 모델링·내적·삼각함수로 장애물 회피 분석'을 이미 한 줄 적어놨어. 그 활동의 후속편으로 가면 1학년 변압기·항온기 → 2학년 디지털 트윈 → 3학년 시뮬레이션의 수직 연계가 완성돼. 산업공학·반도체 진로의 핵심 키워드(스마트팩토리·물류 자동화·시뮬레이션) 정중앙이라 면접에서 "왜 산업공학인가"에 본인 코드와 그래프로 답할 수 있게 돼.

📚 알아두면 좋은 핵심 이론

  • AGV(Automated Guided Vehicle): 정해진 경로를 따라 자재·부품을 옮기는 무인 운반차. 반도체 fab·물류센터의 가장 흔한 자동화 장비.
  • 택시기하 vs 유클리드 거리: 격자 통로처럼 직각으로만 갈 수 있을 땐 |Δx|+|Δy|, 자유 이동이 가능하면 √(Δx²+Δy²). 공장 통로 설계의 출발점.
  • 다익스트라 / A* 알고리즘: 출발점→목표점 최단경로를 찾는 그래프 알고리즘. A*는 휴리스틱(예상 거리)을 더해 더 빠르게 찾아.
  • 처리량(Throughput) vs 리드타임(Lead Time): 단위시간당 운반 횟수와 한 작업이 끝나는 데 걸리는 시간. 산업공학의 두 핵심 KPI.
  • 디지털 트윈(Digital Twin): 실제 공장을 가상에 똑같이 복제해 미리 시뮬레이션·검증하는 기술. 본인 2학년 활동의 산업공학 버전.

A. 실험형 / 실천형

  • 교실·복도를 격자로 만들어 5×5 미니맵 작성 → 출발·목표·장애물 좌표 입력
  • Python으로 다익스트라 또는 A* 알고리즘 구현, 택시기하·유클리드 거리 두 모드 비교
  • 운영 효율 지표(이동시간·회전수)를 표·그래프로 정리 → '디지털 트윈 후속'으로 학급 동선에 적용

B. 문헌형

  • 대한산업공학회지 'AGV 경로 최적화' 논문 2~3편 정리
  • 물류센터 자동화 사례(쿠팡·SSG) 비교표 1쪽

🚀 어떻게 시작하면 될까

  1. 5×5 격자 미니맵 + 좌표 표 만들기⏱ 30분
    모눈종이 또는 Excel 시트에 5×5 격자 그리기 → 출발(S)·목표(G)·장애물(X) 위치를 좌표로 표기. 검색 키워드 AGV 경로 최적화·물류센터 layout으로 실제 공장 통로 사진 1장 찾아 어떻게 본인 격자에 매핑되는지 한 줄 메모.✓ 완성품: A4 반쪽 격자 지도 1장 + 좌표 표. 다음 단계 코드의 입력값.
  2. Colab에서 택시기하 vs 유클리드 거리 비교⏱ 1h

    import numpy as np
    def manhattan(p, q): return abs(p[0]-q[0]) + abs(p[1]-q[1])
    def euclidean(p, q): return np.sqrt((p[0]-q[0])**2 + (p[1]-q[1])**2)
    5×5 격자 모든 칸에서 목표까지 두 거리를 계산해 히트맵 2장(matplotlib.pyplot.imshow)으로 비교. "직각 통로에선 왜 택시기하가 옳은가" 한 단락 보고서.✓ 완성품: 거리 히트맵 .png 2장 + 코드 .ipynb 1개.
  3. A* 알고리즘 구현 → 최단경로 시각화⏱ 2~3h

  4. 학급 동선 적용 — 디지털 트윈 후속 1쪽⏱ 2h

📊 2. 분광광도계 흡광도 데이터 → 6시그마·SPC 통계적 공정관리

난이도 ★★☆ 2주 키워드 연결: 통계적 품질관리·데이터 기반 의사결정
🌱 왜 민찬이에게? 2학년 진로활동의 '음료 식용색소 분광광도계 측정'을 산업공학의 '6시그마·통계적 공정관리(SPC)'와 연결하는 후속편. 미세플라스틱 키토산 응집 실험과 같은 '실험→데이터→공정 개선' 흐름이라 본인 강점에 잘 맞아. 반도체 fab도 음료 공정도 같은 SPC 언어를 쓰니, 한 번 손에 익혀두면 산업공학·반도체 어디든 통하는 무기가 돼.

📚 알아두면 좋은 핵심 이론

  • SPC(통계적 공정관리, Statistical Process Control): 측정값을 시간 순서로 그려 공정이 안정한지 통계로 판단. 반도체·식품 공정의 공통 언어.
  • X-bar/R 관리도: X-bar는 표본 평균의 흐름, R은 표본 범위(최댓값-최솟값). 두 그래프를 같이 봐야 평균 변화와 산포 변화를 모두 잡을 수 있어.
  • 관리한계선(UCL/LCL): 평균 ± 3σ 위치의 점선. 점이 이 선을 벗어나거나 7개 연속 한쪽으로 치우치면 '이상 신호'.
  • 공정능력지수 Cp·Cpk: 규격 폭 대비 공정 산포의 비율. Cpk가 1.33 이상이면 양호, 6시그마 수준은 2.0 이상이라는 산업공학의 통화 단위.
  • 흡광도-농도 비례(Beer-Lambert): A=εbc. 흡광도가 농도에 비례하는 법칙으로, 분광광도계가 품질관리 실험실에서 표준 도구가 된 이유.

A. 실험형 / 실천형

  • 시판 음료 5종의 색소 흡광도 3회 반복 측정 → 평균·표준편차·관리도(X-bar/R chart) 작성
  • 표시값과 실제 측정값의 오차율을 산업공학의 '공차(tolerance)' 개념으로 해석
  • 이상치(out of control) 발생 시 원인 가설 수립

B. 문헌형

  • KOSHA·식품공전에서 색소 함량 관리 기준 조사
  • Montgomery, '통계적 품질관리(SPC)' 교재 1·2장 발췌 정리
  • 식품 공정 품질관리에 분광광도계가 쓰이는 사례 3건 정리

🚀 어떻게 시작하면 될까

  1. 측정 계획표 + 데이터 시트 만들기⏱ 30분
    Excel 또는 Google Sheets에 샘플 / 1회 / 2회 / 3회 / 평균 / 범위(R) 7열짜리 표 만들기. 음료 5종 × 반복 3회 = 15개 행. 검색 키워드 SPC 6시그마 X-bar R chart·반도체 공정 통계적 품질관리로 실제 산업 사례 2건 메모.✓ 완성품: 데이터 시트 1장 + 산업 사례 메모 한 단락.
  2. 분광광도계 흡광도 3회 반복 측정⏱ 1~2h
    학교 실험실에서 음료 5종의 같은 파장(예: 480 nm 황색 색소)에서 흡광도 3회 측정. 측정 사이 큐벳 세척 표준화. Excel 함수로 평균(=AVERAGE())·표준편차(=STDEV.S())·범위(=MAX()-MIN()) 자동 계산.✓ 완성품: 흡광도 원자료 + 평균·표준편차·범위 계산 시트.
  3. X-bar/R 관리도 작성 → 이상치 판정⏱ 1~2h
    Google Colab에서 다음 코드로 X-bar 관리도 그리기:
    import pandas as pd, matplotlib.pyplot as plt
    df = pd.read_csv('absorbance.csv')
    xbar = df.mean(axis=1); xbb = xbar.mean(); s = xbar.std()
    plt.plot(xbar, marker='o'); plt.axhline(xbb+3*s, ls='--')
    plt.axhline(xbb-3*s, ls='--')
    이상치(UCL/LCL 초과)와 7개 연속 같은 방향 패턴을 표시. 공정능력지수 Cpk = min(USL-μ, μ-LSL)/(3σ)도 함께 산출.✓ 완성품: X-bar/R 관리도 .png 2장 + Cpk 산출 표.
  4. "분광광도계로 본 SPC" 1쪽 보고서 + 반도체 확장 한 단락⏱ 1~2h
    발견한 이상치의 원인 가설 3개(샘플 농도 불균일, 큐벳 세척, 광원 변동) 작성. 마지막에 "같은 SPC가 반도체 식각·증착 공정에서 어떻게 쓰일지" 한 단락 — DBpia(dbpia.co.kr)에서 반도체 공정 SPC 검색해 사례 1건 인용. 화학·산업공학 교과샘께 결과 검토 받기.✓ 완성품: A4 1쪽 SPC 보고서 + 반도체 확장 한 단락. 진로 일관성 자료 직결.

💻 3. 디지털 트윈 후속 — 학급 에너지·동선 IoT 시뮬레이션

난이도 ★★★ 4주 키워드 연결: 디지털 트윈·IoT·AI 알고리즘
🌱 왜 민찬이에게? 2학년 디지털 트윈 + CPU 수명 예측 알고리즘을 직접 만든 본인 강점을 3학년에 한 번 더 살리는 활동. 산업공학의 '시뮬레이션·운영 최적화'에 딱 맞고, 머리·가슴·발 패턴 ⑥을 다시 한 번 채워. 반도체 fab의 "스마트팩토리"도 결국 IoT 센서 데이터로 디지털 트윈을 굴리는 거라, 학급 단위 미니 버전이 그대로 진로 연결 자료가 돼.

📚 알아두면 좋은 핵심 이론

  • 디지털 트윈(Digital Twin): 실제 시스템(공장·교실·도시)을 데이터로 똑같이 복제해 미리 시뮬레이션. 본인 2학년 학교 3D 모델의 산업공학 확장판.
  • IoT 센서·엣지 컴퓨팅: 온도·조도·전력 센서가 실시간으로 데이터를 수집하고, 클라우드 가기 전 엣지(현장)에서 1차 처리. 스마트팩토리의 신경망.
  • 회귀분석(Linear Regression): y=ax+b로 두 변수 관계 모델링. sklearn.linear_model.LinearRegression 한 줄이면 학교 공부의 그래프가 데이터 분석으로 바뀌어.
  • 예측 정비(Predictive Maintenance): 고장 나기 전에 미리 예측해 정비. 본인 'CPU 수명 예측 AI 알고리즘'이 산업공학에서 부르는 정확한 이름.
  • OEE(설비종합효율, Overall Equipment Effectiveness): 가동률 × 성능률 × 양품률. 스마트팩토리에서 한 설비의 건강 점수를 한 숫자로 표현하는 산업공학 KPI.

A. 실험형 / 실천형

  • 교실 온도·조도 데이터를 1주간 기록 (스마트폰 센서 앱 가능)

    df = pd.read_csv('classroom.csv')
