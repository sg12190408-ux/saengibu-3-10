너만의 키워드 3개

학종 평가의 한 가지 분명한 원칙: "한 키워드로 1→2→3학년이 이어지면 학종에서 최고점".

알고리즘·자료구조AI·머신러닝시스템·하드웨어 융합데이터 기반 최적화수학→코드 증명AI 윤리·공정성다익스트라이진 탐색아두이노 자율주행

키워드 수직 연계 — 학년별 깊이

알고리즘·자료구조AI·머신러닝시스템·하드웨어 융합
✨ 잘하고 있는 점: 1학년 진로희망에 '과학, 컴퓨터 공학' 두 갈래가 있던 게 2학년에 컴퓨터 공학으로 좁혀지면서 활동도 깔끔히 수렴됐어. 동아리 보고서에 '소프트웨어가 하드웨어 동작을 제어하는 핵심 요소임을 인식하고 자율 시스템 알고리즘을 심화하여 컴퓨터공학 전공의 진로 의지를 구체화함'이라고 본인 언어로 박혀 있는 게 핵심 증거. 이건 일관성 부족이 아니라 전환 이후 일관성 확보야. 알고리즘 키워드는 통합과학 다익스트라(1학년)→수학Ⅰ 이진 탐색·자율활동 메타휴리스틱(2학년)으로 이미 두 학년이 이어졌어. 🌱 다음 한 걸음: 3학년 활동 1개에 '알고리즘 또는 머신러닝'을 한 번 더 등장시키면 키워드가 1→3학년까지 수직으로 한 줄을 만들어 — 학종에서 가장 좋아하는 형태.

너의 베스트 모먼트 3

생기부에서 가장 잘 쓰인 문장 3개. 왜 좋은지를 우수 세특 패턴 분류로 풀어줄게.

🟢 자율활동·테마학습 · 2학년 패턴 ② 키워드 연계형 + ③ 호기심·탐구형

놀이공원 → TSP·메타휴리스틱·실시간 추천

"제한된 시간·자원에서 동선과 대기 시간 최소화 경로를 설계하며 정보과학의 활용 가치를 체감. 유전 알고리즘·시뮬레이티드 어닐링·개미집단 알고리즘과 다익스트라·플로이드-워셜·벨만-포드를 시간 복잡도 기준으로 비교해 적합한 알고리즘 선택 기준을 세우고, AI 기반 실시간 추천 시스템·TSP의 산업 적용까지 비판적으로 검토함."

✨ '실생활 문제 → 알고리즘 비교 → 시간 복잡도 분석 → 산업 적용'까지 한 사이클이 다 들어 있어. 컴퓨터공학과 평가자가 가장 좋아하는 깊이의 자율활동.
🟢 인공지능 기초 · 2학년 패턴 ① 동기·과정·결과·확장형

합성 데이터로 검증한 회귀 모델 — 데이터 분리 엄격성

"월별 수입·고정지출(식비·여가비·교통비)·비정기지출·저축에 따라 추정 순자산을 예측하는 회귀 모델을 직접 기획. 통계 자료와 AI로 합성 데이터를 만들어 선형회귀·랜덤 포레스트·신경망을 비교했고, 학습/검증 데이터를 엄격하게 분리해 결정계수로 성능을 비교함."

✨ 합성 데이터의 한계까지 의식하고 학습/검증 분리를 명시한 부분이 보석. 같은 인공지능 기초 수강자 중 흔치 않은 디테일이야.
🟢 영어Ⅱ · 2학년 패턴 ② 키워드 연계 + ⑤ 반성적 실마리형

감시 사회·알고리즘 윤리 영어 지문 직접 기획

"중국 사회신용 시스템·미국 예측형 범죄 데이터 편향 사례를 본문으로 구성하고, 결론에서 '감시가 일상화될 미래에서 알고리즘 개발자에게 윤리성이 요구된다'고 마무리. 미래 자신의 직무를 단순 개발자가 아닌 사회적 책임을 가진 기술 설계자로 여기며 성찰함."

✨ 컴공 진로 + AI 윤리 + 영어 직무 활용까지 한 활동에서 묶임. 영어 등급은 낮지만 세특 자체는 진로와 깊게 결합된 모범 사례.

🌱 왜 이 활동이 너에게 좋을까? 2학년 테마학습에서 '비교 검토'까지는 갔지만 직접 동일 입력으로 실측·시각화한 적은 없어. 자율활동에서 이미 '알고리즘 선택 기준'을 세웠던 흐름을 한 단계 더 깊게 끌어올리는 가장 자연스러운 후속편이야. 면접에서 "왜 컴공·AI인가?"에 "직접 돌려보고 시간·품질을 그래프로 보여드릴 수 있다"고 답할 수 있는 한 장이 손에 남아.

📚 알아두면 좋은 핵심 이론

  • NP-hard: 다항 시간 안에 최적해를 보장하는 알고리즘이 알려지지 않은 문제군. TSP가 대표 예시 — "정확히 풀려고 하지 말고 근사해라"의 출발점.
  • 유전 알고리즘(GA): 해 후보를 '염색체'로 보고 교차·돌연변이로 세대를 진화시키는 메타휴리스틱. 적합도(fitness) 함수 설계가 핵심.
  • 시뮬레이티드 어닐링(SA): 금속 냉각을 모방 — 초기에는 나쁜 해도 받아들이다 점차 보수적으로. 온도 스케줄이 성능의 절반.
  • 개미집단(ACO): 페로몬 누적·증발로 좋은 경로가 강화. 분산·병렬 친화적이라 산업 응용에 인기.
  • 해의 품질(Optimality Gap): (얻은 해 − 최적해) / 최적해 × 100%. "빠르지만 5% 손해"인지 "10배 느리지만 0.5% 손해"인지 정량 비교의 언어.

🤖 2. 회귀 모델 데이터 분리 검증 — 인공지능 기초 다음 단계

난이도 ★★☆ 2~3주 키워드 연결: AI·데이터 분리·공정성
🌱 왜 이 활동이 너에게 좋을까? 2학년 인공지능 기초에서 합성 데이터의 한계와 학습/검증 분리를 이미 의식하고 있었어. 한 단계 더 — 합성 데이터 vs 실제 공공 데이터, K-fold 교차검증, 특성 중요도까지 다뤄보면 진로선택 과목 성취도(A·97점)에 어울리는 깊이가 돼. 면접에서 "왜 너인가?"에 "합성 데이터 편향이 모델 일반화에 미친 영향을 직접 측정해봤다"고 답할 수 있어.

📚 알아두면 좋은 핵심 이론

  • K-fold 교차검증: 데이터를 K등분해 K번 돌려가며 학습·검증. 한 번 분리(train/test)의 운빨을 제거하는 가장 표준적인 방법.
  • 편향-분산 트레이드오프(Bias-Variance): 단순 모델은 편향↑·분산↓, 복잡 모델은 편향↓·분산↑. 일반화 오차의 출처를 두 축으로 분해하는 사고 틀.
  • 특성 중요도(Feature Importance): 트리 기반 모델이 분기에서 얼마나 자주·얼마나 큰 정보 이득으로 쓰였는지. "왜 이 예측인지"를 설명하는 1차 자료.
  • SHAP(Shapley): 협력 게임이론 기반 — 각 특성이 예측값에 기여한 양을 공정하게 분배. 특성 중요도보다 한 단계 깊은 모델 해석 도구.
  • 분포 편향(Distribution Shift): 학습 분포 ≠ 실제 분포일 때 모델 성능이 무너지는 현상. 합성 데이터 한계의 본질.

  • 합성 데이터의 분포 편향이 모델 일반화에 미친 영향을 그래프로 결론

🌱 왜 이 활동이 너에게 좋을까? 영어Ⅱ에서 알고리즘 윤리 지문을 직접 기획했고, 독서에서 콰인·비트겐슈타인을 빌려 AI 언어 모델의 사회적 편향을 다뤘어. 키워드 수직 연계 패턴 ②를 1→3학년까지 잇기 좋은 카드. 실험 부담이 적어 3학년 시기에 가장 안전하고, 면접의 'Why CS·Why AI'에 직접 답해주는 자료. "감시사회 알고리즘 윤리"라는 본인 색이 또렷해져.

📚 알아두면 좋은 핵심 이론

  • Demographic Parity: 보호 속성(성별·인종 등)에 관계없이 양성 예측률이 동일해야 한다는 공정성 정의. 가장 단순하지만 정확도와 충돌하기 쉬워.
  • Equal Opportunity: 진짜 양성 중에서 양성 예측률이 그룹 간 동일해야. 의료·고용처럼 "놓치면 안 되는" 도메인에 적합.
  • Calibration: 모델이 0.7이라 예측한 사례는 실제로도 70%가 양성이어야 한다는 정의. 위 두 정의와 동시에 만족 불가능(impossibility theorem).
  • 보호 속성 제거의 함정: 성별을 빼도 우편번호·이름이 대리변수(proxy)로 작동. "보지 않는다"가 "공정하다"가 아님의 핵심.
  • 알고리즘 책무성(Accountability): 결정의 근거를 설명·이의제기·감사할 수 있는 체계. EU AI Act·NIA 윤리기준의 공통 키워드.
