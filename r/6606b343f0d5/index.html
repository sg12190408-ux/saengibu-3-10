SECTION 05

너의 베스트 모먼트 3

생기부에서 가장 잘 쓰인 문장 3개. 왜 좋은지를 우수 세특 패턴 분류로 풀어줄게.

🟢 진로활동 · 2학년 패턴 ① 동기·과정·결과·확장

DSSC + 분광검량선 — '빛 → 분자 → 데이터' 한 사이클

"염료감응형 태양전지 실험에서 이산화티타늄 도포와 탄소 전극 제작 등 복잡한 공정을 반복 시행하며 숙련도를 높이고, 블루베리 안토시아닌이 빛을 흡수해 전자를 방출하는 기작과 전극·전해질 사이 에너지 준위 조정을 면밀히 분석함. 분광 분석 실험에서는 표준 검량선 작성 과정을 세밀히 시도하고 흡광도-농도 관계의 오차 요인까지 꼼꼼히 점검함."

✨ '광흡수 → 전자전이 → 데이터화' 한 사이클을 학생 한 명이 같은 학기에 두 실험으로 보여준 사례. 화학분야 지원자 중에서도 분광·광화학 라인이 이렇게 깔끔한 케이스 흔치 않아.
🟢 수학Ⅰ·수학Ⅱ · 2학년 패턴 ② 키워드 연계형

pH 로그함수 → 평형상수 ln K — 수학으로 화학을 잡다

"pH가 수소 이온 농도의 음의 로그값임을 y=−log(x) 그래프로 직접 그려보며 시각적으로 체감(수학Ⅰ). 화학 평형상수가 왜 ln K 형태로 사용되는지 통계역학적 배경까지 확장 해석하고, ΔG°와 K의 관계, 반트 호프 방정식을 활용해 K와 온도의 함수적 변화를 정리함(수학Ⅱ)."

✨ 화학 진로 학생이 수학을 도구로 정확히 끼워 넣었다. 수학Ⅰ·Ⅱ 두 학기 연속으로 같은 진로 키워드가 등장하는 게 학종 평가자에게 가장 매력적인 신호.
🟢 인공지능 기초 + 영어Ⅰ · 2학년 패턴 ③ 호기심·탐구형 + 자기언어 동기

'약의 기전이 궁금했다' — 약(藥)을 향한 본인 언어

"바이오의약품개발 전문가가 되고 싶다고 함. 약 조제 과정을 접할 일이 어렸을 때부터 잦았는데, 자연스럽게 약의 기전 원리에 대해 궁금증을 갖게 되었다고 함(영어Ⅰ). 인공지능 모델 계획 활동에서는 사용자가 증상과 특성을 입력하면 알맞은 약물을 추천하고 부작용 정보를 제공하는 모델을 계획함(인공지능 기초)."

✨ 진로 동기가 학생 본인의 언어로 박혀 있는 가장 단단한 자료. '왜 화학인가'에 대한 답이 어린 시절 경험으로 자연스럽게 연결돼 학종에서 가장 신뢰도 높은 형태야.

💊 1. UV-Vis 분광법 + 검량선 — 실제 의약 성분 농도 추적

난이도 ★★☆ 3주 키워드 연결: 분광·약(藥)·정량 분석
💜 왜 준영이에게? 2학년 진로활동 분광 분석 검량선은 '연습 단계'에 머물렀어. 거기에 너의 또 다른 키워드 '약(藥)'을 합쳐 한 칸 깊은 주제로. 영어Ⅰ에서 본인 입으로 말한 '약의 기전이 궁금했다'에 분광법으로 답을 만드는 흐름이라, 1·2학년 두 키워드가 3학년에서 만나는 학종 최고 패턴이 완성돼.

📚 알아두면 좋은 핵심 이론

  • 베르-람베르트 법칙(Beer-Lambert Law): A = εbc. 흡광도는 농도와 광경로 길이에 비례. 모든 정량 분광의 출발점이고, 검량선의 직선 영역이 성립하는 이유.
  • λmax(최대 흡수 파장): 분자가 가장 강하게 빛을 흡수하는 파장. 약물마다 고유값(아세트아미노펜 ≈ 243nm)이고, 정량의 신호 대 잡음비가 최고가 되는 지점.
  • 용출시험(Dissolution Test): 정제·캡슐이 위·장 환경에서 시간에 따라 얼마나 풀려나오는지 측정. 의약품 품질관리·생체이용률 평가의 핵심 시험.
  • 모의 위액·장액(pH 1.2 / 6.8): 대한민국약전(KP)·USP가 정한 표준 매질. 같은 약이라도 pH에 따라 용해도가 달라져 흡수 속도가 변함.
  • 약물 표적 단백질: 약은 결국 특정 단백질(효소·수용체)에 붙어 작동해. 농도가 충분해야 표적 결합률이 올라가 — 분광 정량과 약효의 다리 역할.

A. 실험형 / 실천형

  • 아세트아미노펜·아스피린 등 일반의약품 1종을 표준 용액으로 단계 희석
  • UV-Vis(또는 학교 분광계) 흡광도 측정 → 검량선 작성(λmax 선택, 베르-람베르트 법칙 적용)
  • 모의 위액(pH 1.2)·장액(pH 6.8) 환경에서 시간별 농도 변화 측정 → 용출(dissolution) 곡선 작도
  • '약물 농도-시간 추적 1쪽 보고서' 산출(보건실·동아리 공유)

B. 문헌형

  • DBpia·RISS 검색어: '약물 용출시험 UV-Vis', 'dissolution test pharmacopeia'
  • 대한화학회지·약학회지의 의약품 정량분석 리뷰
  • 식약처 의약품 품질관리 가이드라인 / 대한민국약전(KP) 일반시험법
  • 단행본: 'Skoog 분석화학(요약본)' 분광법 챕터, '쉽게 배우는 약물동력학' 1·2장

🚀 어떻게 시작하면 될까

  1. 약학정보원에서 한 약의 λmax·구조 메모⏱ 30분
    약학정보원(health.kr) 접속 → "의약품 검색"에서 아세트아미노펜 입력 → 허가사항·약리정보에서 분자식·분자량 확인. 이어 검색 키워드 아세트아미노펜 UV 흡수 스펙트럼으로 λmax(보통 243nm 부근) 한 줄 메모. 식약처 의약품안전나라(nedrug.mfds.go.kr)에서 같은 정보 교차 확인.✓ 완성품: "약물명 / 분자식 / 분자량 / λmax / 표적 단백질" 한 줄 카드 1장. 모든 계산의 출발점.
  2. 학교 분광계로 표준 용액 5점 검량선 작성⏱ 1~2h
    일반의약품 1정을 정확히 칭량 → 증류수에 녹여 모액 제조 → 5단계 희석(예: 0·5·10·20·40 mg/L). 학교 분광계로 λmax에서 흡광도 측정. Google Sheets·Colab에서:
    import numpy as np, matplotlib.pyplot as plt
    c = np.array([0,5,10,20,40]); A = np.array([0, 0.18, 0.36, 0.71, 1.42])
    m, b = np.polyfit(c, A, 1) # 기울기 = 흡광계수×광경로
    R² 0.99 이상 나오면 합격. 안 나오면 큐벳 닦기·기포 점검.✓ 완성품: 검량선 그래프 .png 1장 + 직선식 A = εbc + b 한 줄.
  3. 모의 위액·장액에서 용출 곡선 측정⏱ 2h
    모의 위액(0.1N HCl, pH 1.2)·장액(인산 완충액 pH 6.8) 각 100mL 비커에 정제 1정 투하 → 5·10·20·30·45·60분에 1mL씩 채취해 같은 부피 매질로 보충. 채취 시료를 검량선에 대입해 농도-시간 그래프 작성. 두 pH 곡선을 한 그래프에 겹쳐 그리고 1차 반응 속도식 ln(C∞-C) vs t로 기울기(k) 산출. 화학반응공학의 반응속도 Arrhenius 키워드로 온도 의존성도 함께 토론.✓ 완성품: pH별 용출 곡선 .png 2장 + 속도상수 k 비교 표 1장.
  4. '약물 농도-시간 추적' A4 1쪽 보고서 + 보건샘 면담⏱ 2~3h
    구조: 표적 단백질·작용 기전 → λmax·검량선 → pH별 용출 곡선 → 임상적 의미(언제 복용, 식전·식후 차이). Canva(canva.com) 또는 미리캔버스(miricanvas.com)로 인포그래픽화. 보건샘 5분 면담으로 "환자 복용 시점과 흡수 곡선" 한 번 검토. 화학Ⅱ 교과샘께 검량선 잔차 해석 추가 점검.✓ 완성품: A4 1쪽 보고서 + 동아리 발표 슬라이드 5매. 면접 '분광 → 약' 핵심 자료.

🌈 2. DSSC 효율 향상 — 천연 색소의 분자 구조 비교 정량 실험

난이도 ★★★ 4주 키워드 연결: 광화학·DSSC·정량
💜 왜 준영이에게? 2학년 DSSC는 한 가지 색소(블루베리 안토시아닌)로 끝났어. 한 칸 더 깊은 주제는 '여러 색소의 분자 구조가 효율을 어떻게 바꾸는가'. 너의 분광 분석 경험과 화학Ⅰ 분자 구조 분석(전자쌍 반발·전기음성도)이 만나는 영역이고, 결과를 정량 그래프로 산출할 수 있어. 신약개발에서도 결국 '분자 구조 → 흡수·결합 → 기능'의 같은 사슬이라, 지금 한 번 다뤄보면 그 사고법이 평생 자산.

📚 알아두면 좋은 핵심 이론

  • HOMO-LUMO 갭: 최고 점유 분자궤도(HOMO)와 최저 비점유 분자궤도(LUMO) 사이의 에너지 차. 갭이 좁을수록 긴 파장(붉은쪽) 빛을 흡수 — 색소 색깔의 분자 수준 이유.
  • 공명 구조와 π전자 비편재화: 이중결합이 번갈아 이어지면 π전자가 넓게 퍼져 HOMO-LUMO 갭이 좁아짐. 안토시아닌·카로티노이드의 강한 흡수가 여기서 나옴.
  • DSSC 효율 4지표(Voc·Jsc·FF·η): 개방회로전압·단락전류밀도·곡선인자·총효율. η = (Voc × Jsc × FF) / P_in. 한 색소를 평가하는 4축 좌표.
  • 전자 주입 효율(η_inj): 들뜬 색소가 TiO₂ 전도대로 전자를 얼마나 잘 넘기는가. 색소 LUMO가 TiO₂ 전도대보다 충분히 높아야 자발적 주입.
  • 앵커링기(-COOH, -OH): 색소를 TiO₂ 표면에 고정하는 작용기. 약물 표적 결합과 똑같은 화학(수소결합·정전기) — 신약개발과 같은 분자 사고.

A. 실험형 / 실천형

  • 천연 색소 3종(안토시아닌·클로로필·카로티노이드) 추출 → UV-Vis 흡수 스펙트럼 비교
  • 각 색소로 DSSC를 동일 조건 제작 → 광원·온도 통제, 개방회로전압(Voc)·단락전류(Isc)·효율 측정
  • 분자 구조의 공명·HOMO-LUMO와 흡수 파장의 관계를 그래프로 도식화
  • 포스터·1쪽 비교표로 산출(과학과제 연구 후속 또는 동아리 발표)

B. 문헌형

  • RISS·KISS 검색어: '천연 색소 DSSC 효율', 'natural dye sensitizer HOMO LUMO'
  • 한국태양광발전학회·한국공업화학회지 DSSC 리뷰 논문
  • 한국과학창의재단·KISTI 오픈액세스의 광화학 자료
  • 단행본: '광화학 입문' 또는 'Atkins Physical Chemistry' 광학 분광 챕터

🚀 어떻게 시작하면 될까

  1. 색소 3종 추출 + 분자 구조 정리⏱ 1~2h
    안토시아닌(블루베리·자색양배추), 클로로필(시금치), 카로티노이드(당근·파프리카)를 각 5g → 에탄올 30mL에 30분 침지 후 거름. 각 색소의 구조식을 PubChem(pubchem.ncbi.nlm.nih.gov)에서 검색해 인쇄. 표 작성: 색소명 / 분자식 / 공액 이중결합 수 / 앵커링기 유무. 신약개발의 'SAR(구조-활성 관계)' 사고법을 색소에 그대로 적용해보는 첫걸음.✓ 완성품: 색소 추출액 3개 + 구조 비교 표 A4 반쪽.
  2. UV-Vis 흡수 스펙트럼 3색 겹쳐 그리기⏱ 1h
    학교 분광계로 400~700nm 범위 흡광도 측정. Colab에서:
    import matplotlib.pyplot as plt
    plt.plot(wl, A_anthocyanin, label='안토시아닌')
    plt.plot(wl, A_chlorophyll, label='클로로필')
    plt.plot(wl, A_carotenoid, label='카로티노이드')
    각 색소의 λmax를 표시. 공액 이중결합 수가 늘수록 λmax가 길어지는 경향(우드워드-피저 규칙)을 데이터로 확인.✓ 완성품: 3색 흡수 스펙트럼 겹친 그래프 .png + λmax 표.
  3. DSSC 3종 제작 + Voc·Jsc 측정⏱ 4~6h(분산)
    FTO 유리·TiO₂ 페이스트·요오드 전해질로 동일 셀 구조 제작. 광원(태양광 또는 LED)·온도 통제. 멀티미터 또는 학교 측정기로 Voc(개방회로전압)·Isc(단락전류) 기록 → P_max·FF·η 계산. 각 색소 3회 반복(평균±오차). 화학Ⅱ 반응속도 Arrhenius 키워드로 온도별 효율 변화도 1세트 추가하면 깊이 ↑.✓ 완성품: 색소별 I-V 곡선 3개 + 효율 비교 표(Voc·Jsc·FF·η).
  4. '분자 구조 → DSSC 효율' 1쪽 비교 인포그래픽⏱ 2~3h
    Canva(canva.com)·미리캔버스(miricanvas.com)로 A4 1매. 구조: 색소 구조식 3개 → 흡수 스펙트럼 → DSSC 효율 4지표 → "왜 ○○가 가장 효율이 높았나" 1단락. 마지막에 "이 사고법은 신약 분자 설계에서 표적 결합 친화도 비교에 그대로 쓰인다"는 한 줄 연결. 화학샘께 HOMO-LUMO 해석 점검 받기.✓ 완성품: A4 인포그래픽 1매 + 동아리 포스터 발표. 학종 '분광·광화학 → 신약' 다리.

💜 왜 준영이에게? 2학년 인공지능 기초의 '약 이미지 분류 모델'이 정확히 너의 다음 단계를 지목했어 — "이미지만으로는 약의 특징을 분류하기 어렵다, 성분·효능 테이블 데이터를 활용하고 싶다"고 학생 본인이 정리. 그걸 그대로 실행하는 탐구. 진로활동에서 읽은 '인공지능과 신약개발'과도 곧장 연결. 신약개발의 표준 사고법(분자 기술자 → 활성 예측)을 고등학생 수준에서 한 번 직접 만져보는 경험.

📚 알아두면 좋은 핵심 이론

  • 리핀스키의 5규칙(Lipinski's Rule of Five): 분자량≤500, logP≤5, HBD≤5, HBA≤10. 경구 투여 약물의 '합격선'. 신약개발 첫 필터.
  • 분자 기술자(Molecular Descriptors): 분자를 숫자로 표현한 변수(분자량·logP·TPSA·rotatable bond 수). AI가 분자를 '학습'하려면 먼저 숫자가 필요해.
  • logP(분배계수): 옥탄올/물 분배 농도비의 로그값. 친유성 척도이고, 너무 높으면 막을 못 빠져나오고 너무 낮으면 흡수가 안 됨.
  • SMILES 표기법: 분자 구조를 한 줄 텍스트로 표현(예: 아세트아미노펜 = CC(=O)Nc1ccc(O)cc1). RDKit·ChEMBL의 공통 입력 언어.
  • 약물 표적 단백질 도킹: 약 분자가 단백질 결합 부위에 어떻게 끼워지는지 컴퓨터로 시뮬레이션. AI 신약개발의 다음 단계 — 이번 탐구는 그 직전 단계.

A. 실험형 / 실천형

  • 공공 약물 데이터(약학정보원·공공데이터포털) 또는 ChEMBL 일부 샘플 다운로드
  • 분자 기술자(분자량·logP·HBD/HBA·TPSA 등 Lipinski rule 변수)를 표로 정리
  • Teachable Machine·간단 분류기로 '경구 흡수 가능성' 분류 모델 시도 → 정확도 평가
  • 'AI는 신약 개발을 어디까지 줄여줄 수 있는가' 1쪽 보고서로 산출(독서 후속편)

B. 문헌형

  • DBpia·RISS 검색어: 'AI 신약개발 사례', 'machine learning drug discovery review'
  • 한국화학공학회지·대한화학회지의 cheminformatics 입문 리뷰
  • 식약처·KIST·한국화학연구원(KRICT) AI 신약개발 동향 리포트
  • 단행본: '인공지능과 신약개발(이미 읽음, 재정독)' + 'Lipinski's Rule of Five' 원논문 요약본

🚀 어떻게 시작하면 될까

  1. 약 30종 데이터 수집 + Lipinski 변수 표 만들기⏱ 1~2h
    약학정보원(health.kr) 또는 PubChem(pubchem.ncbi.nlm.nih.gov)에서 일반의약품 30종 선정 → 각 약의 SMILES·분자량·logP·HBD·HBA·TPSA를 Google Sheets에 정리. 라벨 열에 '경구 가능(1) / 불가능(0)' 추가. 검색 키워드 약물 표적 단백질 도킹으로 약별 표적 단백질도 함께 메모하면 다음 단계 깊이 ↑.✓ 완성품: 30행 × 8열 분자 데이터셋(.csv 또는 .xlsx).
  2. Colab에서 RDKit로 분자 기술자 자동 계산⏱ 1~2h
    Google Colab에 새 노트북 →
    !pip install rdkit -q
    from rdkit import Chem; from rdkit.Chem import Descriptors, Lipinski
    mol = Chem.MolFromSmiles('CC(=O)Nc1ccc(O)cc1')
    Descriptors.MolWt(mol), Descriptors.MolLogP(mol)
    Lipinski.NumHDonors(mol), Lipinski.NumHAcceptors(mol)
    30종 SMILES를 for 루프로 돌려 표 자동 생성 → 손으로 모은 값과 비교 검증.✓ 완성품: 30종 분자 기술자 .csv + 손-자동 비교 표.
  3. scikit-learn으로 경구 흡수 분류 모델 학습⏱ 2~3h
    Colab에서:
    from sklearn.ensemble import RandomForestClassifier
    from sklearn.model_selection import train_test_split
    X = df[['MolWt','LogP','HBD','HBA','TPSA']]; y = df['oral']
    X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3)
    clf = RandomForestClassifier().fit(X_tr, y_tr); clf.score(X_te, y_te)
    특성 중요도(clf.feature_importances_)를 막대그래프로 → "어떤 분자 기술자가 경구 흡수를 가장 잘 설명하는가" 한 줄 결론. Lipinski 룰 단순 적용과 정확도 비교.✓ 완성품: 분류기 학습 코드 .ipynb + 정확도·특성 중요도 그래프.
  4. 'AI 신약개발, 어디까지 줄일 수 있나' 1쪽 보고서⏱ 2~3h
    구조: 전통 신약개발 단계(타깃 발견 → 임상까지 10년·1조원) → AI가 단축한 단계(분자 스크리닝) → 내가 만든 모델의 한계 → 다음 단계: 도킹 시뮬레이션·단백질 구조 예측(AlphaFold 언급). 진로활동에서 이미 읽은 '인공지능과 신약개발' 인용 1~2회. 마무리에 "왜 나는 이 길을 가고 싶은가" 본인 언어 한 단락 — 면접 핵심 자료.✓ 완성품: A4 1쪽 보고서 + 코드 저장소(GitHub 또는 Colab 공유 링크).
