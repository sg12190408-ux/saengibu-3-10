"환자 의료 활동을 돕는 챗봇 모델을 분석한 뒤 웨어러블 기기로 선수 생체 데이터(심박수·움직임·체온)를 수집해 부상 위험을 경고하는 모델을 직접 기획·합성 데이터까지 제작함. 이어 디지털 트윈 학교 모델링과 질병 자가진단 인공지능 알고리즘 설계에 자발적으로 참여함."

✨ '간호+AI'라는 같은 진로 지원자 중 흔치 않은 조합을 두 활동이 하나로 이어주고 있어. 학종 평가자 시선이 여기서 잡혀.

"기존 화학적 방제의 한계를 짚고 독성이 적은 Bt균을 선택 → 혈구계수기로 균 농도를 측정하고 동일 개체군·동일 환경의 통제 조건에서 농도 변화에 따른 유충 치사율을 정량 분석 → 다양한 분사 방식을 비교한 뒤 아두이노로 자동화 시스템 제작까지 스스로 도전."

✨ 가설→통제→정량 분석→자동화로 이어진 한 사이클이 너무 깔끔해. 학종 평가자가 가장 좋아하는 '실험 동력학' 사례.

✨ 가설→자료수집→논문비교→발표까지 의생명 핵심 사이클을 1학년에 한 번 완주한 사례. 간호 진로 동기의 가장 단단한 뿌리야.

🌱 왜 이 활동이 너에게 좋을까? 2학년 인공지능 기초의 웨어러블 부상 경고 모델 + 지구과학 디지털 트윈 자가진단 알고리즘 + 의료 챗봇 분석 — 흩어진 세 활동이 임상 시나리오 1건으로 합쳐지는 순간, 같은 간호학과 지원자 중에서도 흔치 않은 'AI×간호' 색이 또렷해져. 무엇보다 "AI를 다룰 줄 아는 간호사"라는 본인만의 정체성을 직접 만들어보는 경험이야. 면접에서 "왜 너인가?"에 답할 수 있는 한 장이 손에 남게 돼.

📚 알아두면 좋은 핵심 이론

  • 시계열 데이터(Time Series): 시간 흐름에 따라 측정된 값(심박수·체온·혈압 등). 환자 상태 변화를 따라가는 가장 기본 단위야.
  • 임계치(Threshold) 알림: 측정값이 정해진 한계를 넘으면 알람을 보내는 가장 단순한 룰. 모든 의료 모니터링의 1차 방어선.
  • 이상치 탐지(Anomaly Detection): 평소 패턴에서 벗어난 값을 찾는 기법. 결정트리·격리 숲(Isolation Forest) 같은 가벼운 모델로도 충분히 만들 수 있어.
  • False Alarm Fatigue(거짓 알람 피로): 알림이 너무 자주 울리면 의료진이 무뎌지는 현상. 임계치를 너무 민감하게 두면 안 되는 이유.
  • SaMD(Software as a Medical Device): 소프트웨어 자체를 의료기기로 본다는 개념. 식약처가 별도 인증 가이드를 내고 있어 — '디지털헬스 시대'의 핵심 키워드.

A. 실험형 / 실천형

  • 임상 시나리오 1건 선정 (만성 심부전 또는 당뇨 입원환자) — 모니터링 핵심 변수 도출
  • 변수별 웨어러블 센서 매핑 + Python으로 24~48h 시계열 더미 데이터 생성
  • 임계치·추세 변화·복합 조건을 탐지하는 룰 베이스 + 간단한 분류 모델로 알림 시뮬레이션
  • '간호사 의사결정 흐름도' 1쪽 인포그래픽으로 산출

B. 문헌형

  • DBpia·RISS '원격 환자 모니터링', 'remote patient monitoring nursing'
  • 대한간호학회지·간호행정학회지의 디지털헬스 적용 사례
  • 한국보건의료연구원(NECA)·식약처 SaMD 가이드라인
  • 단행본: '디지털 헬스케어 의료의 미래(최윤섭)' 일부

💊 2. 약물 반감기·다회 투약 시뮬레이션 (수학Ⅰ 다음 단계)

난이도 ★★☆ 2주 키워드 연결: 약물·인체 항상성·간호 직무
🌱 왜 이 활동이 너에게 좋을까? 2학년 수학Ⅰ에서 약물 반감기 단일 투약은 그렸지만, 다회 투약·환자 변동성까지 끌고 가본 적은 없어. 그런데 이게 간호사 직무에서 매일 마주치는 '투약 시각·간격 계산'의 진짜 모습이야. 너의 수학·코딩 강점을 임상의 가장 일상적인 의사결정에 직접 연결해 보는 활동 — 한 번만 해보면 "약물 농도가 왜 환자마다 다른지"를 본인 언어로 설명할 수 있게 돼.

📚 알아두면 좋은 핵심 이론

  • 반감기(Half-life): 체내 약물 농도가 절반으로 줄어드는 데 걸리는 시간. 약물마다 고유의 값이고, 투약 간격을 결정하는 가장 중요한 숫자.
  • 1차 약동학(First-order kinetics): C(t) = C₀·e^(-kt). "남은 양에 비례해 사라진다"는 가장 기본 모델. 수학Ⅰ 지수함수의 의학판이라고 보면 돼.
  • 정상상태(Steady State): 다회 투약 시 들어오는 양과 빠져나가는 양이 같아져서 농도가 안정화되는 구간. 보통 반감기의 4~5배 시간 후 도달.
  • Cmax / Cmin / 축적계수: 최고/최저 농도와 다회 투약 시 약이 얼마나 쌓이는지의 비율. Cmax가 너무 높으면 독성, Cmin이 너무 낮으면 효과 × — 이 균형이 간호의 핵심.
  • 클리어런스(Clearance): 시간당 체내에서 제거되는 약물의 양. 신장·간 기능과 직결되며, 환자별 용량 조정의 근거가 돼.

A. 실험형 / 실천형

  • Python·엑셀로 1차 약동학 C(t)=C₀·e^(-kt) 다회 투약 시뮬레이터 작성
  • 변수: 반감기(4·8·12h) × 복용간격(6·8·12h) × 클리어런스 보정
  • 정상상태 농도·Cmax/Cmin·축적계수 그래프
  • 아세트아미노펜 등 일반의약품 1종의 실제 데이터로 검증

B. 문헌형

  • 임상약학회지·대한약학회지 'pharmacokinetics review' 키워드
  • 약학정보원·식약처 의약품 허가정보의 반감기·청소율 공시 자료
  • TDM(치료적 약물 모니터링) 가이드라인(반코마이신·디곡신)
  • 단행본: '쉽게 배우는 약물동력학' 1·2장

🚀 어떻게 시작하면 될까

  1. 약학정보원에서 한 약의 반감기 찾기⏱ 30분
    약학정보원(health.kr) 접속 → 상단 "의약품 검색" → 아세트아미노펜 입력 → 결과의 "약리정보" 또는 "허가사항" 탭에서 반감기(half-life) 항목을 찾아 메모. 보통 2~3시간으로 표기됨. 식약처 의약품안전나라(nedrug.mfds.go.kr)도 같은 정보 제공.✓ 완성품: "아세트아미노펜 반감기 = 2.5h" 한 줄 메모. 이 숫자가 모든 계산의 출발점.
  2. Colab에서 단일 투약 농도 곡선 그리기⏱ 30~60분
    Google Colab에 새 노트북 → 다음 코드 입력:
    import numpy as np, matplotlib.pyplot as plt
    t = np.linspace(0, 24, 240)
    k = np.log(2) / 2.5 # 반감기 2.5h → 분해상수
    C = 100 * np.exp(-k*t) # 초기농도 100mg
    plt.plot(t, C); plt.xlabel('Time (h)'); plt.ylabel('C (mg/L)')
    그래프가 지수 감소 곡선으로 떨어지는 모습 = 수학Ⅰ 지수함수의 의학판. 반감기를 4·8·12h로 바꿔 그래프 3장 비교하면 좋아.✓ 완성품: 단일 투약 농도-시간 곡선 .png 3장 + 코드 .ipynb.
  3. 다회 투약 시뮬레이션 — 정상상태 도달 관찰⏱ 1~2h
    for 루프로 일정 간격 반복 투약을 더해보기:
    doses = [0, 6, 12, 18, 24, 30, 36, 42, 48] # 6h 간격
    C_total = np.zeros_like(t)
    for d in doses:
      mask = t >= d
      C_total[mask] += 100 * np.exp(-k*(t[mask]-d))
    그래프에서 정상상태(steady state)가 보이는 순간을 직접 확인. 변수 조합: 반감기 3종 × 복용간격 3종 → 그래프 9장으로 비교 표 작성.✓ 완성품: 다회 투약 그래프 9장 + Cmax/Cmin/축적계수 산출 표 1장.
  4. 간호사 투약 의사결정 매뉴얼 A4 1쪽으로 정리⏱ 1~2h
    표 형식 약물명 / 반감기 / 권장 간격 / Cmax / 위험 신호로 일반의약품 3~5종 정리. 마지막에 "왜 어떤 환자는 12h, 어떤 환자는 6h 간격일까?"를 본인 답으로 한 단락. 신장·간 기능 저하 케이스도 한 줄씩 추가하면 깊이 ↑. 수학 교과샘께 그래프 해석 한 번 점검 받기.✓ 완성품: A4 1쪽 매뉴얼. 자기소개서·면접 핵심 자료로 직결.

🛡️ 3. 스트레스·면역과 학업 환경 — 1학년 가설검정 후속 메타분석

난이도 ★☆☆ 3~4주(분산) 키워드 연결: 면역·간호·문헌 종합
🌱 왜 이 활동이 너에게 좋을까? 1학년에 가설검정·설문·논문 인용·PPT까지 한 사이클을 이미 완주한 게 너의 가장 큰 자산이야. 그걸 같은 주제 한 단계 더 깊게 가져가면 "1학년 호기심을 3학년 메타분석으로 이어간 학생"이라는 서사가 완성돼. 실험 부담이 적어 3학년 시기에 가장 안전한 카드이고, 간호학과 면접의 단골 질문 "Why nursing?"에 직접 답해주는 자료가 손에 남게 돼.

📚 알아두면 좋은 핵심 이론

  • PNI(정신신경면역학, Psychoneuroimmunology): 스트레스 → 호르몬 → 면역의 연결 경로를 다루는 학문. 간호학과 기초 중에서도 가장 통합적인 분야.
  • 코르티솔(Cortisol): 스트레스 시 부신에서 나오는 호르몬. 면역세포 활동을 억제하는 작용을 해 — "스트레스가 감기 걸리게 한다"의 진짜 이유.
  • SIgA(분비성 면역글로불린 A): 침·점막에 분비되는 항체로 호흡기 감염의 1차 방어선. 스트레스가 높을수록 농도가 떨어진다는 연구가 많아.
  • 종단 vs 횡단 연구: 같은 사람을 시간 두고 보면 종단, 한 시점에 여러 사람 보면 횡단. 인과관계를 말할 수 있는지가 갈려 — 메타분석이 강력한 이유.
  • 효과 크기(Effect Size): "유의함/아님"이 아니라 얼마나 강한 효과인지 정량화하는 값(Cohen's d, r 등). 메타분석의 기본 언어이고, 면접에서 "이 차이가 의미 있다고 본 근거"를 말할 때 쓰는 단어.

A. 실천형

  • 1·2학년 학생 대상 동일 설문 재실시(소규모 종단)로 1학년 본인 표본과 비교
  • 또는 청소년건강행태조사 공공데이터로 학업 스트레스-감염 빈도 상관 분석
  • 결과를 인포그래픽 1매로 정리해 보건실·학급에 공유 (발 단계)

B. 문헌형

  • DBpia·KISS '청소년 학업 스트레스 면역', 'PNI 정신신경면역학'
  • 국내외 청소년 코호트 5건 메타표(연구·표본·지표·효과 크기)
  • 질병관리청 청소년건강행태조사 원자료
  • 단행본: '면역에 관하여(율라 비스)' 면역-스트레스 챕터

🚀 어떻게 시작하면 될까

  1. 책 한 챕터 + 키워드 5개 메모⏱ 1~2h
    '면역에 관하여(율라 비스)'를 학교 도서관 또는 시립도서관에서 빌리기. 면역과 스트레스 관련 30~50쪽만 읽고 메모. 메모 형식: 키워드 / 한 줄 정의 / 책에서 본 사례 한 줄. 기대 키워드: 코르티솔 · SIgA · 사이토카인 · 만성 vs 급성 스트레스 · PNI.✓ 완성품: 키워드 5개 표 1장. 다음 단계 검색의 출발점.
  2. 공공데이터 한 번 만져보기 — 학년별 스트레스 비교⏱ 1h
    공공데이터포털(data.go.kr) 접속 → 검색창에 청소년건강행태조사 입력 → 통계자료 또는 원자료 다운로드 (Excel 형식 권장). Google Sheets에서 "스트레스 인지율" 또는 "감기 빈도" 항목을 학년별·성별로 정렬하고 막대그래프 1장. 어렵게 가지 말고 여기까지가 1단계.✓ 완성품: 학년별 스트레스 인지율 막대그래프 .png 1장 + 시트 파일.
  3. DBpia·KISS 논문 5편 → 메타 비교 표⏱ 3~4h
    DBpia(dbpia.co.kr) 또는 KISS(kiss.kstudy.com)에서 검색 키워드 청소년 학업 스트레스 면역 · PNI 정신신경면역학 · 코르티솔 청소년. 5편의 초록·결론만 읽고 표 작성: 연구(저자·연도) / 표본 크기 / 측정 지표(코르티솔·SIgA 등) / 결과 / 효과 크기. 효과 크기가 명시 안 됐으면 "결과 강도(강·중·약)" 정도로 적어도 OK.✓ 완성품: A4 1쪽 메타 비교 표 + PNI 경로 다이어그램 1쪽.
  4. 인포그래픽 1매로 마무리 + 보건샘 면담⏱ 2~3h
    Canva(canva.com) 또는 미리캔버스(miricanvas.com)에서 A4 1매. 구조: 문제 인식(스트레스 ↑) → 메커니즘(PNI 경로) → 결과(면역 ↓ → 감염 ↑) → 대응 방법(수면·운동·이완). 완성 후 보건샘께 5~10분 면담으로 검토 받고 보건실 게시판 또는 학급 공유. 이 한 번의 공유가 '발(실천)' 단계까지 채워줌.✓ 완성품: A4 인포그래픽 1매 + 보건샘 피드백 메모. 면접의 'Why nursing' 답변 자료로 직결.
