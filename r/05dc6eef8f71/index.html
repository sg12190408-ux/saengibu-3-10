🔊 1. 푸리에 변환을 활용한 음성·음향 노이즈 필터링 시뮬레이터

난이도 ★★☆ 3주 키워드 연결: 신호처리·푸리에·전자회로
🌱 왜 이 활동이 건우에게 좋을까? 2학년 수학Ⅰ의 사인파→푸리에 인식 + 영어Ⅱ의 음향전자기기 본문 기획 + 진로활동의 '이어폰·디지털 신호처리'가 흩어진 단발 활동 셋이야. 이걸 한 시뮬레이터로 묶으면 같은 전자공학과 지원자 중에서도 "신호의 흐름을 직접 만질 줄 아는 학생"이라는 색이 또렷해져. 인공지능 기초 A 성취 + LLM 분석 산출물 경험과 정확히 만나는 카드라, 면접에서 "왜 전자공학이냐"에 답해줄 본인만의 한 장이 손에 남아.

📚 알아두면 좋은 핵심 이론

  • 푸리에 변환(FFT): 시간 영역의 파형을 주파수 성분의 합으로 분해하는 수학 도구. 사인파의 합이 곧 임의의 신호라는 직관이 핵심이야.
  • RC 시정수(τ=RC): 1차 저역통과 필터의 차단 주파수 fc=1/(2πRC). 커패시터 충방전 속도가 곧 필터의 성격을 결정해.
  • 나이퀴스트 정리: 표본화 주파수는 신호 최고 주파수의 2배 이상이어야 한다는 법칙. 음성 8kHz·음악 44.1kHz의 근거.
  • SNR(신호대잡음비): 필터 성능을 숫자로 평가하는 가장 기본 지표. dB 단위로 표기되며 +6dB는 약 2배.
  • 임베디드 신호처리: 마이크로컨트롤러(MCU)에서 ADC→FFT→DAC 흐름. 이어폰·보청기·노이즈캔슬링의 실제 구현 방식이야.

A. 실험형 / 실천형

  • Python(numpy·scipy) 또는 MATLAB Online으로 1초 이내 짧은 음원 1~2개 준비 (말소리 + 의도적으로 60Hz/화이트노이즈 추가)
  • FFT로 시간→주파수 변환 후 특정 대역 차단(저역·고역·대역통과) 필터 적용 → 역FFT로 복원
  • 원본/필터링 결과 파형·스펙트럼을 4분면 그래프로 비교
  • '왜 이 대역만 잘랐을 때 가장 깨끗한가'를 1쪽 인포그래픽으로 산출

B. 문헌형

  • DBpia·RISS '디지털 신호처리 입문', 'FFT noise reduction'
  • 대한전자공학회지·정보과학회지의 잡음 제거·음향 처리 리뷰 논문
  • 한국전자통신연구원(ETRI) 기술리포트 음향·음성 인식 항목
  • 단행본: '쉽게 배우는 디지털 신호 처리' 또는 '신호와 시스템(오펜하임)' 1·2장

🚀 어떻게 시작하면 될까

  1. 음원 준비 + 노이즈 합성⏱ 30~60분
    스마트폰 녹음기로 1~2초 분량 본인 목소리 .wav 1개 저장. Google Colab(colab.research.google.com)에서 새 노트북을 열고 다음 코드로 60Hz 험과 화이트노이즈를 더해줘:
    import numpy as np, scipy.io.wavfile as wav
    fs, x = wav.read('voice.wav')
    t = np.arange(len(x))/fs
    noisy = x + 0.05*np.max(x)*np.sin(2*np.pi*60*t) + 0.02*np.max(x)*np.random.randn(len(x))
    이 단계의 의미는 "신호 = 원하는 것 + 원치 않는 것"의 직관을 손으로 한 번 만들어보는 것.✓ 완성품: voice.wav + noisy.wav 2개. 다음 단계의 입력 데이터.

    import matplotlib.pyplot as plt

    그래프에서 60Hz 부근의 뾰족한 봉우리가 험, 전 대역에 깔린 바닥이 화이트노이즈야. 음성 봉우리(보통 100~300Hz의 기본주파수 + 배음)와 잡음을 눈으로 분리.✓ 완성품: 스펙트럼 .png 1장 + "분리해야 할 잡음 대역" 메모.

🔋 2. 리튬이온 vs 전고체 배터리 — BMS·열폭주 안전 시뮬레이션

난이도 ★★☆ 2~3주 키워드 연결: 전력·배터리·임베디드
🌱 왜 이 활동이 건우에게 좋을까? 2학년 진로활동에서 리튬이온 화재 사례·BMS·전고체까지 한 번 정리해본 게 큰 자산이야. 1학년 과학탐구실험의 '전기차 회생제동·리튬이온' 흐름과 정확히 이어지는 후속편이고, 전기→전자 전환 후에도 '전력·에너지' 키워드를 1→2→3학년 수직 연계로 잇는 가장 안전한 카드. 발전소 입지 AI 분석 활동과 묶으면 "에너지를 다루는 전자공학자"라는 본인만의 색이 또렷해져.

📚 알아두면 좋은 핵심 이론

  • SoC(State of Charge): 셀의 현재 충전 상태(%). 개방회로전압(OCV)과 비선형 곡선 관계라, 전압만 보고 SoC를 추정하면 오차가 커.
  • C-rate: 1C = 정격 용량을 1시간에 충방전. 2C는 30분, 0.5C는 2시간. C-rate가 높을수록 내부 저항 발열이 제곱으로 커져.
  • 열폭주(Thermal Runaway): 셀 온도 ↑ → 분리막 손상 → 단락 → 더 큰 발열의 양의 피드백 루프. 보통 80~120℃ 부근에서 임계점.
  • BMS(Battery Management System): 셀 전압·전류·온도를 모니터링해 충방전을 차단/밸런싱하는 임베디드 시스템. 전력반도체 IGBT·MOSFET이 핵심 스위칭 소자.
  • 전고체(Solid-State): 액체 전해질을 고체로 대체. 가연성 ↓·에너지 밀도 ↑·저온 성능 ↓라는 장단점 트레이드오프.

A. 실험형 / 실천형

  • 엑셀·Python으로 셀 내부 저항·SoC(충전상태)·온도 변화의 간이 모델링
  • 변수: 충방전 C-rate(0.5C·1C·2C) × 주변 온도(25·35·45℃)
  • 임계 온도 도달 시점 → 'BMS가 차단해야 할 알림 트리거' 룰 설계
  • 1쪽 비교표: 리튬이온 vs 전고체 (에너지 밀도·열안정성·수명·단가)

B. 문헌형

  • 대한전기학회지·전력전자학회지 '리튬이온 BMS', '전고체 배터리' 키워드
  • 한국에너지기술연구원(KIER)·산업통상자원부 배터리 안전 기술 보고서
  • 소방청 ESS·전기차 화재 사고 분석 자료
  • 단행본: '배터리 인사이드(박철완)' 일부 장

🚀 어떻게 시작하면 될까

  1. 셀 등가회로 모델 한 줄로 정리⏱ 30~60분
    가장 단순한 1차 RC 모델: V_cell = V_OCV(SoC) − I·R_int − V_RC. R_int는 보통 30~80mΩ. SoC vs OCV 곡선은 대한전기학회지 '리튬이온 OCV-SoC' 키워드로 표 1개 다운로드 → 7~10점 보간. RC 시정수가 여기서도 등장한다는 점을 직접 확인.✓ 완성품: SoC vs OCV 표 + 등가회로 한 컷 도식 (PowerPoint).
  2. Colab에서 충방전 시뮬레이터 작성⏱ 1~2h
    import numpy as np, matplotlib.pyplot as plt
    Q = 2.5 # Ah, 정격용량
    I = 1*Q # 1C 방전
    R = 0.04 # 내부저항 40mΩ
    dt = 1; t = np.arange(0, 3600, dt)
    SoC = 1 - I*t/3600/Q
    P_loss = I**2 * R # 발열 [W]
    T = 25 + np.cumsum(P_loss*dt)/(50*0.9) # 열용량 단순화
    C-rate를 0.5/1/2C로 바꿔 그래프 3장. 2C에서 온도가 어떻게 비선형으로 치솟는지가 핵심.✓ 완성품: SoC·온도 곡선 .png 3장 + .ipynb.
  3. BMS 차단 룰 + 미적분으로 임계점 추정⏱ 1~2h
    ① 임계 온도 룰: if T > 60: cut_off = True
    ② 추세 룰: dT/dt > 1℃/min 이면 사전 경고 (np.gradient(T, t))
    ③ 복합 룰: SoC<5% AND T>55℃ 조합
    인덕터·커패시터 미적분 강점을 살려, 1차 ODE dT/dt = (P_loss − k(T−T_amb))/C_th를 손으로 풀어 정상상태 온도식을 한 줄로 도출. 코드 결과와 비교.✓ 완성품: BMS 룰 3종 비교 표 + 정상상태 온도식 손풀이 1쪽.
  4. 리튬이온 vs 전고체 비교 인포그래픽 + 사고사례 분석⏱ 2~3h
    소방청 'ESS 화재 통계'·산업통상자원부 'ESS 안전관리 강화방안' PDF 1건 → 사고 1건의 추정 원인을 본인 시뮬레이터의 BMS 룰로 사후 검증. 표 형식 항목 / 리튬이온(LFP·NCM) / 전고체로 에너지 밀도·열안정성·수명·단가 비교. Canva A4 인포그래픽 1매 + "내가 BMS 엔지니어라면 이 사고를 어떻게 막을 것인가"를 한 단락으로.✓ 완성품: A4 인포그래픽 1매 + 사고 분석 보고서 4쪽. 면접 핵심 자료.

🤖 3. PID 제어 기반 라인트레이싱·온도 항상성 임베디드 미니 프로젝트

난이도 ★☆☆ 2주 키워드 연결: 임베디드·자동제어·아두이노
🌱 왜 이 활동이 건우에게 좋을까? 1학년 자율활동의 아두이노 RC카 + 2학년 자율활동의 PID·페일세이프·놀이기구 자동운행 분석을 본인 손으로 한 번 더 구현하는 카드야. 실험 부담이 적어 3학년 시기에 가장 안전하고, 광센서·RFID 활동 경험과도 연결돼. '시스템 한계 분석 + 다음 모델 설계'까지 가면 패턴 ⑤(반성적 실마리)도 자연스럽게 채워지고, "Why 전자공학?"에 답하는 본인 직접 구현 사례 1건이 손에 남아.

📚 알아두면 좋은 핵심 이론

  • 피드백 제어: 목표값(Setpoint) − 측정값(Process Variable) = 오차(Error). 오차를 0으로 만드는 게 모든 제어의 출발점.
  • P·I·D 항의 역할: P=현재 오차에 비례, I=과거 누적 오차 적분, D=미래 오차 미분. "미적분이 왜 공학에 필요한가"의 가장 직관적인 답.
  • PID 튜닝 (Ziegler-Nichols): Kp만 키워 임계 진동을 찾은 뒤 Kp·Ki·Kd를 비율로 분배하는 고전 방법. 현장의 가장 표준적 첫걸음.
  • 오버슈트·정착시간: 목표값을 얼마나 넘었다 안정되는지·언제 정착하는지의 두 지표. 시스템 성능 평가의 핵심 숫자.
  • 임베디드 신호처리: 센서(ADC) → 제어기(MCU) → 액추에이터(PWM)의 파이프라인. 이어폰·드론·전기차 모두 이 구조야.

A. 실천형

  • 아두이노+TinkerCAD/Wokwi 시뮬레이터로 P→PI→PID 단계 비교
  • 예시 1: 라인트레이싱 카(P 제어만 vs PID 제어의 진동 차이 그래프)
  • 예시 2: 가상 온도 챔버에서 항온 유지 시 오버슈트·정착 시간 비교
  • 결과를 30초 영상 + 1쪽 보고서로 동아리·학급에 공유 (발 단계)

B. 문헌형

  • 대한전자공학회·제어로봇시스템학회지 'PID 제어 튜닝'
  • 한국과학창의재단 SW·임베디드 교사용 자료의 PID 단원
  • 아두이노 공식 PID Library 문서 + Ziegler-Nichols 튜닝법
  • 단행본: '제어공학 입문' 또는 '아두이노로 배우는 제어공학' 1~3장

🚀 어떻게 시작하면 될까

  1. Wokwi에서 가상 라인트레이싱 회로 구성⏱ 30~60분
    Wokwi(wokwi.com) 접속 → New Arduino Uno → 좌·우 광센서(LDR 또는 디지털 핀) + L298N 모터 드라이버 + DC모터 2개 추가. 회로도는 광센서 활용 경험을 한 단계 확장한 형태. 첫 코드는 P 제어만:
    int err = analogRead(A0) - analogRead(A1);
    int u = Kp * err;
    analogWrite(M1, 150+u); analogWrite(M2, 150-u);✓ 완성품: Wokwi 회로 링크 1개 + P 제어 동작 영상 10초.
  2. P → PI → PID 순차 추가 + 그래프 비교⏱ 1~2h
    같은 회로에서 적분·미분 항 차례로 추가:
    integral += err * dt;
    derivative = (err - prev_err) / dt;
    u = Kp*err + Ki*integral + Kd*derivative;
    각 단계 위치 오차를 Serial.println()으로 1초마다 출력 → 복사해 Colab에서 그래프. PI에서 정상상태 오차가 사라지고, D를 추가하면 진동이 줄어드는 차이를 직접 눈으로 확인. RC 시정수처럼 미분 항도 잡음에 약하다는 점을 한 줄 메모.✓ 완성품: P/PI/PID 위치 오차 그래프 3장 + 시리얼 로그 .csv.
  3. PID 튜닝 + 가상 온도 챔버 두 번째 사례⏱ 1~2h
    Ziegler-Nichols: Ki=Kd=0으로 두고 Kp를 천천히 올려 시스템이 일정 진폭으로 진동하는 임계 게인 Ku와 진동주기 Tu를 찾기 → 표 적용 (Kp=0.6Ku, Ki=2Kp/Tu, Kd=Kp·Tu/8). 같은 코드 구조로 가상 온도 챔버(히터 PWM + 온도 ADC) 사례 1건 추가. 라인트레이싱과 온도 항상성 두 시스템의 오버슈트·정착시간을 표로 비교.✓ 완성품: 튜닝 전후 그래프 4장 + 두 시스템 성능 비교 표 1장.
  4. 한계 분석 + 다음 모델 설계 1쪽⏱ 1~2h
    "이 PID로 못 잡는 게 무엇인가?"를 직접 적기. 예: 비선형 마찰·센서 잡음·시간 지연 → 해결책으로 저역통과 필터(RC 시정수 적용)·게인 스케줄링·모델예측제어(MPC) 한 줄씩. 이게 패턴 ⑤(반성적 실마리). 30초 발표 영상 + 1쪽 보고서로 학급·동아리 공유. 마지막 줄에 "내가 다음에 만들 시스템은 ___" 한 문장으로 다음 탐구의 씨앗을 남겨.✓ 완성품: A4 보고서 1쪽 + 발표 영상 30초. 자기소개서 직결.
