신경망·생성형 AI의류·아트 테크놀로지미디어아트·시각화
✨ 잘하고 있는 점: 1학년 '수의학→신경망 연구원'으로 한 번 좁힌 뒤, 2학년에 아트.테크놀로지로 다시 한 번 뾰족해진 흐름이 진로활동에 그대로 남아 있어. 핵심은 — 두 전환 모두 'AI'라는 척추가 빠지지 않았다는 거야. 1학년 자연어 처리·튜링 테스트·머신러닝 가짜웃음 분류기 → 2학년 의류 분류 AI·가상피팅·AI 수요예측·디지털 트윈·Y2K 댓글 시각화. 이건 일관성 부족이 아니라 전환 이후 일관성 확보야. 'AI를 어디에 쓸 것인가'만 의료→예술/의류로 바뀐 거지. 🌱 다음 한 걸음: 3학년 활동 1개에 'AI×아트테크'를 한 번 더 등장시키면 1·2학년 키워드가 3학년까지 수직으로 한 줄을 만들어 — 학종에서 가장 좋아하는 '키워드 수직 연계' 완성.

🟢 인공지능 기초 · 2학년 패턴 ② 키워드 연계형 + ⑥ 머리·가슴·발 통합

"가상피팅 모델의 한계를 분석하고, 사용자 체형·선호 입력 기반 추천 모델을 직접 기획. 이어 청바지·스웨터 등 15종 의류 이미지를 학습시켜 분류 모델을 제작. 2학기에는 LLM 텍스트 시각화로 Y2K 패션 영상 댓글을 키워드·시간별로 시각화하고, 아시아 3국 미녀 합성 결과로 AI가 미적 편견을 재생산할 수 있음을 비판적으로 지적함."

✨ 'AI×의류·예술'이라는 같은 아트테크 지원자 중 흔치 않은 조합을, 모델 제작과 윤리 비판이라는 두 축으로 동시에 보여줘. 학종 평가자 시선이 여기서 잡혀.
🟢 과학과제 연구 · 2학년 패턴 ① 동기·과정·결과·확장형 + ⑤ 반성적 실마리형

어깨 비대칭 가방끈 — 주제 전환·힘 센서·정량 분석

"IoT 필름 첫 주제에서 변인 통제 한계를 만나자 단순 실패가 아닌 문제점을 정리해 팀과 공유, 주제를 어깨 비대칭 가방끈 장력으로 전환. 어깨 기울기를 정량 측정하고 가방끈에 힘 센서를 부착해 장력을 기록, 가방끈 길이별 양쪽 장력 차이가 최소가 되는 조건을 도출. 단순 비례가 성립하지 않음을 알고 신체 비대칭 변수를 결론에 반영함."

✨ 첫 실패 → 원인 분석 → 주제 전환 → 정량 실험 → 결과의 한계까지 인정하는 한 사이클이 너무 깔끔해. 학종 평가자가 가장 좋아하는 '실패에서 배운 사람' 사례.
🟢 진로활동 · 2학년 패턴 ② 키워드 연계형 + ① 동기·과정·결과·확장형

SPA 의류 폐기 → AI 수요예측·TSP 유전 알고리즘 융합

"SPA 브랜드 대량 의류 소각 사례에서 출발해 수요 예측의 한계와 생산 비효율을 분석. AI 개발에서 코딩보다 '문제 정의·요구 구조화 역량'이 핵심임을 인식하고, 판매 이력·기후·트렌드 데이터를 학습하는 AI 수요예측 시스템과 원단 배치 최적화·불량 자동 검출까지 구체화. 외판원 문제(TSP)를 유전 알고리즘으로 풀고 NP-난해 특성을 이해하며 물류·제조·의류 산업의 동선 최적화로 연결."

✨ 사회 문제 → AI 시스템 설계 → 알고리즘 이론(TSP·유전 알고리즘) → 산업 적용까지 한 활동 안에서 다 끌고 갔어. 아트테크 진로 동기의 가장 단단한 뿌리야.

너의 키워드를 한 단계 더 깊게 가져갈 탐구 3종.

🎨 1. 생성형 AI 의류 디자인의 편향성 검증 — 데이터셋·프롬프트 실험

난이도 ★★☆ 3~4주 키워드 연결: 생성형 AI·아트테크·윤리
💜 왜 재용이에게? 2학년 인공지능 기초에서 'AI 미녀 합성이 미적 편견을 재생산한다'고 직접 지적한 그 통찰의 후속편. 단발 비판 한 줄을 데이터 실험으로 이어가면 같은 아트테크 지원자 중에서도 흔치 않은 'AI×예술 윤리'라는 색이 또렷해져. 무엇보다 "AI를 비판도 하고 다룰 줄도 아는 디자이너"라는 본인만의 정체성이 손에 남아. 면접에서 "왜 너인가?"에 답할 수 있는 한 장이 생기는 활동이야.

📚 알아두면 좋은 핵심 이론

  • 생성형 AI(Generative AI): 텍스트·이미지·음악을 만들어내는 AI(Stable Diffusion·Midjourney·DALL·E). 학습 데이터의 분포를 그대로 모방한다는 게 핵심.
  • 데이터셋 편향(Dataset Bias): 학습 데이터가 특정 인종·체형·성별에 치우쳐 있으면 결과물도 그 방향으로 쏠림. "AI가 만든 미녀"가 다 비슷해 보이는 이유.
  • 프롬프트 엔지니어링: 같은 모델이라도 입력 문장을 어떻게 쓰느냐에 따라 결과가 달라져. 'debias prompt'는 편향 완화 표현(예: 'diverse body types')을 의도적으로 넣는 기법.
  • 정량 라벨링: "예쁘다"처럼 모호한 평가를 색·실루엣·노출도·허리비율 같은 수치로 쪼개 표기하는 작업. 주관을 데이터로 바꾸는 출발점.
  • AI 윤리 가이드라인: 한국정보화진흥원(NIA)·OECD·EU AI Act가 제시한 신뢰AI 원칙(공정성·투명성·책임성). 비판 한 줄을 학술 언어로 옮기는 어휘 창고.

A. 실험형 / 실천형

  • 의류·체형 키워드 5쌍(예: '한국형 vs 서구형', '여성복 vs 유니섹스')으로 동일 프롬프트 30회씩 생성
  • 색·실루엣·노출도·체형 비율을 표로 정량화 + 사람이 직접 라벨링
  • 편향 점수 산출 후 프롬프트 보정 전·후 비교 (debias prompt 1회 적용)
  • 결과를 1쪽 인포그래픽 + 학급 게시판 전시

B. 문헌형

  • DBpia·RISS '생성형 AI 편향', 'fashion AI bias dataset'
  • 한국정보화진흥원(NIA) AI 윤리 가이드라인·신뢰AI 자료
  • Stable Diffusion·Midjourney 편향 연구 리뷰 논문(arxiv 한국어 정리본)
  • 단행본: '대량살상 수학무기(캐시 오닐)' 알고리즘 편향 챕터

🚀 어떻게 시작하면 될까

  1. 키워드 5쌍 + 라벨링 항목 표 설계⏱ 30분
    본인이 봤을 때 'AI가 편향될 것 같은' 의류·체형 키워드 5쌍을 정해 메모. 예: 한국형 vs 서구형 · 여성복 vs 유니섹스 · 10대 vs 30대 · 오피스 vs 스트릿 · 플러스사이즈 vs 슬림. 다음으로 라벨링 항목 4개 설계: 주조색 / 실루엣(A·H·X) / 노출도(1~5) / 허리비율.✓ 완성품: A4 반쪽 분량의 키워드 5쌍 × 라벨링 4항목 표 1장. 모든 실험의 기준선.
  2. HuggingFace에서 무료 Stable Diffusion으로 30장 생성⏱ 1~2h
    HuggingFace Spaces(huggingface.co/spaces)에서 Stable Diffusion XL 검색 → 무료 데모로 들어가 키워드 1쌍당 6~10장씩 총 30~50장 생성. 같은 프롬프트라도 seed가 달라 결과가 다르다는 점 메모. Colab에서 직접 돌리고 싶으면 diffusers 라이브러리 한 줄: from diffusers import StableDiffusionPipeline.✓ 완성품: 키워드별 폴더에 정리된 이미지 30~50장 + 프롬프트·seed 기록 시트.
  3. 구글 시트로 정량 라벨링 → 편향 점수 산출⏱ 2~3h
    Google Sheets에 1행=이미지 1장으로 키워드·실루엣·노출도·허리비율 채우기. 함수 한 줄로 평균: =AVERAGEIF(A:A,"한국형",D:D). 두 키워드 그룹의 평균 차이가 편향 점수. 결과를 막대그래프로: 어떤 항목이 가장 크게 갈렸는지 한눈에. 본인 라벨링이 주관적인 점은 보고서 한계로 명시.✓ 완성품: 라벨링 시트 1개 + 편향 점수 막대그래프 .png 1장.
  4. debias 프롬프트 적용 후 비교 + 인포그래픽 1매⏱ 2~3h
    같은 5쌍에 'diverse body types, multiple ethnicities, varied silhouettes' 한 줄을 추가해 다시 30장 생성 → 1·2단계 점수와 비교. Canva(canva.com)에서 A4 1매 인포그래픽: 문제(편향) → 측정(점수) → 보정(프롬프트) → 결과(개선/한계) 4단 구조. 학급 게시판·동아리방 공유로 '발' 단계 완성. 미술·정보 교과샘께 검토 한 번.✓ 완성품: A4 인포그래픽 1매 + 보고서 6쪽. 면접 핵심 자료로 직결.
🛠️ 사용 도구·자료

· HuggingFace Spaces (huggingface.co/spaces) — Stable Diffusion 데모
· Google Colab + diffusers (colab.research.google.com)
· DBpia (dbpia.co.kr) — '생성형 AI 편향'
· NIA AI 윤리 가이드라인 (nia.or.kr) · Canva

📦 산출물

· Stable Diffusion 생성 이미지 60~100장 (.zip)
· 라벨링·점수 시트 1개
· 보고서 6쪽 내외
· 학급 전시용 인포그래픽 A4 1매

👗 2. 인터랙티브 미디어아트 — 옷·신체·센서로 보는 데이터 시각화

난이도 ★★☆ 3주 키워드 연결: 미디어아트·웨어러블·시각화
💜 왜 재용이에게? 2학년 과학과제 연구에서 가방끈에 힘 센서를 붙여 어깨 비대칭을 정량 분석한 경험 + 폴리우레탄 3D 모델링 + 인공지능 기초 LLM 텍스트 시각화 — 이 셋이 만나는 지점이 바로 미디어아트야. 진로 핵심 키워드 '아트.테크놀로지'에 정면으로 답하는 활동 — 끝나면 너는 "센서 데이터로 작품을 만들어본 사람"이 돼. 같은 학과 지원자 사이에서 가장 또렷한 차별점이 손에 남게 돼.

📚 알아두면 좋은 핵심 이론

  • 인터랙티브 미디어아트: 관람자의 동작·소리·생체신호가 작품에 실시간으로 반영되는 예술 형식. 라파엘 로자노 헤메르·teamLab이 대표 작가.
  • 센서·액추에이터: 압력·가속도·근전(EMG) 센서로 신체·의류 데이터를 수집하고, LED·진동·소리로 출력하는 입출력 짝꿍. 아두이노·M5Stack이 진입장벽 가장 낮음.
  • 데이터 매핑(Mapping): 센서값을 시각·청각 파라미터(색·크기·주파수)로 변환하는 규칙. 같은 데이터라도 매핑에 따라 작품이 완전히 달라져.
  • p5.js / TouchDesigner: 코딩 기반 비주얼 시각화 도구. p5.js는 자바스크립트로 브라우저에서 바로, TouchDesigner는 노드 기반 GUI로 영상 효과까지.
  • 웨어러블 인터랙션 디자인: 옷·가방 자체가 입력장치가 되는 분야. 너의 가방끈 힘 센서 경험이 정확히 이 지점이야 — '학생 작품'을 '학술 용어'로 옮기는 다리.

A. 실험형 / 실천형

  • 아두이노·m5 + 압력/가속도 센서로 옷·가방의 움직임 데이터 수집(걷기·앉기·점프)
  • p5.js 또는 TouchDesigner로 동작에 반응하는 시각 패턴 생성(색·라인·파티클)
  • '몸의 비대칭이 시각으로 보이게' — 좌·우 센서값 차이를 색 농도 변화로 매핑
  • 1분 데모 영상 + 작품 노트 1쪽으로 산출, 동아리·학급에 공유

B. 문헌형

  • DBpia·KISS '미디어아트 인터랙티브', 'wearable interaction design'
  • 한국문화예술위원회·예술경영지원센터 미디어아트 사례집
  • 국립현대미술관·아트센터 나비 전시 도록(라파엘 로자노 헤메르·Random International)
  • 단행본: '디지털 미디어아트(스티븐 윌슨)' 1·3장

🚀 어떻게 시작하면 될까

  1. 레퍼런스 작가 3명 분석 + 매핑 아이디어 메모⏱ 1h
    유튜브·국립현대미술관 아카이브에서 검색: Rafael Lozano-Hemmer · teamLab · Random International "Rain Room". 각 작품마다 입력(센서/카메라) / 출력(빛/소리/물) / 매핑 규칙을 한 줄씩 정리. 이 표가 본인 작품 설계의 출발점.✓ 완성품: A4 1쪽 작가 분석표 + 본인 작품 한 줄 컨셉 ("어깨 비대칭이 색의 비대칭으로 보이는 옷").
  2. 아두이노 + 압력 센서로 데이터 한 번 흘려보기⏱ 2~3h
    학교 동아리실 또는 메이커스페이스에서 Arduino UNO + FSR(힘 센서) 2개 빌리기. 가방끈 좌·우에 부착(이전 실험 세팅 재사용 OK). 시리얼 모니터로 값이 들어오는지만 확인: Serial.print(analogRead(A0));. 이 단계는 "작동만 시키면 성공".✓ 완성품: 좌·우 센서값이 시리얼 모니터에 흐르는 영상 30초 + 회로 사진 1장.
  3. p5.js 웹에디터에서 시각 패턴 만들기⏱ 3~4h
    p5.js Web Editor(editor.p5js.org)에서 새 스케치. 핵심 코드:
    let l=0, r=0;
    function draw(){ background(0); fill(l,50,200); ellipse(200,200,l/4); fill(200,50,r); ellipse(400,200,r/4); }
    아두이노 값을 p5.serialcontrol로 받아 l, r에 넣으면 좌·우 센서값이 두 원의 크기·색으로 바뀜. "센서값 차이 = 색 농도 차이"로 매핑하면 비대칭이 시각화돼. TouchDesigner를 쓰면 영상 효과까지.✓ 완성품: p5.js 데모 페이지 1개 + 코드 .js 파일.
  4. 1분 데모 영상 + 작품 노트 1쪽 + 학급 공유⏱ 2~3h
    스마트폰으로 본인이 옷·가방을 입고 걷기·점프하는 영상을 찍고, 동시에 화면에 패턴이 변하는 모습을 캡처(OBS Studio로 화면+카메라 합성). 작품 노트 1쪽 구조: 제목 / 컨셉 / 입력 / 매핑 / 출력 / 의도. 동아리·학급 SNS 또는 게시판에 공유 — 이게 '발' 단계. 미술·정보 교과샘께 검토 1회.✓ 완성품: 1분 데모 영상 .mp4 + 작품 노트 A4 1쪽. 면접 포트폴리오 핵심 자산.

🧵 3. AI 수요예측 의류 폐기 절감 시뮬레이터 — 2학년 진로활동 후속

난이도 ★★☆ 3~4주 키워드 연결: AI·의류 산업·지속가능성
💜 왜 재용이에게? 2학년 진로활동에서 'AI 수요예측 시스템으로 SPA 의류 소각 문제 해결'을 개념으로 제안만 했던 부분의 직접 구현편. 같은 주제를 한 단계 더 깊게 가져가는 흐름이라 '키워드 수직 연계' 패턴 ②를 1→3학년까지 잇게 돼. 또 본인이 따로 탐구한 TSP 유전 알고리즘 물류 최적화까지 자연스럽게 결합되는 영역 — 인공지능 기초 A 성취도와도 정확히 만나는 지점이야. 끝나면 손에 "정책 제안 + 실제 코드" 한 세트가 남아.

📚 알아두면 좋은 핵심 이론

  • 수요예측(Demand Forecasting): 과거 판매·검색·기후 데이터로 미래 수요를 추정하는 모델. 재고 과잉(소각)과 결품(매출 손실) 사이 균형이 핵심.
  • 이동평균 vs 회귀 vs 신경망: 가장 단순한 평균 → 변수 여러 개 다중회귀 → 비선형까지 잡는 신경망. 데이터 양·해석 가능성에 따라 선택. 고등 수준은 scikit-learn으로 모두 가능.
  • MAPE(평균 절대 백분율 오차): 예측이 실제와 얼마나 빗나갔는지 %로 표시. 의류 업계는 보통 20~30%면 양호. 이 한 숫자가 모델 비교의 공통 언어.
  • TSP(외판원 문제) + 유전 알고리즘: N개 도시를 한 번씩 돌아오는 최단 경로. NP-난해라 완전해 대신 GA로 근사해. 본인이 이미 탐구한 영역 — 수요예측 결과를 물류 동선 최적화에 직접 연결할 수 있어.
  • 지속가능 패션(Sustainable Fashion): SPA 대량 소각·과잉 생산을 줄이려는 산업 흐름. EU 디지털 제품 여권(DPP)·환경부 의류 폐기물 통계가 정책 데이터의 출발점.

A. 실험형 / 실천형

  • 공공데이터(통계청 의류 출하·소비자물가지수) + 트렌드 키워드 검색량 가짜 데이터 12개월 구성
  • Python·엑셀로 단순 이동평균 vs 다중회귀 vs 간단 신경망(scikit-learn) 3가지 모델 비교
  • 예측오차(MAPE)와 과잉생산 절감량(폐기 톤 추정) 표로 산출
  • 결과 + TSP 유전 알고리즘 물류 최적화 1쪽 사례를 결합한 보고서

B. 문헌형

  • DBpia·RISS '의류 수요예측', 'fashion demand forecasting deep learning'
  • 한국섬유산업연합회·KOTRA 지속가능 패션 산업 동향 리포트
  • 환경부·한국환경산업기술원 의류 폐기물 통계 자료
  • 단행본: '패션의 흑역사(다나 토머스)' 패스트패션 챕터

🚀 어떻게 시작하면 될까

  1. 공공데이터 한 줄 받아오기 + 환경부 폐기 톤 메모⏱ 30~60분
    공공데이터포털(data.go.kr)에서 의류 출하 또는 소비자물가지수 의류 검색 → Excel 다운로드. 환경부 자원순환정보시스템(recycling-info.or.kr)에서 의류 폐기물 발생량 연도별 통계 한 줄 메모(예: "연 3X만 톤"). 이 숫자가 보고서의 임팩트 지점.✓ 완성품: 12개월 의류 출하 데이터 .xlsx + 환경부 폐기 톤 한 줄 메모.
  2. Colab에서 이동평균·다중회귀 두 모델 돌려보기⏱ 1~2h
    Google Colab 새 노트북 → pandas·sklearn 임포트:
    import pandas as pd
    from sklearn.linear_model import LinearRegression
    df = pd.read_csv('clothes.csv')
    df['MA3'] = df['sales'].rolling(3).mean() # 3개월 이동평균
    다중회귀는 X = df[['month','price','search_trend']] · y = df['sales']로 LinearRegression().fit(X, y). 두 모델의 예측치를 같은 그래프에 겹쳐 그려.✓ 완성품: Colab 노트북 1개(.ipynb) + 모델 비교 그래프 .png 1장.
  3. 간단 신경망 + MAPE 비교 표 + 절감량 추정⏱ 2~3h
    sklearn.neural_network.MLPRegressor 한 줄 추가:
    MLPRegressor(hidden_layer_sizes=(8,8), max_iter=2000).fit(X, y)
    세 모델의 MAPE 계산: np.mean(np.abs((y-pred)/y))*100. "가장 좋은 모델로 예측했을 때 과잉 생산이 N% 줄어 → 폐기 X톤 절감" 한 줄 추정. 본인이 탐구했던 TSP·유전 알고리즘은 "예측 후 물류 동선 최적화"로 자연 연결되니 보고서 1쪽 추가.✓ 완성품: 모델 3종 비교 표(MAPE·절감량) + TSP 결합 1쪽 사례.
  4. 정책 제안형 보고서 + 학급·진로샘 공유⏱ 2~3h
    보고서 6~8쪽 구조: 문제(SPA 소각) → 데이터(공공·환경부) → 모델 3종 비교 → 절감 시뮬레이션 → TSP 물류 결합 → 정책 제안(EU DPP·국내 적용). 마무리는 "고등학생 수준 한계"를 솔직히 명시해 학술 윤리도 챙김. 진로샘께 5~10분 면담으로 검토받고, 학급·진로 동아리에 1쪽 요약본 공유.✓ 완성품: 보고서 6~8쪽 + 1쪽 요약 인포그래픽 A4 1매. 면접 핵심 자료.
