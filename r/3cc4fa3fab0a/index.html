⚙ 1. MR 댐퍼 응답 특성 — 자기유변유체 후속 탐구

난이도 ★★★ 3~4주 키워드 연결: 자기유변유체·자동제어·동역학
🌱 왜 이 활동이 너에게 좋을까? 2학년 과학과제 연구에서 '점성 변화'까지는 측정했지만, 실제 댐퍼 응답(전류 변화에 대한 감쇠력 시간 응답)까지는 아직 못 갔어. 그 한 단계 더가 메커트로닉스의 핵심이야. MR 유체를 직접 다뤄본 학생은 흔치 않고, 거기에 시간 응답 + 전류 제어까지 더하면 "왜 자기유변유체에서 그쳤지?"라는 면접 질문에 곧바로 답할 수 있는 너만의 이야기가 손에 남게 돼.

📚 알아두면 좋은 핵심 이론

  • 자기유변유체(MR fluid): 자기장이 걸리면 사슬 구조가 형성되어 점성이 수십 배로 커지는 스마트 유체. 자동차 능동 서스펜션·인공관절·진동 흡수에 쓰여.
  • 감쇠력(Damping force): 진동을 줄이는 힘 F = c·ẋ. MR 댐퍼는 전류로 감쇠계수 c를 실시간 바꿀 수 있다는 게 핵심.
  • 응답 시간(Rise time): 입력 변화 → 출력 안정까지 걸리는 시간. MR 댐퍼는 보통 10~30 ms로 매우 빨라 — 그래서 'semi-active' 제어가 가능해.
  • PWM(Pulse Width Modulation): 디지털 신호로 평균 전류·전압을 조절하는 방법. 아두이노 analogWrite()가 바로 PWM이야.
  • Semi-active control: 액추에이터로 직접 힘을 만들지 않고, '감쇠 특성'만 실시간 바꿔 진동을 다스리는 방식. MR 댐퍼의 가장 큰 장점이고 자동차·교량에서 실제 쓰여.

A. 실험형 / 실천형

  • 기존 솔레노이드+유체 장치에 가속도계(스마트폰 센서) 부착해 진동 감쇠 곡선 측정
  • 전류 0/0.5/1.0A 단계 변화로 응답 시간(rise time) 비교
  • 아두이노 PWM 전류 제어 — 1학년 라인트레이싱 코딩 경험 재활용
  • '능동 서스펜션 개념도' 1쪽 인포그래픽으로 산출

B. 문헌형

  • KCI·DBpia '자기유변유체 응답', 'MR damper semi-active control'
  • 대한기계학회지의 차량 진동 제어 사례
  • 한국과학기술원(KIST)·자동차연구원 기술자료실
  • 단행본: '기계진동학(Rao)' 감쇠계 단원, '메카트로닉스 시스템 설계' 일부

🚀 어떻게 시작하면 될까

🛞 2. 마찰계수 제어 — ABS·로봇 관절 PID 시뮬레이션

난이도 ★★☆ 2주 키워드 연결: 동역학·자동제어·기전공학
🌱 왜 이 활동이 너에게 좋을까? 2학년 진로활동 '과학 심화실험'에서 마찰계수를 직접 측정하고 '기계 요소 설계와 동력 전달 효율'까지 갔지만, 제어 시나리오는 다루지 않았어. 너의 회전 운동방정식 미분 탐구와 결합하면 "마찰을 모델로 잡는 동역학"이라는 한 단계 깊은 영역이 열려. PID라는 자동제어의 기본 언어를 한 번 손에 잡아두면, 3학년 면접에서 ABS든 로봇이든 "어느 곳에 어떻게 적용되는지"를 본인 언어로 풀 수 있어.

📚 알아두면 좋은 핵심 이론

  • 슬립률(Slip ratio λ): λ = (v_차량 - v_타이어)/v_차량. 타이어가 도로보다 얼마나 미끄러지는지의 비율. 0%는 완전 구름, 100%는 완전 잠김.
  • μ-λ 곡선: 슬립률 λ가 0.15~0.20일 때 마찰계수 μ가 최대가 되는 종 모양 곡선. ABS의 목표는 이 정점 근처에서 작동시키는 것.
  • Stribeck 곡선: 속도-마찰계수 그래프. 정지·경계·혼합·유체 윤활 4구간. 로봇 관절의 미세 제어에서 가장 골치 아픈 비선형성의 원인.
  • PID 제어: u(t) = K_p·e + K_i·∫e dt + K_d·(de/dt). P는 현재 오차, I는 누적 오차, D는 변화율. 자동제어의 가장 기본 언어.
  • 회전 운동방정식: τ = I·α (= I·dω/dt). 너의 2학년 미분 탐구가 바로 이 식이고, ABS·관절 제어 둘 다 이 식 위에서 돌아가.

A. 실험형 / 실천형

  • 경사면 위 정지/운동 마찰계수 측정 5쌍(접촉면 3종)
  • Colab으로 ABS 시뮬레이터 — λ 변화에 따른 μ 곡선 재현
  • 로봇 관절 마찰 모델(Stribeck) + PID 단순 시뮬
  • 결과 1쪽 비교 인포그래픽으로 정리

B. 문헌형

  • 대한기계학회·한국자동차공학회 'ABS 슬립 제어' 키워드
  • Pacejka 마찰모델 리뷰 논문(국내외 2~3편)
  • 한국로봇학회지 관절 마찰 보상 제어 사례
  • 단행본: '동역학(Hibbeler)' 마찰 단원, '제어공학 입문' PID 단원

🚀 어떻게 시작하면 될까

  1. 경사면 실험으로 정지/운동 마찰계수 측정⏱ 30분~1h
    각도 조절 가능한 판 + 시료(고무·플라스틱·금속) 3종. 시료가 막 미끄러지는 임계각 θ_s 측정 → μ_s = tan(θ_s). 이어 등속 미끄러질 때 각도 → μ_k. Phyphox '가속도'로 정량 검증. 표 작성: 접촉면 / μ_s / μ_k / σ(편차). 5쌍 측정으로 평균±편차 산출.✓ 완성품: 마찰계수 표 1장 + 측정 사진 3장. 시뮬에 넣을 입력값 확보.
  2. Colab에서 μ-λ 곡선(Pacejka magic formula) 그리기⏱ 1~2h
    Google Colab에 새 노트북. Pacejka 단순화식:
    import numpy as np, matplotlib.pyplot as plt
    lam = np.linspace(0, 1, 200)
    B,C,D,E = 10, 1.9, 1.0, 0.97 # 건조 아스팔트 예
    mu = D*np.sin(C*np.arctan(B*lam - E*(B*lam - np.arctan(B*lam))))
    plt.plot(lam, mu) → λ ≈ 0.15~0.20에서 μ 정점이 보임. D값을 0.6(젖은 길)·0.3(빙판)으로 바꿔 3개 곡선을 한 그래프에.✓ 완성품: 노면별 μ-λ 곡선 1장 + 코드 .ipynb. ABS 목표점이 한눈에.
  3. 1/4 차량 모델 + PID로 슬립률 0.15 추종 시뮬⏱ 2~3h
    회전 운동방정식 I·dω/dt = -μ(λ)·N·r + T_brake를 Colab에서 4차 룽게-쿠타(scipy.integrate.solve_ivp)로 풀기. 목표 λ* = 0.15, PID로 브레이크 토크 결정: T = Kp*e + Ki*∫e dt + Kd*de/dt. (Kp, Ki, Kd) 세 조합 비교 → 정착 시간·오버슈트 표. ABS OFF/ON 정지거리 비교 그래프 1장.✓ 완성품: 정지거리 비교 그래프 + PID 게인 튜닝 표.
  4. 로봇 관절 Stribeck 보상 + 인포그래픽 1매⏱ 2~3h
    Stribeck 식 F_f = (F_c + (F_s - F_c)·exp(-(v/v_s)²))·sgn(v) + σ·v를 Colab에서 그리고, 관절 위치 제어 PID에 마찰 보상 항을 더했을 때/안 했을 때 위치 오차 비교. Canva A4 1매: ABS μ-λ 곡선(좌) + 로봇 관절 Stribeck(우) + 공통 키워드: PID 자동제어. 한국로봇학회지(kros.org) 1편 인용.✓ 완성품: A4 비교 인포그래픽 1매 + KCI 인용 1건 + Colab .ipynb 1개.

🤖 3. CNN 기반 부품 결함 탐지 — 베어링 진동 데이터 실측

난이도 ★★☆ 3~4주(분산) 키워드 연결: 메커트로닉스·AI·자동제어
🌱 왜 이 활동이 너에게 좋을까? 2학년 인공지능 기초에서 'CNN 열화상 결함 탐지'를 탐색했지만 실제 데이터로 학습은 안 했어. 후속편으로 베어링 진동 공개 데이터셋으로 모델을 직접 돌려보면 "기계공학+AI"가 1·2·3학년 수직으로 이어져 패턴 ② 키워드 연계가 완성돼. 무엇보다 "AI 도구를 다룰 줄 아는 기계공학도"라는 차별점을 직접 만들어보는 경험 — 면접 단골 질문 "왜 너인가?"에 답할 수 있는 한 장이 손에 남게 돼.

📚 알아두면 좋은 핵심 이론

  • CNN(Convolutional Neural Network): 이미지·시계열의 국소 패턴을 합성곱 필터로 잡아내는 모델. '결함 진동의 모양 차이'를 알아서 학습해줘.
  • FFT(고속 푸리에 변환): 시간 신호 → 주파수 성분 분해. 베어링 결함은 BPFI·BPFO·BSF 같은 특정 주파수에서 튀어나와 — CNN의 입력으로 가장 좋아.
  • 스펙트로그램(Spectrogram): 시간-주파수 2D 이미지. 진동을 '그림'으로 바꿔서 영상 CNN을 그대로 쓸 수 있게 해주는 표현 방법.
  • 혼동행렬(Confusion Matrix): 모델이 정상/결함을 어떻게 맞추고 틀렸는지 4칸 표. 정확도만 보면 안 되고 정밀도·재현율을 같이 봐야 해.
  • PHM(Prognostics and Health Management): 기계 상태 감시·고장 예지 분야 통칭. 항공·발전·공장 자동화의 핵심이고, 기계+AI가 만나는 가장 뜨거운 영역.

A. 실천형

  • CWRU 베어링 진동(또는 NASA PHM) 공개 데이터셋 1종 다운로드
  • Google Colab에서 정상/결함 분류 CNN 학습
  • 혼동행렬·정확도 지표로 모델 평가, 1쪽 보고서
  • 스마트폰 가속도계로 모터 진동 녹음 → 모델에 입력해보는 확장

B. 문헌형

  • 대한기계학회·한국정밀공학회 'PHM' 키워드
  • 'condition monitoring CNN bearing' 리뷰 논문 2~3편
  • 한국산업기술시험원(KTL) 예지보전 자료
  • 단행본: '기계상태 감시와 진단' 일부, '딥러닝의 정석' CNN 단원

  1. CWRU 베어링 데이터 다운로드 + 신호 한 장 그리기⏱ 30분~1h
    케이스웨스턴리저브대 베어링 데이터 센터 (engineering.case.edu/bearingdatacenter) 접속 → '12k Drive End Bearing Fault Data'에서 정상(Normal) 1개 + 내륜결함(IR) 1개 + 외륜결함(OR) 1개의 .mat 파일 다운로드. Colab에서 scipy.io.loadmat로 읽고 첫 1초(12,000샘플) 시계열 그래프 3장. 결함 신호에서 주기적 충격 패턴이 한눈에.✓ 완성품: 정상/IR/OR 진동 시계열 .png 3장 + 코드 .ipynb. CNN 입력 후보 확보.
  2. FFT·스펙트로그램으로 입력 이미지 만들기⏱ 1~2h
    Colab에서 scipy.signal.spectrogram 또는 numpy.fft.rfft로 시간 신호 → 주파수 영역 변환. 1초 윈도우를 슬라이딩(50% 겹침)해 100~200장의 64×64 스펙트로그램 .png 생성. 클래스별 폴더 구조: /data/normal/, /data/IR/, /data/OR/. BPFI(내륜 통과 주파수) 위치를 메모 — CNN이 학습할 핵심 패턴.✓ 완성품: 클래스 3종 × 100~200장 스펙트로그램 + 폴더 구조 정리.
  3. 가벼운 CNN 모델 학습 + 혼동행렬 평가⏱ 2~3h
    Colab에서 PyTorch 또는 Keras 사용. 핵심 코드:
    from tensorflow import keras
    model = keras.Sequential([Conv2D(16,3,activation='relu',input_shape=(64,64,1)), MaxPool2D(2), Conv2D(32,3,activation='relu'), MaxPool2D(2), Flatten(), Dense(64,'relu'), Dense(3,'softmax')])
    model.compile('adam','sparse_categorical_crossentropy',metrics=['accuracy'])
    train/test 8:2 분할 → 10~20 epoch 학습. sklearn.metrics.confusion_matrix로 혼동행렬 출력. 정확도·정밀도·재현율 표 정리. 보통 95% 이상 잘 나와.✓ 완성품: 학습 곡선 .png + 혼동행렬 .png + 모델 성능 표.
  4. 스마트폰 모터 진동 녹음으로 확장 + 학회지 1편 인용⏱ 2~3h
    Phyphox로 가정용 선풍기·믹서기 진동 1초 녹음 → CWRU와 동일 전처리 → 학습된 모델에 입력. 결과 라벨이 무엇이 나왔는지 메모(완전히 다른 도메인이라 분류가 어색해도 OK — 그 자체가 도메인 적응 한계로 보고서 거리). KCI에서 '베어링 결함 CNN' 또는 '진동 기반 PHM' 논문 1편 검색해 인용. 6쪽 보고서: 동기→데이터→방법→결과→한계(도메인 격차)→확장.✓ 완성품: 6쪽 보고서 .pdf + KCI 인용 1건 + 본인 모터 진동 시연 결과. 학종 융합 키워드 완결.
