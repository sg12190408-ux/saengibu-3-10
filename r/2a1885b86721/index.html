SECTION 03

너만의 키워드 3개

학종 평가의 한 가지 분명한 원칙: "한 키워드로 1→2→3학년이 이어지면 학종에서 최고점".

건축 구조·안전친환경·에너지 효율BIM·디지털 설계재료 물성내진 설계아치 하중 분산단열·외피모듈러 건축도시 주거

키워드 수직 연계 — 학년별 깊이

건축 구조·안전친환경·에너지 효율BIM·디지털 설계
✨ 잘하고 있는 점: 1학년 진로희망 '건축학' → 2학년 진로희망 '건축'으로 한 번도 흔들림 없이 동일 키워드를 지켜왔어. 더 좋은 건 키워드 안의 '깊이'가 학년마다 진화한다는 점 — 1학년은 내진 구조·면진·제진의 분류에서 시작했고, 2학년에 들어와선 아치 하중을 곡률·두께를 변인으로 가설 연역 실험까지 끌고 갔어. BIM·모듈러는 1학년엔 단어조차 없다가 2학년 진로활동에서 통계와 한계 분석까지 들어간 새 키워드. 🌱 다음 한 걸음: 3학년에 건축 구조·친환경·BIM 셋 중 두 개를 한 활동에서 묶어줘. 예를 들어 'BIM으로 친환경 외피 곡면을 시뮬레이션' 같은 한 활동이면 1·2학년 세 키워드가 3학년에 모이며 수직 연계가 완성돼.

너의 베스트 모먼트 3

생기부에서 가장 잘 쓰인 문장 3개. 왜 좋은지를 우수 세특 패턴 분류로 풀어줄게.

🟢 진로활동 · 2학년 패턴 ① 동기·과정·결과·확장 + ⑥ 머리·가슴·발 통합

아치 하중 분산 — 독서·논문·실험으로 일반화

"'건축은 어떻게 서 있는가'로 아치 구조 하중 분산 원리를 학습하고, 관련 논문을 비교 분석한 뒤 골판지로 아치 하중 지지 실험을 기획. 곡률과 두께를 독립변인으로 설정하고 동일 스팬에서 최대 지지 하중을 반복 측정해 곡률·두께가 커질수록 지지력이 향상됨을 검증, 결과를 실제 아치·돔·교량 설계로 일반화."

✨ 독서 → 논문 비교 → 가설 연역 실험 → 일반화의 4단계 사이클이 한 활동에 다 들어가 있어. 학종에서 가장 좋아하는 '탐구 동력학' 모범 사례.
🟢 동아리활동(이데아2) · 2학년 패턴 ② 키워드 연계형 + ① 동기·과정·결과

단열재 비교 — 버터 녹는 속도로 본 열손실

"스티로폼·플라스틱·유리 구조물 내부에 동일 비커·동일 질량 버터를 넣고 외부 온도·비커 크기·물의 양·초기 온도·버터 질량을 통제하며 상변화 정도를 비교. 스티로폼이 가장 늦게 녹아 단열 성능이 가장 우수함을 검증. 변인 통제 체크리스트를 직접 제작해 실험 전 과정을 총괄."

✨ '단열'이라는 친환경 건축 핵심 키워드를 고등학생 수준에서 가장 단순·명료한 지표(버터 상변화)로 풀어냈어. 변인 통제 체크리스트를 본인이 만든 점이 학종에서 결정타.
🟢 진로활동 · 2학년 패턴 ② 키워드 연계형 + ⑤ 반성적 실마리

BIM·모듈러 건축 — 통계로 본 디지털 전환의 빛과 그림자

"디지털 기술과 구조 원리를 결합한 문제 해결형 건축 전문가를 목표로, BIM과 모듈러 건축의 디지털 전환 흐름을 분석. 모듈러가 공사 기간 단축·자재 낭비 감소·탄소 배출 저감에 기여함을 통계로 확인하고, 초기 비용 부담·기술 의존성 증가 등 한계도 함께 검토. 디지털 설계 기술이 주거·공공 건축, 재난 대응, 도시 재생으로 확장될 가능성까지 예측."

✨ '장점만'이 아니라 '한계도'를 함께 짚었어. 학종 평가자 시선에서 가장 신뢰가 가는 서술 방식이고, BIM이라는 학과 핵심 키워드가 너의 진로 어휘에 정착했다는 증거.

📐 1. BIM 기반 외피 곡면 일사량 시뮬레이션 — 수학Ⅱ 다음 단계

난이도 ★★☆ 3~4주 키워드 연결: BIM·친환경·외피
🪨 왜 민규에게? 2학년 수학Ⅱ에서 외피 곡면 일사량을 미적분으로 모델링은 했지만, 실제 건축물 형상(예: 곡면 학교 강당 1동)에 대입한 적은 없어. 진로선택 인공지능 기초 A의 코딩 역량 + 기하 A의 태양벡터 입사각 경험이 정확히 만나는 영역이고, 같은 학과 지원자 중 흔치 않은 차별점이 돼.

📚 알아두면 좋은 핵심 이론

  • BIM(Building Information Modeling): 3D 형상에 자재·열·에너지 데이터를 같이 담는 디지털 건물 모델. 설계·시공·운영 전 단계가 한 파일로 연결되는 게 핵심.
  • 입사각(Angle of Incidence): 태양 광선과 외피 법선이 이루는 각. cos(θ)에 비례해 단위면적당 일사량이 결정 — 외피 경사가 왜 중요한지의 수식적 이유.
  • U값(열관류율): 외피 1㎡가 1℃ 차이일 때 통과하는 열량(W/㎡·K). U값이 낮을수록 단열 좋음. 단열재 비교의 1순위 지표.
  • 일사 흡수율 vs 반사율(Albedo): 외피 색·재질에 따라 일사 에너지 중 얼마나 들어오고 얼마나 튕겨나가는지. 친환경 외피 설계의 결정 변수.
  • 녹색건축인증(G-SEED): 국토교통부의 친환경 건축 평가 시스템. 에너지·실내환경·재료 등 7개 분야로 별 5등급 — 같은 학과 지원자 중 이 키워드 쓰는 학생 거의 없음.

A. 실험형 / 실천형

  • 춘천고 건물 또는 임의 강당 1동을 대상으로 SketchUp·Sweet Home 3D(무료)로 단순 매스 모델링
  • 곡률 또는 외피 경사를 0·15·30·45도로 변인 설정하고 위도(춘천 약 37.9°N) 일사 데이터로 하지·동지 입사 일사량 계산
  • 외피 곡률 vs 연간 일사량 그래프 + 단열재 종류별 열손실 표 작성
  • 1쪽 인포그래픽으로 '에너지 효율 외피 가이드' 산출

B. 문헌형

  • DBpia·RISS '건물 외피 일사량', 'building envelope solar'
  • 대한건축학회논문집·한국건축친환경설비학회 논문 1~2편
  • 국토교통부 녹색건축인증(G-SEED) 매뉴얼·에너지효율등급 기준
  • 단행본: '건축 환경 계획' 또는 '제로에너지건축 입문' 1~2장

🚀 어떻게 시작하면 될까

  1. 춘천 일사·위도 데이터 한 장으로 정리⏱ 30분~1h
    기상자료개방포털(data.kma.go.kr) 접속 → "기후통계분석" → 지점 춘천 선택 → 월별 일사량(MJ/㎡) 다운로드. 위도 37.9°N과 함께 월 / 평균 기온 / 일사량 / 일조시간 표 1장으로 정리. 하지·동지 태양고도(약 75.6°·28.6°)도 메모.✓ 완성품: A4 반쪽 춘천 기후 데이터 표. 모든 계산의 기준선.
  2. SketchUp으로 강당 매스 모델링 + 경사 변인 4종⏱ 1~2h
    SketchUp Free(app.sketchup.com) 가입 → 직사각형 강당(20m×30m×8m) 매스 1동 그리기 → 지붕 경사를 0°·15°·30°·45° 4가지로 복제. 메뉴 창 → 그림자에서 위도·날짜·시각 설정 → 하지(6/21) 정오·동지(12/22) 정오 그림자 캡처 4장 × 2계절 = 8장.✓ 완성품: 경사별 그림자 비교 캡처 8장 + .skp 파일.
  3. Excel로 입사각·일사량 자동 계산 시트⏱ 1~2h
    Excel 시트에 경사각·태양고도·입사각=|경사각-(90-태양고도)|·실효일사=일사량×COS(RADIANS(입사각)) 수식 입력. 단열재 4종(스티로폼·글라스울·우레탄·진공단열재)의 U값(0.040·0.038·0.022·0.008 W/m·K) 추가해 열손실=U×면적×ΔT로 일일 열손실 비교. (도전) BIM 4D 시뮬레이션·친환경 건축 LCA 키워드로 KCI(kci.go.kr) 논문 1편 더 찾아보기.✓ 완성품: 입사각-일사량-열손실 자동계산 .xlsx + 비교 그래프 3장.
  4. '에너지 효율 외피 가이드' A4 인포그래픽 마무리⏱ 2~3h
    Canva(canva.com)에서 A4 1매 → 구조: 춘천 위도·기후 → 경사 0/15/30/45° 비교 → 최적 경사 + 추천 단열재 → G-SEED 등급 추정. 건축학회지(aik.or.kr) 또는 건축구조학회지에서 비슷한 외피 연구 1편 찾아 인용 1줄 추가. 수학·물리 교과샘께 cos 입사각 모델 검토 받기.✓ 완성품: A4 인포그래픽 1매. 자기소개서·면접의 'BIM·친환경' 핵심 자료.

🏗️ 2. 콘크리트 노화 진단 — 건축 안전성 후속 탐구

난이도 ★★☆ 2~3주 키워드 연결: 구조 안전·내진·재료
🪨 왜 민규에게? 1학년 내진 설계, 2학년 영어Ⅰ '외벽 무너진 사고가 진로 동기'였다는 본인 진술, 자율활동 재료 물성 비교까지 — '왜 같은 콘크리트도 어떤 건물은 오래 가는가'가 너의 진짜 호기심이야. 1학년 진로활동에서 'pH 변화로 콘크리트 부식을 감지하는 천연 센서' 아이디어를 이미 던졌으니, 그 아이디어를 한 단계 검증하는 후속편.

📚 알아두면 좋은 핵심 이론

  • 중성화(Carbonation): 공기 중 CO₂가 콘크리트 알칼리 성분과 반응해 pH가 13 → 9 이하로 떨어지는 현상. 철근 부식 시작 = 건물 수명 종료의 1차 신호.
  • 철근 부식 임계 pH: pH 11 이하에서 철근 보호막(부동태 피막)이 깨지고 녹슬기 시작. 외부 균열보다 먼저 진행되는 '눈에 안 보이는 노화'.
  • 아치 하중분산 vs 보-기둥 구조: 1학년에 본인이 탐구한 주제. 아치는 압축력으로 하중 전달 → 콘크리트 강점 활용 / 보-기둥은 인장 → 철근 의존. 부식이 더 치명적인 쪽이 후자.
  • 비파괴 검사(NDT): 슈미트 해머·초음파·페놀프탈레인 시약 등으로 건물을 부수지 않고 강도·중성화 깊이를 진단. 국토안전관리원 시설물 점검의 기본.
  • 수명 예측 모델: 중성화 깊이 ∝ √시간 — Square-root law로 알려진 가장 단순한 모델. 너의 1학년 가설검정 경험과 직결.

A. 실험형 / 실천형

  • 모르타르 큐브 3~4개를 만들어 양생 후 식초·소금물·중성수에 일정 시간 담그기
  • 천연지시약(자색양배추 등)으로 표면 pH 변화 추적, 무게 변화·표면 균열 사진 비교
  • '재료 노출 환경 → pH·균열 발생 여부' 표 작성
  • 1쪽 진단 가이드 인포그래픽 산출

B. 문헌형

  • DBpia '콘크리트 중성화', 'concrete carbonation aging'
  • 한국콘크리트학회 논문집의 중성화·내구성 평가 논문
  • 국토안전관리원 시설물 안전점검 매뉴얼(콘크리트 비파괴 검사)
  • 단행본: '콘크리트 공학' 또는 '구조 재료 노화' 입문 챕터

🚀 어떻게 시작하면 될까

  1. 모르타르 큐브 4개 제작 + 자색양배추 지시약 추출⏱ 1~2h + 양생 7일
    학교 과학실 또는 가정에서 시멘트:모래:물 = 1:3:0.5 비율 → 50mm 큐브 4개 성형(우유팩 활용 가능). 7일간 비닐로 덮어 양생. 자색양배추 1/4통을 끓여 지시약 액(pH 1=빨강 / 7=보라 / 13=노랑)을 200mL 만들어 분무기에 보관.✓ 완성품: 모르타르 큐브 4개 + 자색양배추 지시약 200mL.
  2. 4가지 환경 노출 + pH·무게·균열 매일 기록⏱ 매일 10분 × 7일
    큐브 4개를 ① 식초(산성, pH 3) ② 소금물(3% NaCl) ③ 중성수 ④ 공기 중(대조군) 환경에 7일 배치. 매일 사진 + 무게(0.1g 단위) + 자색양배추 지시약 분무 후 색 변화 메모. Excel에 날짜 / 환경 / 무게 / pH 추정 / 균열 사진 표 작성.✓ 완성품: 7일 × 4환경 = 28건 데이터셋 + 사진 28장.
  3. 구조해석 유한요소 개념으로 균열 → 강도 손실 추정⏱ 2~3h
    검색 키워드 구조해석 유한요소·concrete carbonation aging으로 KCI(kci.go.kr) 한국콘크리트학회 논문 2편 + RISS 학위논문 1편 다운로드. 초록·결론에서 중성화 깊이 = K√시간 모델의 K값(보통 1~3 mm/√년) 발췌. 본인 실험의 7일 데이터에 K값 대입해 '50년 후 예상 중성화 깊이' 추정 표 작성. (도전) Sweet Home 3D로 가상 외벽 단면 그리고 부식 진행 시각화.✓ 완성품: 수명 예측 표 1장 + 논문 3편 인용 메타표 1장.
  4. '콘크리트 노화 자가진단 가이드' 인포그래픽 + 학급 공유⏱ 2~3h
    Canva(canva.com)에서 A4 1매 → 구조: 중성화 메커니즘 → 실험 결과 4환경 비교 → K√t 수명 모델 → 일반인이 따라 할 수 있는 자가진단 3단계. 한국콘크리트학회 윤리 가이드 1줄 인용 추가. 화학·물리 교과샘께 pH·재료 모델 검토 받고 학급·과학실 게시.✓ 완성품: A4 인포그래픽 1매. 1학년 'pH 천연 센서' 아이디어를 검증한 결과물 → 면접 단골 카드.

🌳 3. 모듈러·도시 주거 + 자연 접근성 — 문학 토론 후속 메타 분석

난이도 ★☆☆ 2~3주(분산) 키워드 연결: 도시·모듈러·주거
🪨 왜 민규에게? 2학년 문학에서 '청산별곡'을 도시 주거 문제와 연결한 토론 글쓰기가 정말 좋았어. 그 흐름이 일회성으로 끝나지 않게, 통계지리정보 같은 공공데이터 + 모듈러 건축까지 끌어오면 '문학 → 사회과학 데이터 → 모듈러 건축 설계 제안'으로 1·2·3학년 키워드가 도시·주거 축에서 한 번 더 이어져. 실험 부담이 가장 적어 3학년에 안전한 카드.

📚 알아두면 좋은 핵심 이론

  • 모듈러 건축(Modular Construction): 공장에서 미리 제작한 박스형 유닛을 현장에서 조립하는 방식. 공기 50% 단축·폐기물 80% 감소 — 1인 가구·임시 주거의 차세대 솔루션.
  • 녹지 접근성(Green Space Accessibility): 거주지에서 가까운 녹지까지의 거리·면적·질. WHO 기준은 도보 5분(300m) 내 0.5ha 이상이지만 한국 도시는 평균 미달.
  • 1인 가구·도시 외로움: 한국 1인 가구 비율 35% 돌파(2023). 정신건강·신체건강 모두에 부정적 — '청산별곡 정서'가 현대 도시에서 재현되는 이유.
  • 필로티·옥상정원·수직정원: 좁은 도시 대지에서 녹지를 '쥐어짜는' 3대 건축 기법. 친환경 건축 LCA(생애주기평가)에서 점수가 잘 붙는 영역.
  • SGIS(통계지리정보서비스): 통계청이 운영하는 무료 GIS 플랫폼. 1인 가구 비율·녹지율·연령 분포를 동 단위로 시각화 — 같은 학과 지원자 중 이 도구 쓰는 학생 거의 없음.

A. 실천형

  • 춘천 시내 학교 주변 1km 반경의 1인 가구 비율·녹지 비율을 통계지리정보서비스(SGIS)에서 추출
  • 주거 유형(아파트·다세대·주택)별 녹지 접근성 차이 비교 표
  • 학급 친구들 대상 짧은 설문(10분 이내·10명)으로 '집 근처 자연 공간 만족도' 데이터화
  • 모듈러 + 옥상정원·필로티 녹지 적용 제언 1쪽 정리 후 학급 게시

B. 문헌형

  • DBpia·KISS '도시 1인 가구 주거', 'urban green space wellbeing'
  • 대한건축학회·한국도시설계학회 도시재생·녹지 계획 논문 2~3편
  • 국토연구원·서울연구원 1인 가구 주거실태 보고서
  • 단행본: '도시는 무엇으로 사는가(유현준)' 일부 챕터

🚀 어떻게 시작하면 될까

  1. SGIS에서 춘천 1km 반경 데이터 추출⏱ 1~2h
    통계지리정보서비스(sgis.kostat.go.kr) 접속 → "대화형 통계지도" → 학교 위치 검색 → 반경 1km 설정. 항목: 1인 가구 비율·녹지면적 비율·연령별 인구 3개를 동(읍면) 단위로 캡처. Excel에 옮겨 동 / 1인 가구 % / 녹지 % / 학생 거주 여부 표 작성.✓ 완성품: 학교 주변 5~7개 동의 데이터 표 1장 + SGIS 캡처 3장.
  2. 학급 설문 10명 + 자연공간 만족도 데이터화⏱ 1h + 응답 1일
    Google Forms에 5문항 설문(2분 이내): ① 거주 동 ② 주거 유형(아파트/다세대/주택) ③ 집에서 가장 가까운 공원까지 도보 시간 ④ 집 근처 자연공간 만족도(1~5점) ⑤ 자유의견 한 줄. 학급 단톡방에 공유 → 10명 응답 수집. Excel 피벗으로 주거 유형별 평균 만족도 비교 막대그래프.✓ 완성품: 설문 응답 .xlsx + 만족도 비교 그래프 1장.
  3. 논문 2~3편 + '도시는 무엇으로 사는가' 1챕터 메타 표⏱ 3~4h
    DBpia(dbpia.co.kr) 검색 키워드 도시 1인 가구 주거·urban green space wellbeing·모듈러 주거 → 건축학회지(aik.or.kr)·도시설계학회 논문 2~3편 다운로드. 학교 도서관에서 '도시는 무엇으로 사는가(유현준)' 빌려 1~2챕터 읽기. 메타 표: 저자·연도 / 표본·지역 / 핵심 지표 / 결론 한 줄 / 인용 가능 부분.✓ 완성품: 메타 비교 표 1장 (논문 3편 + 단행본 1챕터).
  4. 모듈러 + 녹지 통합 제언 인포그래픽 + 학급 게시⏱ 2~3h
    Sweet Home 3D 또는 SketchUp으로 1인용 모듈러 유닛(3m×6m) 1동 + 옥상정원·필로티 녹지 간단 모델링 후 캡처. Canva(canva.com) A4 1매 인포그래픽: 춘천 데이터 핵심 → 친구 설문 결과 → 논문 메타 결론 → 모듈러+녹지 건축 제언 3가지. 국어 교과샘께 청산별곡 → 현대 주거 흐름 검토 받고 학급 게시. (도전) 친환경 건축 LCA 키워드로 모듈러의 탄소 절감량 1줄 추가.✓ 완성품: A4 인포그래픽 1매 + 모듈러 모델 캡처. 면접의 '문학→데이터→건축' 서사 카드.
