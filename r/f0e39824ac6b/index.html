🦟 1. BT균 살충 효능 모델링 — 과학과제 연구 다음 단계

난이도 ★★☆ 3~4주 키워드 연결: 미생물·환경생명·정량 분석
🌱 왜 이 활동이 경민이에게 좋을까? 2학년 과학과제 연구에서 BT균 농도-치사율을 정성적으로 비교했지만, 시간·온도 의존성을 수학 모델로 끌어올린 적은 없어. 인공지능 기초 A의 코딩 역량을 더해 살충 곡선을 함수로 만들면 1학년 알지네이트비드 → 2학년 BT균 → 3학년 BT균 살충 동력학으로 키워드가 수직 연계되고, 면접에서 "왜 환경생명공학?"에 본인 그래프 1장으로 답할 수 있게 돼.

📚 알아두면 좋은 핵심 이론

  • 로지스틱 생장 모델(Logistic growth): dN/dt = rN(1 − N/K). 미생물 개체수가 환경 수용력 K에 다가가며 S자 곡선을 그리는 가장 기본 모델 — 수학Ⅰ 지수함수의 미생물판이라고 보면 돼.
  • 미카엘리스-멘텐 효소속도론(Michaelis–Menten): v = Vmax·[S]/(Km+[S]). BT 결정독소가 곤충 장세포 수용체에 결합·작용하는 속도를 설명하는 식. 농도가 높아져도 속도가 어느 한계를 넘지 못하는 이유야.
  • 치사율-시간 곡선(Lethal Time, LT₅₀): 시험 개체군의 50%가 죽는 데 걸리는 시간. 농도-반응(LD₅₀)에 시간축을 더한 개념으로, 살충제 효력 비교의 표준 지표.
  • Q₁₀(온도계수): 온도가 10℃ 오를 때 반응속도가 몇 배가 되는지를 나타내는 값. 효소 반응은 보통 Q₁₀ = 2~3 — 정화조 15℃와 상온 25℃의 살충 효율 차이를 정량적으로 설명할 수 있어.
  • 잔류성·반감기(Persistence): Bt 결정독소가 자외선·토양에서 분해되는 1차 반응 속도상수 k. 친환경 농약의 안전성과 재처리 주기를 결정하는 핵심 변수야.

A. 실험형 / 실천형

  • 기존 BT균 농도-치사율 데이터를 시간(0·12·24·48h) 축으로 재정리
  • 로지스틱·지수감쇠 모델 두 개로 사망률 곡선을 Python·엑셀로 피팅
  • 온도(상온·정화조 평균 약 15℃) 변수 추가해 활성 차이 비교
  • 결과를 '한 장 인포그래픽 + 부록 그래프 1쪽'으로 정리해 동아리에 공유

B. 문헌형

  • DBpia·RISS '바실러스 투린지엔시스 살충 효능', 'Bt mosquitocidal'
  • 한국미생물·생명공학회지의 BT 제제 안정성·잔류성 리뷰
  • 식약처·농촌진흥청 미생물농약 등록 가이드라인 공시 자료
  • 단행본: '미생물에 관한 거의 모든 것(존 잉그레이엄)' BT 챕터

🚀 어떻게 시작하면 될까

  2. Colab에서 1차 사멸 곡선 피팅⏱ 1~2h

  3. 온도 변수 추가 + Q₁₀ 산출⏱ 1~2h
    상온(25℃) 데이터와 정화조 평균(15℃) 데이터를 모은 뒤 같은 농도에서 사멸상수 k를 비교. Q10 = (k_25/k_15)**(10/(25-15))로 온도계수 계산. (도전) scipy.stats.linregress로 Arrhenius 그래프(ln k vs 1/T)를 그려 활성화 에너지 Eₐ까지 산출하면 깊이 ↑. 정화조 운용 한계 농도를 한 줄 결론으로.✓ 완성품: Q₁₀ 값 + Arrhenius 그래프 1장 + "정화조 운용 시 권장 농도" 한 줄 결론.

🌊 2. 환경 eDNA로 본 도시 하천 생물 다양성

난이도 ★★☆ 3~4주(분산) 키워드 연결: eDNA·환경생명·생물 다양성
🌱 왜 이 활동이 경민이에게 좋을까? 2학년 동아리 스타브릿지에서 eDNA 채취·필터링까지는 직접 해봤지만, 결과를 '도시 하천 생물 다양성'이라는 한 가지 질문으로 묶어내는 단계가 비어 있어. 진로활동의 '환경생명공학' 키워드와 정확히 만나고, 침묵의 봄·DDT 잔류성 분석과도 한 줄로 이어져 — "직접 손으로 환경을 만져본 학생"이라는 본인 색깔이 데이터로 증명되는 활동이야.

📚 알아두면 좋은 핵심 이론

  • eDNA 환경유전자(environmental DNA): 생물이 환경(물·흙)에 떨어뜨린 점액·배설물·세포 조각에서 추출한 DNA. 직접 잡지 않고도 그 수역에 어떤 종이 사는지 알 수 있는 가장 빠른 생태 모니터링 도구야.
  • 메타바코딩(Metabarcoding): 한 시료에 든 모든 종의 DNA를 동시에 PCR 증폭·시퀀싱하는 기법. 어종은 12S rRNA, 미생물은 16S rRNA, 어류·양서류는 COI 영역을 표적으로 삼아.
  • OTU/ASV(분류 단위): 시퀀스 유사도로 묶어낸 '운영분류단위(OTU)' 또는 정확히 한 염기까지 구분하는 'ASV'. 같은 시료에서도 어느 단위를 쓰느냐에 따라 종 풍부도가 달라져.
  • Shannon·Simpson 다양도 지수: 종 수만이 아니라 균등도까지 반영하는 정량 지수. H = −Σpᵢ·ln pᵢ로 도시화 정도가 다른 두 지점의 다양성을 한 숫자로 비교할 수 있어.
  • 지표종(Indicator species): 특정 환경 조건에서만 살아남는 종. 도시 하천에서 검출되는 BOD 내성종(예: 깔따구·실지렁이)은 오염도의 살아있는 신호등이야.

A. 실험형 / 실천형

  • (가능 시) 학교 인근 하천 2~3지점에서 eDNA 추가 채취 또는 기존 데이터 재분석
  • OBIS·GBIF·국립생태원 공공 eDNA 데이터로 도시화 정도와 종 풍부도 비교
  • 오염원(생활하수·공업)이 우점종에 미치는 영향 가설 검증
  • 결과를 학급·보건실용 인포그래픽 1쪽 + 동아리 발표 1회

B. 문헌형

  • DBpia·KISS '환경 DNA 메타바코딩', 'eDNA biodiversity stream'
  • 국립생태원·국립생물자원관 eDNA 모니터링 보고서
  • 한국하천호수학회지 도시 하천 수질-생물 다양성 리뷰 5건
  • 단행본: '강의 죽음과 부활(주디스 드 종)' 또는 침묵의 봄 재독 메모

🚀 어떻게 시작하면 될까

  1. 2학년 스타브릿지 데이터 + 지점 메타정보 정리⏱ 1h
    2학년에 채취한 하천 시료의 GPS 좌표·채취 일시·검출 종 리스트를 Google Sheets에 지점 / 좌표 / 일시 / 검출 종(학명·국명) / 시퀀스 수 형식으로 정리. 환경부 물환경정보시스템(water.nier.go.kr)에서 같은 좌표의 BOD·COD·도시화율(주변 100m 토지피복) 자료 추가. 이 한 표가 모든 비교의 출발점이야.✓ 완성품: 지점별 eDNA + 수질 + 도시화 메타 표 1장.
  2. 공공 eDNA 데이터로 비교군 확보⏱ 1~2h
    GBIF(gbif.org) 또는 국립생물자원관 한반도생물다양성(species.nibr.go.kr)에서 검색 키워드 eDNA stream Korea, 한강 어류로 공공 데이터셋 1~2개 다운로드(CSV). 도시 하천(서울·부산권)과 자연 하천(강원·경북) 각 1지점씩을 비교군으로 골라 본인 데이터와 같은 칸에 정렬. 직접 채취가 어려우면 이 단계가 메인 데이터가 돼.✓ 완성품: 비교군 2지점 데이터 통합 시트 1장.
  3. Colab에서 Shannon 다양도 + 우점종 비교⏱ 2~3h
    Google Colab에 새 노트북 → 다음 코드로 다양도 산출:
    import pandas as pd, numpy as np
    df = pd.read_csv('edna.csv') # 지점·종·count
    def shannon(p): return -np.sum(p*np.log(p+1e-9))
    for site in df.site.unique():
      c = df[df.site==site]['count']; p = c/c.sum()
      print(site, shannon(p))
    지점별 H 값을 막대그래프로 + 도시화율과의 산점도 1장. scipy.stats.spearmanr로 상관계수까지 산출하면 깊이 ↑.✓ 완성품: 지점별 Shannon 다양도 막대 + 도시화율-다양도 산점도 + 상관계수 r.
  4. 지표종 인포그래픽 + 보고서 마무리⏱ 2~3h
    Canva(canva.com)에서 A4 1매 → 구조: 채취 지점 지도 → 지점별 지표종(깔따구·실지렁이 등 BOD 내성종 vs 자연하천 청정종) → Shannon 다양도 비교 → 도시화→다양성 감소 한 줄 결론 + 환경 정화 제언. KISTI NDSL(scienceon.kisti.re.kr)에서 'eDNA 도시 하천' 논문 1편의 결론과 본인 결과를 1줄로 비교. 동아리·진로 발표용 메모 1쪽 추가.✓ 완성품: A4 인포그래픽 1매 + 발표 메모. 환경생명공학 면접 자료 직결.

난이도 ★☆☆ 2~3주 키워드 연결: 미생물·탄소중립·환경생명
🌱 왜 이 활동이 경민이에게 좋을까? 2학년 진로활동에서 스피룰리나 등 미세조류의 CO₂ 고정 효율을 수치 자료로 정리한 흐름을, '여러 균주·여러 조건'의 정량 비교까지 한 단계 더 끌어올리는 후속편이야. 실험 부담이 적어 3학년 일정에 가장 안전한 카드이고, 면접의 "왜 환경생명공학?"에 직접 답해주는 자료가 손에 남게 돼 — 발효 대사공학·합성생물학으로 가는 다리도 같이 놓이고.

📚 알아두면 좋은 핵심 이론

  • 광합성 탄소고정(C3·C4·CAM): 미세조류는 대부분 C3 경로로 RuBisCO 효소가 CO₂를 3-PGA로 고정. 같은 CO₂ 1몰을 잡는 데 ATP·NADPH가 얼마나 드는지가 균주별 효율 차이의 출발점이야.
  • 발효 대사공학(Metabolic engineering): 미생물의 대사 흐름을 의도적으로 재설계해 목적 산물(바이오디젤·단백질·CO₂ 흡수)을 늘리는 분야. 합성생물학과 함께 환경생명공학의 가장 뜨거운 축이야.
  • 비생장률 μ와 더블링타임: dX/dt = μX. 더블링타임 td = ln2/μ로 환산. 광량·CO₂ 농도가 바뀌면 μ가 달라지고, μ_max 대비 어디쯤인지가 균주 비교의 핵심.
  • 광량-광합성 곡선(P-I curve): 광량(I)이 낮을 때는 선형으로 증가하다 포화광량 Iₖ를 넘으면 광저해(photoinhibition)로 도리어 감소. "빛이 많을수록 좋다"가 거짓인 이유.
  • 탄소고정 효율과 LCA(전과정평가): 배양조 구동·CO₂ 공급에 드는 에너지를 빼야 진짜 순고정량이 나와. "화석연료 정당화" 비판을 정량으로 반박하려면 LCA 관점이 필수.

A. 실천형

  • 스피룰리나·클로렐라·해마토코쿠스 등 3종의 CO₂ 고정 효율을 표준 자료로 비교표 작성
  • (가능 시) 클로렐라 소규모 배양 + 광량·CO₂ 농도별 색·생장 관찰
  • '배양 안정성·비용·화석연료 사용 정당화 우려' 관점을 정성 보완
  • 한 장 인포그래픽 + 발표 자료 1세트로 산출

B. 문헌형

  • DBpia·KISTI 'microalgae carbon capture', '바이오 탄소중립'
  • 한국조류학회지·한국생물공학회지 미세조류 배양 리뷰
  • 환경부·산업부 탄소중립 시나리오의 바이오 부문 보고서
  • 단행본: '바이오 이코노미(이장재)' 미세조류 챕터

🚀 어떻게 시작하면 될까

  1. 3종 균주 표준 자료 카드 만들기⏱ 1~2h
    KISTI ScienceON(scienceon.kisti.re.kr)·DBpia(dbpia.co.kr)에서 microalgae CO2 fixation rate, 스피룰리나 탄소고정로 검색. 스피룰리나·클로렐라·해마토코쿠스 각 1편씩 리뷰 논문에서 균주 / CO₂ 고정률(g/L/d) / 비생장률 μ / 최적 광량 / 최적 온도 카드 1장씩 작성. 단위가 다르면 g CO₂/g biomass·d로 통일.✓ 완성품: 균주별 표준 카드 3장. 다음 단계 비교의 기준선.
  2. Colab에서 비생장률·더블링타임 그래프⏱ 1h
    Google Colab에 새 노트북 → 다음 코드:
    import numpy as np, matplotlib.pyplot as plt
    mu = {'스피룰리나':0.45, '클로렐라':0.65, '해마토코쿠스':0.20} # 1/day, 논문값
    td = {k: np.log(2)/v for k,v in mu.items()}
    plt.bar(td.keys(), td.values()); plt.ylabel('Doubling time (day)')
    μ가 광량·CO₂ 농도에 따라 어떻게 변하는지 P-I 곡선 함수(μ = μ_max·I/(Iₖ+I))로 추가 시뮬레이션 1장.✓ 완성품: 더블링타임 막대 + P-I 곡선 .png 2장 + .ipynb.
  3. (가능 시) 클로렐라 소규모 배양 관찰⏱ 1~2주(분산)
    학교 과학실 또는 동아리실에서 클로렐라 분양체(온라인 1만 원대) + Erlenmeyer 플라스크 250mL × 3개. 광량 변수: 책상등 직조명·반그늘·자연광. 매일 1회 OD₆₈₀(분광광도계가 없으면 색강도를 휴대폰 카메라 + ImageJ로 RGB 추출) 측정해 일자 / OD or 색강도 시계열 만들기. 7~10일 데이터로 μ 추정. 실험 불가하면 NCBI GEO(ncbi.nlm.nih.gov/geo) 공공 배양 데이터로 대체.✓ 완성품: 광량별 생장 곡선 1장 + μ 추정값 + 사진 일지.
  4. LCA 관점 비판 보강 + 인포그래픽⏱ 2~3h
    "미세조류 탄소포집이 화석연료를 정당화한다"는 비판을 한 단락 인용(환경부 탄소중립 시나리오 보고서 또는 그린피스 자료) → 본인 데이터로 배양 에너지 투입 vs CO₂ 고정량 추정 한 줄 추가. Canva(canva.com)에서 A4 1매 → 구조: 3종 비교 → 최적 조건 → LCA 관점 한계 → 환경생명공학 제언. 진로샘께 5분 발표 검토.✓ 완성품: A4 인포그래픽 1매 + 발표 자료. 면접 'Why 환경생명공학' 답변 자료 직결.
